# 0.69 界面改版 · 第一、二级

## 第一级：换白 + 图标（0.69.0）
- 全工程 33 个 ui 文件、363 处写死的颜色统一换成浅色系：底色 #F4F5F7、面板纯白、文字 #22262B、次要文字 #6B7178、分隔线 #E8EBEF、选中底 #E3EDFF。深色只留在画布外一圈与全屏预览。
- 新增 `ui/RevealPalette.kt`：`Rv` 对象集中管理颜色、圆角、间距、动效时长（150/220/320ms）与强调缓动曲线。**以后新界面一律从这里取，不许再写死颜色。**
- 软件图标换成参考图裁切：以 900×900 裁切（脸居中、铃铛在左上），生成 mdpi~xxxhdpi 五套 `ic_launcher.png`、`ic_launcher_round.png`（白底圆形裁切）、`ic_launcher_foreground.png`（自适应图标前景，内容占 68%）；`ic_launcher_background` 由深色改成白色。

## 第二级：模式化外壳（0.69.1）
- 新增 `ui/ModeShell.kt`：
  - `RvMode` 六个模式：抠图 / 调色 / 排版 / 修图 / 绘制 / AI（顺序按功能完善度）。
  - `filterForMode()`：按模式过滤左侧类目。抠图=选区；调色=调色+滤镜；排版=变换+文字+形状；修图=「绘制」里的修复类（修复画笔/污点/仿制/图案图章/红眼/历史画笔/艺术历史/减淡/加深/海绵/涂抹/颜色替换/混合器/魔术橡皮）+ 特效；绘制=「绘制」剩下的上色类；AI=空（点它只提示「还没接入」）。
  - 图层 / 样式 / 辅助 / 文件 / 面板 这五个全局类目在所有模式下都保留。
  - `ModeBar`：顶部一排模式胶囊，选中态背景/文字/缩放都走 220ms 强调缓动过渡。
  - `LayerFab`：右下角 58dp 圆形图层按钮（主色底、白图标、右上角层数角标）。
- `EditorScreen`：顶部状态栏下面接模式栏；左侧栏只渲染当前模式的类目；根布局右下角浮一个图层按钮，点了直接开图层面板。

3. 模式切换没有做左栏整体滑入/淡入，只做了胶囊的选中过渡。
4. 首页（工程列表）只是配色跟着变白，版式没重排。
5. AI 模式只有入口，没有任何功能。
6. 没跑模拟器。

## 怎么验
1. 桌面图标应变成蓝发猫耳角色（白底）。
2. 打开任意工程：顶部状态栏下面多一排「抠图 调色 排版 修图 绘制 AI」。
3. 点「调色」：左侧栏只剩调色/滤镜/图层/样式/辅助/文件/面板；点「抠图」只剩选区类。
4. 右侧下角有一个蓝色圆形图层按钮，右上角数字是层数，点它直接开图层面板。
5. 点「AI」：弹一句「AI 模式还没接入，先占个位置」。
