# 0.72.6 色相饱和度 / 亮度对比度接上

1. 调色→色相饱和：三个滑块（色相 -180~180、饱和度 -100~100、明度 -100~100）+「应用」「归零」。
2. 调色→亮度对比：两个滑块（亮度 -100~100、对比度 -100~100）+「应用」「归零」。
3. 两个都走 `AdjustOp` + `AdjustApply.applyInPlace`，应用后进 `applyFilterToActive`（自带撤销与图层刷新）。

这样调色 11 项里已有 9 项可用：曝光度、自然饱和度、色彩平衡、黑白、照片滤镜、色调分离、渐变映射、色相饱和、亮度对比。剩色阶、曲线两项。
