# 0.74.93 修复记录（侵权审计整改）

审计依据：2026-11-11 对 0.74.92 全量只读审计，结论为「代码未发现抄写痕迹，资源与文案有 6 处合规风险」。
本版只做合规整改，不改任何图像算法与界面逻辑。

## 改了什么

1. **删除个人赞赏码**
   - 删除 `app/src/main/res/drawable-nodpi/reward_qr.png`（229KB，微信赞赏码，中间嵌动漫插画、属个人收款码）
   - 删除 `app/src/main/java/com/reveal/editor/ui/WelcomeDialog.kt`（该弹窗早已无调用点，是死代码）
   - 移除 `MainActivity.kt` 里对应的 `import com.reveal.editor.ui.WelcomeDialog`
   - 效果：APK 内不再含个人收款码与那张插画

2. **README 去掉以商业软件品牌作卖点的表述**
   - 开头改成「手机上的抠图 App（Android），实验性项目」的事实描述，删掉原文里拿桌面修图软件当卖点的那句
   - 「已知限制」里删掉「某桌面软件同样有这个限制」这类借品牌作背书的句子
   - 进度、功能、限制三节按 0.74.x 实际能力重写（原文停在 v0.1.0 骨架）
   - 全文不再出现任何厂商品牌名；只在功能列表里保留 `.psd` 这一文件格式名

3. **新增 `docs/第三方许可.md`**
   - 列出 Apache-2.0 组件（Kotlin、coroutines、AndroidX、Compose）
   - 列出 16 款 OFL 1.1 字体及随包许可证位置 `assets/fonts/OFL-LICENSE.txt`
   - 说明不随包分发第三方 CMYK / 印刷色彩配置（运行时从用户文件解析）
   - 说明 `.psd` / `.psb` / `8BPS` 仅为文件格式名与字节标识

4. **LICENSE 署名统一**：`Copyright (c) 2025 Palette contributors` → `Copyright (c) 2025-2026 Reveal contributors`

5. **`.gitignore` 排除历史快照**：新增 `_snapshots/`，并 `git rm -r --cached _snapshots` 把已暂存的 270 个文件移出版本库（本地文件未删除）

6. **proguard 包名修正**：`-keep class com.palette.editor.**` → `com.reveal.editor.**`（原规则因包名不符一直无效）

7. **源码注释里的品牌名清掉**
   - 按用户要求「不要任何和桌面修图软件有关的东西」，把 47 个 kt 文件里 270 行注释中的品牌缩写与全称统一改为「桌面端」，涉及文件见 `git diff --stat`
   - 顺手把内部常量 `PS_HDR_32` 改名 `HDR_CM_32`（纯标识符，不影响行为）
   - 保留不能改的两类：①MIME 类型串 `image/vnd.adobe.photoshop`（分享/另存为时系统按它识别文件）②文字层描述符键名 `/Photoshop`（格式规范固定字段，改了文字层就读不出来）
   - README、docs、UI 文案里已无任何品牌名；`.psd` / `.psb` / `8BPS` 只作为文件格式名保留

8. **许可证改为 PolyForm Noncommercial 1.0.0**
   - 换证前的许可证允许任何人商用、闭源分发；按用户要求换成「源码公开、禁止商业使用」
   - 正文取自官方仓库 `polyformproject/polyform-licenses` 的 `PolyForm-Noncommercial-1.0.0.md`（sha 5ecc88cfc4b1cff608ed640efe913c9dd97935c3），仅补 Required Notice 行署名
   - README「许可」节、`docs/第三方许可.md` 开头同步改写
   - 同时清理 `docs/` 下 94 份文档、README 里的同类品牌字样（共 441 行）；MIME 串 `image/vnd.adobe.photoshop`、文字层键名 `/Photoshop`、外部引用链接原样保留
   - 说明：该许可证不是 OSI 开源许可（source-available），也不能阻止反编译，但明确禁止商用
