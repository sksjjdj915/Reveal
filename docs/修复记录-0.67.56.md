# 修复记录 0.67.56

## 0.67.55 的日志说明了什么

```
大笔刷一笔：移动 1 次 909ms / 盖章 430ms / 预览拷贝 550ms
小笔刷：    移动 7 次 145ms / 盖章  93ms / 预览拷贝  26ms
```

小笔刷已经正常（≈20ms 一次移动）。大笔刷还有两个独立的坑：

1. **预览拷贝 550ms**：上一版按「视口 ∩ 笔迹」做预览块，可缩到适应屏幕时，视口在**文档坐标**里依然覆盖 3600×2400 —— 也就是 34MB，裁剪等于没裁。
2. **盖章 430ms**：225 号笔刷按 9% 间距，一段仍要盖 3~4 下，每下往 50MB 缓冲里画一趟。

## 这一版

**预览块改成固定大小的窗口（1024×1024），跟着笔尖走。**
- 笔尖在窗口内 → 只拷这一小段 dab（几毫秒）；
- 笔尖走出窗口 → 把窗口挪到笔尖附近，整块重拷一次（1M 像素 ≈ 4MB，几毫秒）。
- 上限是死的：无论画布 4096 还是 8192、无论一笔拖多远，预览块永远是 1024²（4MB），不再随范围膨胀。

**大图笔头间距按桌面端的常规改成 22%**（上一版 9% 仍偏密）。
一段从 3~4 下减到 1~2 下；软边笔头本来就重叠，视感不变。

## 怎么验
1. 4096 上**一笔拖遍整张画布**（最狠）→ 应该一直跟手，走到哪画到哪，不该中途顿住。
2. **大笔刷 200 以上**快速划长线 → 线条连续，不能看出一个个圆点。
3. 日志里 `盖章`、`预览拷贝` 两数：大笔刷下应该都在几十毫秒内（原来 430 / 550）。
4. 顺手确认小笔刷没退化（原来已经是 20ms 一次移动）。
