# 0.74.22 子工具目标 ④⑤：极坐标 / 波纹

## ④ 极坐标（`FilterFx.polarAt`）
**文献**：极坐标与笛卡尔坐标的互换（`x = cx + r·cosθ`、`y = cy + r·sinθ`），对应桌面端的「平面坐标到极坐标 / 极坐标到平面坐标」两个方向。
**补的参数**
| 参数 | 范围 | 说明 |
|---|---|---|
| 方向 | 0 平面→极坐标 / 1 极坐标→平面 | 同桌面端的两项 |
| 中心 X % / 中心 Y % | 0~100 | 卷起来的圆心（桌面端固定在画面中心） |
| 半径 % | 10~200 | 卷成多大的圆；小于 100 只卷中间一块 |

## ⑤ 波纹（`FilterFx.rippleAt`）
**文献**：正弦位移场——`offset = A·sin(2π·y/λ + φ)`，是桌面端「波纹」和多数水面波纹 shader 的共同模型；「大小」就是波长 λ，「数量」就是振幅 A。
**补的参数**
| 参数 | 范围 | 说明 |
|---|---|---|
| 数量（振幅） | 1~120 | 推挤幅度 |
| 大小（波长） | 4~400 | 波峰间距 |
| 方向 | 0 水平 / 1 垂直 / 2 两者 | 桌面端没有方向，这里补上 |
| 相位 % | 0~100 | 推动波形平移（做动画/对位用） |

## 过程记录（踩坑）
- 批量脚本先写了函数、再改 spec，中间 spec 文本不匹配导致退出，但函数已落盘 → 重跑后出现 `Conflicting overloads`（同名函数两份）。修法是写了个按函数块去重的脚本删掉后一份。教训：**改文件要一次性成功再写盘，分两个文件时必须先校验两边 anchor 都存在**。
