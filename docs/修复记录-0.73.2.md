# 0.73.2 加选减选高亮修好 + 色阶/曲线接上

## 一、加选/减选按钮没反应（功能却生效）
- 根因：`SketchView.selectOp` 是普通 `var`，不是 Compose 状态；chip 的选中态每次都从它读，读到的变化不会触发重组，所以按钮不会亮。
- 改法：`CutDock` 里加本地 `var selOp by remember { mutableStateOf(...) }`，点 chip 先改本地状态（触发重组、立刻高亮），再写给 `sketch.selectOp`。

## 二、色阶（真面板）
五个参数：输入黑场 0~254、伽马 0.1~3、输入白场 1~255、输出黑场、输出白场；「应用」用 `Levels.Params` + `Levels.apply` 走 `applyFilterToActive`（可撤销），「归零」一键复位。

## 三、曲线（简化面板）
三个控制点：阴影 / 中间调 / 高光（-50~50），拼成 5 点曲线 `(0,0) (0.25,0.25+s) (0.5,0.5+m) (0.75,0.75+h) (1,1)`，交给 `Curves.apply`。没有画曲线的可视化控件，但参数可调、能叠出 S 形和提亮压暗。

## 四、没做
1. 曲线没有「拖点」的图形界面（要画曲线控件，工作量大）。
2. 文字参数、液化变形、裁剪/图像大小、AI 仍未接。
