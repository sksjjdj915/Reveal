# 0.67.85 修复记录（2026-11-08）

## 1. 裁剪现在能选「范围」
底部裁剪条多了一个可点的按钮：

- `范围：整张`（默认）—— 所有图层一起裁，画布尺寸跟着裁剪框变（和桌面端一样）
- `范围：当前层` —— **只裁当前选中的那一层**，其它图层一个像素不动，画布尺寸也不变

点一下就能切换，切到「当前层」时字变蓝。
配套修正：整张裁剪前，先把「尺寸和画布不一致的图层」补齐到画布大小（贴左上、透明补满），
避免因为尺寸不够被跳过，出现「有的层裁了、有的没裁」。

## 2. 裁剪后的尺寸一定是最新、且和图一致
- 「完成」之后不再用活动层去算尺寸，而是用 `docPixelWidth()/docPixelHeight()`（第一个有像素的层）；
- toast 直接报结果：`已裁剪整张：1080 × 1064` 或 `已裁剪当前图层（画布尺寸不变）`；
- 裁剪框没动就点完成时，会明确说 `裁剪框没变，什么都没裁`，不再静默。

## 3. 之前那个 1080 × 1064 是怎么来的
那是裁剪框的实际高度（你拖到的地方就是 1064），不是算错——
只是原来 toast 只说「已裁剪」、右上角又不刷新，所以看不出「裁成了多少」。
现在右上角和 toast 都会显示同一个数字，能直接对照。

## 怎么验
1. 两个图层的图 → 变换 → 裁剪 → 点成「范围：当前层」→ 只拖小一点 → 完成：
   只有当前层变了，另一层和画布尺寸都没变。
2. 再点成「范围：整张」→ 拖 → 完成：所有层一起裁，右上角和 toast 都显示新尺寸。
3. 进裁剪什么都不拖，直接点完成：应该提示「裁剪框没变，什么都没裁」。
