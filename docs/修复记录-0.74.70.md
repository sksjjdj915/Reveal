# 0.74.70 需求③：光晕工作室（用基础光元素自由组合）

## 入口
调色模式 → 「滤镜」→ 子滤镜行最左边「**光晕工作室**」。

## 五个基础光元素（参考主流光效插件的构成）
| 元素 | 形态 |
|---|---|
| 辉光 | 中心光核，三次方衰减 |
| 光环 | 同心圆环（半径 0.75×大小，带宽 0.12×大小） |
| 鬼影 | 沿光轴反向排布的 5 个小圆（尺寸随序号变化） |
| 星芒 | 十字 + 对角共 4~6 条细光条（宽 0.035×大小） |
| 拉丝 | 横向长光条（长 2.6×大小，宽 0.05×大小） |

## 每个元素独立参数
位置 X / 位置 Y（0~100% 画面）、大小（1~90% 短边）、亮度（0~100%）、色温（中性/暖/冷）。

## 组合与复用
- 「+ 辉光 / + 光环 …」任意叠加，列表里点哪条就调哪条，可单条删除；
- 「预览」用 900px 底图后台算一版（不会卡参数拖动），「应用」落层；
- 「存为预设」把当前组合存进 `filesDir/flare_presets.json`，下方预设列表点名字即恢复整组元素，右侧「删」移除。

## 没做
1. 元素只能调位置/大小/亮度/色温，不能给单个元素加旋转角度或长宽比；
2. 没有「光轴方向」整体参数（鬼影固定沿画面中心反向排）；
3. 工作室里没有画面上的可拖动手柄（要改位置只能拉滑块）；
4. 预设没有缩略图预览。
