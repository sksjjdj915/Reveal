# 修复记录 0.67.58

两个问题，分别是一个真 bug、一个设计错。

## 1. 画完笔迹消失（真 bug）

大图落笔时图层**本来就不写**（为了不每帧重传 50MB 纹理），像素只在收笔那一刻才合成进图层。
但收笔后我漏了一步：没有告诉画面「这块像素变了」。合成缓存还拿着旧画面，
于是刚画的东西在收笔的瞬间就被旧缓存盖掉 —— 看起来就是「画完什么都没留」。

修法：收笔合成完立刻把该区域标脏（`compositePixelStamp++` + `markDocDirty(笔迹矩形)`），
缓存下一帧按新像素重建。取消笔画那条路本来就有这一步，收笔这条路是漏的。

## 2. 预览锯齿（设计错）

上一版的预览是「从 4096 的笔迹缓冲里抠一小块，缩到屏幕上贴上去」。
放大着画时它是 1:1，没问题；但**缩着画（比如刚打开时适应屏幕）等于把线缩到 1/4 甚至 1/10**，
双线性采样硬缩细线就是一圈台阶 —— 这就是锯齿。

修法：**预览不再从缓冲里抠，而是同一个笔头按屏幕分辨率再盖一遍。**
- 预览图直接带「文档→屏幕」矩阵，每个印子按文档坐标盖进去，形状/角度/抖动完全一致；
- 边缘是在**屏幕分辨率**上重新画出来的，所以任何缩放倍率都不会糊、不会锯齿；
- 预览图始终是屏幕大小（约 4MB），不随笔迹长度增长，也不再有「抠块—拷贝」那几十毫秒。

顺带：这条预览路径只给画笔用。图章/修复的笔头是直接从原图取块画的，走预览会缺内容，仍走原来的逐段合成。

## 自检
1. 收笔顺序：先合成进图层 → 标脏 → 再回收预览图（顺序反了会闪一下或留残影）。
2. 取消 / 切工具 / 离开页面：三条路径都清预览图和它的 Canvas。
3. 预览与缓冲的笔头参数完全同源（同一个 `stampAt` 调用），不存在「画的时候粗、松手变细」。
4. 非大图（<1200 万像素）、有选区、阿尔法锁定、非正常混合、带渐隐的画笔：都不启用预览路径。

## 怎么验
1. 4096 上画一笔，**松手后笔迹必须留着**，不能消失（这条是硬指标）。
2. 缩到「适应屏幕」直接画 → 线条边缘应该是平滑的，没有台阶。
3. 放大到 1:1 以上再画 → 同样顺滑，且跟手。
4. 画长线（横跨整张画布）→ 整条都在，不掉段。
5. 日志里 `盖章` 会比 0.67.57 略大一点（预览也盖一遍），但 `预览拷贝` 恒为 0。

## 已知取舍
预览多盖一遍笔头，`盖章` 会接近翻倍（几十毫秒级，仍在跟手范围内）；
换来的是任何倍率都不锯齿。如果你觉得还是偏慢，下一步可以让预览用「降一级的笔头」来盖。
