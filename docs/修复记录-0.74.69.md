# 0.74.69 需求②：区域范围补「反转 / 强度」

## 新增两个参数（`RegionSpec`）
| 参数 | 范围 | 作用 |
|---|---|---|
| 反转 | 开/关 | 范围**外**生效、范围**内**不生效（`invert`） |
| 强度 | 0~255 | 遮罩整体 alpha 系数（`opacity`）；128 就是「效果只做一半」 |

## 实现细节
- `regionMask()`：
  - 反转时先把整块画布铺成不透明，再用 `PorterDuff.Mode.DST_OUT` 把范围**挖掉**（比反过来画更省事，也保留了羽化）；
  - 强度 < 255 时，把遮罩再按 `alpha=强度` 画一遍到新位图（不改变形状，只整体减淡）。
- 面板（`RegionDock`）在「羽化」下面加了「强度」滑块和「反转：开/关」胶囊，改动即时刷新画布上的描边与预览裁切。
- `RegionStore` 的 `regions.json` 同步存 `invert` / `opacity`，重开工程能恢复。

## 现在的组合能力
- 只改选中范围 → 默认；
- 只改「范围外」→ 反转；
- 效果减半 → 强度 128；
- 柔边 → 羽化；
- 再叠加选区和色带抠图都互不冲突（遮罩是相乘关系）。

## 没做
1. 强度只作用于**遮罩**，不作用于「已应用过的效果」（不是调整图层，改强度不会重算历史效果）；
2. 反转时描边仍然画在范围边界上（视觉上没标出「外面才是生效区」）。
0.74.x 全部只编译验证，无真机验收。
