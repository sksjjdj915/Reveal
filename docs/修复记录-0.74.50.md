# 0.74.50 目标⑧：木刻补边缘简化度 / 边缘逼真度

## 文献依据
桌面端「木刻」三参数：**色阶数 2~8、边缘简化度 0~10、边缘逼真度 1~3**。
- 简化度越大 → 边缘越圆滑、碎边越少（概括成木刻版画的粗线）；
- 逼真度越大 → 边缘越贴合原图细节（1 最概括、3 最精确）。

## 旧实现
`cutout(src, levels, edge: Boolean)`：只有「色阶」和「描边开/关」两项，边缘阈值写死 42，没有平滑也没有精度分级。

## 新实现 `FilterFx.cutoutAt(src, levels, simplify, fidelity)`
1. Sobel（`|gx|+|gy|`）得到边缘强度图；
2. **简化度**：边缘图做 `simplify` 次 3×3 均值 → 越大越平滑、碎边越少；
3. **逼真度**：阈值分三档（1→24、2→34、3→44），逼真度越高阈值越严 → 边更细、更贴合原图；
4. 亮度按 `levels` 分档，边缘处压成纯黑，其余为对应灰阶。
全部行区间并行。

## 没做
桌面端的木刻会把边缘「沿着色块轮廓」走，我们是直接对边缘图阈值，所以细节区（如草地、毛发）会比桌面端碎一些；要完全对齐得先做区域分割（meanshift）。0.74.x 全部只编译验证，无真机验收。
