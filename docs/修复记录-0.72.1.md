# 0.72.1 启动空画布 / 删层不刷新 / 选区参数补齐

1. **打开软件不再有画布**：启动时不再 `newDocument(1080,1620)`，画布区先空着（只有灰工作区），导入图片时按图片真实尺寸 `newDocument(宽, 高)` 再把这图加成图层，所以导入后直接就是图片本身。
2. **删图层后列表不刷新**：`layerTick` 只被 lambda 捕获、没参与重组，`NewLayerSheet` 收不到变化（内容删了、列表还在）。改成 `key(layerTick) { NewLayerSheet(...) }`，每次 tick 强制重建面板。
3. **选区参数补齐**：原来只有「羽化应用/全选/反选/取消/到新层」，现在两排共十个：
   - 第一排：羽化 / 平滑 / 扩张 / 收缩 / 边界（都走 `modifySelection(kind, px)`，kind 0~4）
   - 第二排：全选 / 反选 / 取消 / 到新层 / 选主体
   仍共用同一个「羽化」数值滑块（0~50）。

没做：存选区 / 载选区（SketchView 没有这两个 API，需要先加通道存储）；选区「方式」切换仍靠底部工具行。
