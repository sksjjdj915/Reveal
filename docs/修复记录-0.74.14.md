# 0.74.14 黑白 / 色调分离提速 + 渐变映射「强度」

## 一、黑白：改颜色矩阵（GPU）
黑白本质是 `gray = (r*wr + g*wg + b*wb) / (wr+wg+wb)`，是**线性加权**，可以写成 4×5 颜色矩阵（三行都是同一组权重），用 `ColorMatrixColorFilter` 一次画完。原来逐像素 + `Color.red/green/blue` 三个 JNI 调用，拖动权重时明显掉帧。

## 二、色调分离：改 256 项 1D 查表
量化公式 `q(v) = round(v/step)*step` 每像素要算三次除法，改成先建 256 项表，然后每像素三次查表；同时跳过 alpha=0 的像素。规律是「每通道独立、同一张表」，不需要 3D LUT。

## 三、渐变映射：加「强度」
之前问过你桌面端的口径——**桌面端的渐变映射面板本体确实没有强度**（强度在「渐变填充」图层里）。但你要的是这个效果，所以这次按手机端调色常见的做法加上：
- 面板里新增「强度 0~100%」一行；
- 强度 <100 时，把映射结果和原图按比例混合（`out = orig + (mapped - orig) * t`），100 就是完全映射；
- 预览是常驻泵，拖强度能实时看到变化；「确定」落盘时同样带上强度。
