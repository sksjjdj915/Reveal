# 0.68.21 修复记录

## 一、「没有只画范围」

- 0.68.20 里这个 chip 确实写进去了，但被放在第一行最右边：
  `线性 / 径向 / 色块 → 色块 / 到透明 / 反向 / 只画范围` —— 一行装不下，最右边的 chip 被挤出屏幕，
  所以看起来「没有」。（和之前「应用」被挤成一根竖条是同一类问题。）
- 改法：第一行只留 `线性 / 径向 / 两个色块 / 到透明`；
  新增第二行专门放开关：`反向颜色` / `只画范围`。
  现在是四行：模式+色块 / 开关 / 平滑度 / 缩放 + 提示与取消应用。

## 二、顺带
- 「反向」改名成「反向颜色」，和「只画范围」并列，避免两个两字 chip 挤在一起看不清。
- 其它逻辑没动（0.68.20 的 `clipLinearOutside`、参数回填都还在）。

## 三、这次没做
1. 「只画范围」仍只对线性生效。
2. 抹边界是 CPU 上一遍全图（w×h），超大画布会慢。
3. 平滑度只作用 8 位主图。
4. 没跑模拟器。

## 四、怎么验
1. 选渐变 → 参数条应该有四行，第二行写着「反向颜色」「只画范围」。
2. 点「只画范围」→ 变成高亮（蓝字）。
3. 从中间往上拉白色→透明 → 下方不再被白色铺满，只有上方淡出。
4. 再点一次关掉 → 恢复「下方被铺满」的旧行为。
