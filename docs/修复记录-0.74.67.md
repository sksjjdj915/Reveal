# 0.74.67 目标⑨：镜头光晕补参数 + 预设

## 参考（常见光晕插件 的参数分组）
光晕一般由「中央辉光 + 光环 + 沿光轴排布的鬼影」三部分组成，可调项是：光斑大小、亮度、光环大小、鬼影数量/强度、色温。我们原来只有「亮度/镜头类型/中心/半径」5 项，且光环大小、鬼影强度写死。

## 新增参数（`FilterFx.lensFlareAt`）
| 参数 | 范围 | 说明 |
|---|---|---|
| 亮度 | 0~100 | 原有 |
| 镜头 | 0 变焦 / 1 35mm / 2 105mm / 3 电影 | 决定鬼影数量（6/3/2/8） |
| 中心 X / Y % | 0~100 | 光源位置（可配合「点画面定光源」胶囊） |
| 光斑半径 % | 10~200 | 中央辉光与整体尺度 |
| **鬼影强度** | 0~100 | 0 只留光斑与光环，100 鬼影明显 |
| **光环大小** | 0~100 | 光环半径 = maxR×(0.15 + 0.9×值) |
| **色温** | 0 中性 / 1 暖 / 2 冷 | 输出 R/G/B 加色各自乘系数 |

## 预设（8 个，面板顶部一排胶囊，点一下整组套用）
标准太阳 / 电影暖斑 / 冷调科技 / 单点星芒 / 环形光晕 / 低调微光 / 横向拉丝 / 柔焦暖阳
每个预设就是「8 个旋钮的一组值」，所以本质上就是「可自由组合」——调好之后的值就是一组自定义组合，只是暂不能命名保存。

## 没做
1. 预设不能**保存成自定义命名项**（没有「存为预设」按钮和持久化）；
2. 没有 桌面端 那种多光源叠加（现在一次只能一个光晕）；
3. 没有变形六角星芒（anamorphic streak）的独立形状。
0.74.x 全部只编译验证，无真机验收。
