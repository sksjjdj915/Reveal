# 0.74.25 子工具目标 ⑧：油画

## 文献 / 成熟算法
- 油画类滤镜的经典算法是 **Kuwahara（1976）**：对每个像素取邻域，按亮度分箱统计，取「出现最多的那一箱」的平均颜色 —— 结果天然保留笔触边缘、又抹掉细节。
- 桌面端在 CS5 之后把油画做成独立滤镜，参数表是：**画笔风格/缩放（笔触大小）、清洁度、硬毛刷细节、光照（角度 + 闪耀）**。

## 这次补的参数（`FilterFx.oilAt`）
| 参数 | 范围 | 对应桌面端 |
|---|---|---|
| 画笔大小 | 1~10 | 缩放（邻域半径） |
| 硬毛刷细节 | 4~48 | 硬毛刷细节（亮度分箱数，越大笔触越细） |
| 清洁度 | 0~10 | 清洁度（0 保留混合感，10 只取众数色） |
| 光照角度 | −180~180° | 光照方向 |
| 光照强度 | 0~100 | 光照强弱（按亮度梯度补高光，模拟颜料凸起受光） |

## 没做
晶格化的格子形状、点状化的点半径/形状；镜头光晕/挤压/球面化/旋转扭曲的「点画面直接指定中心」手势；曲线吸管、液化/变形/图案图章、裁剪与画布大小、AI。0.74.x 全部只编译验证，无真机验收。
