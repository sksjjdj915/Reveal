# 0.69.15 界面改版 · 左栏滑入动效（收尾）

## 一、这次做了什么
1. 左侧工具栏切换模式时从「整列淡入」升级成「整列淡入 + 8dp 滑入归位」：
   - 透明度 0.3 → 1（220ms）；
   - 纵向位移 8dp → 0（260ms）；
   - 两条同时跑，都用 Material 3 强调缓动 `cubic-bezier(0.2,0,0,1)`。
   切模式时左栏不再像被瞬间替换，而像「新的一列工具推上来」。

## 二、这次没做
1. 仍是整列动，不是逐项错开（staggered）。逐项错开要给每个 `RailItem` 单独持有动画状态，得改它的签名并动到十几处调用点，收益不大，暂时不做。
2. 全部改动仍只有「编译通过 + 代码接线核对」这一层证据，**没有真机/模拟器验收**（你说过不用虚拟机）。

## 三、怎么验
1. 顶部在「抠图 / 调色 / 绘制」之间来回切 → 左栏工具应该先略微下沉、再淡入并上移到位。
2. 只是切换而画布不动：画布、图层、缩放位置都不应该被重置。
