# 0.68.9 图层面板多选

版本：0.68.9（code 367）
日期：2026-11-09

## 做了什么

图层面板原来只能单选（点哪层切哪层），这一版加了一整套多选。

1. 图层面板标题行加 **「多选」** 按钮，点一下进多选，再点变「取消」退出。
2. 进多选后每行左边出现 **☐ / ☑**，点行是勾选，**不会切活动层**；勾中的行底色变蓝灰。
3. 列表下面浮出批量操作条（两行）：
   - 已选 N ｜ 全选 ｜ 反选 ｜ 删除 ｜ 成组 ｜ 合并
   - 显示 ｜ 隐藏 ｜ 上移 ｜ 下移 ｜ 退出多选
4. 批量删除、成组、合并、上下移都是 **一步撤销**（左右撤销能整批还原）。

## 怎么改的

- `SketchView.kt`
  - `Stroke` 新增 `orderBefore` / `orderAfter`（图层表前后顺序，只存引用），`isStruct()` 把它们也算结构步骤；`strokeBytes()` 把「只被撤销栈引用着的旧层」的位图计入预算，防止批量删太多把内存吃掉。
  - `undo()` / `redo()` 开头先按 `orderBefore` / `orderAfter` 整表还原，再走原来的像素补丁逻辑。
  - 新增 `pushLayerOrder()`、`deleteLayersAt()`、`groupLayersAt()`、`mergeLayersAt()`、`setLayersVisibleAt()`、`moveLayersAt()`。批量移动按「连续选中段整体挪一格」，避免段内互相踩。
- `Dialogs.kt`（`LayerPanel`）：加多选状态、行勾选、批量操作条；`onBatch(action, indices)` 一个新回调取代一堆参数。
- `LayerPanelHost.kt`：把 `onBatch` 分派到上面六个函数，失败给中文提示（「至少要勾两层才能合并」等）。

## 怎么验

1. 图层面板 → 点「多选」→ 每行左边出现 ☐。
2. 勾两层 → 点「合并」→ 两层变一层「合并 2 层」→ 按撤销 → 两层回来了。
3. 勾三层 → 点「成组」→ 生成「组 N」把三层包住 → 按撤销 → 组没了，三层原位。
4. 勾两层 → 点「删除」→ 两层消失 → 按撤销 → 两层都回来（以前删层撤不回来）。
5. 勾两层 → 「隐藏」→ 两层一起不显示；再「显示」→ 一起回来。
6. 勾两层 → 「上移」→ 这两层一起往上走一格，相对顺序不变。
7. 多选状态下点行只勾选，右边「编辑中」不会跟着跳。

## 没做的

- 批量操作不进「部分撤销」：一次操作算一步，没有更细粒度。
- 合并按正常叠加与各自不透明度算，混合模式没有逐个参与合成。
- 成组不会自动折叠，也不会自动命名成「组 1」以外的名字。
- 多选状态不进工程文件，关掉面板就退出多选。
