# 素材来源说明

这份文档记录 App 里每一类视觉素材从哪来、什么许可，方便以后自查和对外说明。

## 1. 启动图标

- 内容：纯黑方块（`#000000`），无图案、无文字。
- 生成方式：本地脚本生成（`E:\deepseek\_mk_black_icon.py`，Pillow 画纯色 PNG），
  2026-11-11 替换旧图标。
- 旧图标（已删除）：一张蓝发动漫女孩插画，生成来源不可考，因与既有角色形象存在
  混淆风险，发布前整体替换为纯色图标。
- 自适应图标：`res/mipmap-anydpi-v26/ic_launcher.xml`，背景色 `@color/ic_launcher_background`
  = `#FF000000`，前景为全透明 PNG，效果就是一枚纯黑图标。
- 各密度：mdpi 48 / hdpi 72 / xhdpi 96 / xxhdpi 144 / xxxhdpi 192（legacy），
  前景 mdpi 108 / hdpi 162 / xhdpi 216 / xxhdpi 324 / xxxhdpi 432。

## 2. 界面图标

全部来自 `androidx.compose.material:material-icons-extended`（Material Icons），
许可 Apache License 2.0，未修改图标形状，只做尺寸与颜色适配。
工程里没有自制的矢量图、没有从其它 App 截取或描摹的图标。

## 3. 字体

`app/src/main/assets/fonts/` 下 16 款，全部来自 Google Fonts，SIL Open Font License 1.1，
每款均保留原字体名（Reserved Font Name 不变）、未做字形修改。
许可证全文有两份：`assets/fonts/OFL-LICENSE.txt`（OFL 1.1 通用全文）＋ 16 款字体各自目录里的
逐款 OFL 许可文件。

字体是**单独授权**的，不受本工程 PolyForm Noncommercial 限制：任何人可以脱离本工程、
单独把字体用于商业项目，这个权利不因本工程许可而改变。

## 4. 色彩配置

只内嵌一份系统标准 sRGB ICC 配置（见 `docs/第三方许可.md` 第 3 节）。
CMYK / 印刷配置不随包分发，从用户打开的文件里运行时读取。

## 5. 画笔纹理 / LUT / 图案 / 光效预置

工程不随包分发任何外部纹理、LUT 表、图案或光效素材。
画笔纹理由用户在 App 内导入；LUT 表在运行时按公式生成；光效（镜头光晕、光环、鬼影、
星芒等）全部按数学公式逐像素算出，没有使用任何软件厂商的预设文件。

## 6. 测试素材

测试用的分层图像样本由本地脚本（`E:\deepseek\_mkpsd.py`，psd_tools + Pillow）生成，
放在桌面 `Reveal-测试PSD\`，不进仓库、不进 APK。
psd_tools 与 Pillow 只装在开发机上用来造样本，不是本工程的依赖、不随包分发。

## 7. 代码

全部为本工程自写。PSD/PSB 读写按公开的分层图像文件格式规范实现，未使用第三方解析库。
算法出处写在对应源文件的注释里（如修复画笔的调和插值、无缝克隆、Sobel 边缘等）。
