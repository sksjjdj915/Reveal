# 0.67.81 修复记录（2026-11-08）

基线：0.67.73（code 338，回档后的版本）。这一版只修 A 段实测暴露的五条，不动画笔。

## 1. 图像大小 / 画布大小：不再误报「宽高至少 16 像素」

`ui\SizeDialogs.kt` 重写：

- 新增「保持比例」开关，默认**开**：改宽自动按原比例算高，改高自动算宽；
- **只填一边也能确定**：另一边按原比例补齐（原图比例取自打开对话框时的宽高）；
- 报错分开说：`宽度不能小于 16 像素（现在填的是 N）` / `高度不能小于 16 像素（现在填的是 N）` / `宽度和高度至少要填一个（另一个会按原比例自动补上）`。

## 2. 改完尺寸，右上角分辨率立刻刷新

`ui\EditorScreen.kt`：`resizeCanvas` / `resizeDocument` 成功回调里补 `docInfo = "$w × $h"`（原来只在打开文档时赋一次）。

## 3. 变换的「应用 / 取消」永远看得见

`ui\EditorScreen.kt`：删掉原来浮在画布底部的那条（会被底部参数条压住），改成**变换激活时直接接管底部参数区**——和「选择并遮住」同一个位置：

- 左边两行字：第一行「自由变换 / 透视变换」，第二行这一模式的拖拽说明；
- 右边按钮：`切自由/切透视` →（透视时多一个）`复位` → `取消` → `应用`；
- 应用失败（没拖过）时提示「这次没有可以应用的变换（先拖角或拖边）」。

## 4. 四角行为固定 + 模式一眼可见

- 每次进变换都强制回到**自由变换**（`SketchView.beginTransform()` 里 `tfPersp = false`，`EditorScreen` 侧 `onTransformChanged(true)` 时 `perspMode = false`）；
- 画布上档框上方常驻一行小字：`自由变换 · 拖角等比 / 拖边拉伸 · 双指缩放旋转` 或 `透视变换 · 拖四角各自移动 · 三指缩画布`（金/蓝色区分）。

## 5. 拖四角「有时灵有时不灵」

- 命中半径 34 → **44** 像素（自由与透视都改），四角手柄从 9 画到 15、边中点 7 → 11，视觉和判定对得上；
- `ACTION_MOVE` 里补做命中：`tfCorner < 0 && tfMode == 0` 时用当前点再判一次（原来是「按下那一下没点中就再也不响应」，被双指打断后尤其明显）；透视模式同理（`tfMode != 6 && != 7` 时补抓）。

## 怎么验

1. 画布大小：只填宽 1080、高留空 → 确定，应该成功且高自动变成 1620；把宽填 8 → 提示「宽度不能小于 16 像素（现在填的是 8）」。
2. 改完尺寸，右上角立刻显示新尺寸，不用重新打开。
3. 分类 → 变换 → 变换：底部出现「自由变换 / 切透视 / 取消 / 应用」，点应用能落下。
4. 拖四角：每次都响应，不用抬起重按；四角方块明显比原来大。
5. 点「切透视」→ 标题变「透视变换」、画布上小字跟着变；再点「切自由」回来。

## 没做

- 变换没有做「回车/双击确认」的手势，只有底部按钮；
- 组图层/无像素图层进变换仍然是静默不动（这次的提示只加在「应用失败」上，进不去时还没有提示）——下一版补。
