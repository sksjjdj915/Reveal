# 0.74.37 水彩方格 / 画面来回闪

## 一、水彩的「一格一格」
- 原因：水彩的核心是 `median()`，而中值是**方形窗口**的众数/中位结果；细节拉到 9 时半径只有 2，方窗边界在同一亮度区里会连成网格，看起来就是一格一格。
- 改法：①中值半径上限从 4 放宽到 6（细节越小、色块越平）；②中值之后补一次 1px 高斯，把方窗的格边抹平（水彩本来就不该有硬格）。

## 二、画面来回闪（含切到别的滤镜后还在闪）
- 原因是 0.74.36 引入的「渐进清晰」会**振荡**：900 算得慢 → 降到 640 → 停手 0.5 秒 → 升回 900 → 又慢 → 再降 640 …… 每 0.5 秒翻一次，表现就是一直闪。
- 改法：升回 900 **每个面板只做一次**（`hiResDone` 标记）。之后不再降档，画面稳定在一张清晰图上。
- 另外「切到别的滤镜还在闪」是同一原因：旧面板的泵在切走前正好处于升降循环里。现在循环条件被 `hiResDone` 掐断，切走后 `DisposableEffect` 清预览即可。

## 三、没做
没有做「不同滤镜各自记住上次的预览档位」；曲线吸管、液化/变形/图案图章、裁剪与画布大小、AI 仍未做。0.74.x 全部只编译验证，无真机验收。
