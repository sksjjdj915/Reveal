# 0.74.38 水彩重做（去方格、不糊）+ 重滤镜改为「停手才出预览」

## 一、水彩换底层算法：中值 → 表面模糊
- 之前的方格根源是 `median()` 的**方形窗口**：同一亮度区里方窗边界连成网格，加 1px 高斯只能把格子抹成模糊块，结果「又方又糊」。
- 现在底层换成 `surfaceBlur`（按亮度差加权的选择性平滑）：平坦区自然连成水渍块、边缘不被抹掉，**既没有方格也不会整体发糊**。
- 半径由「画笔细节」反推（细节 10 → r=1，细节 0 → r=5）；阴影（边缘压暗）从 0.6 提到 0.9 倍权重，笔痕更明显；纸纹颗粒从 1.6 降到 1.3，减少脏感。

## 二、重滤镜改成「停手才出预览」
按你说的「卡就卡点吧，参数条停了画面变化就行」：
- 重滤镜清单（油画 / 水彩 / 中间值 / 蒙尘划痕 / 表面模糊 / 减少杂色 / 智能锐化 / USM / 高反差 / 镜头光晕 / 木刻）在拖动过程中**先不算**；
- 手指停 **220ms** 后出第一帧，之后继续按原逻辑（快的话实时，慢的话降档）。
- 轻量滤镜（高斯/动感模糊/查找边缘/杂色等）保持实时预览。

## 三、没做
重滤镜「停手 220ms」是全局常量，没有让用户可调；曲线吸管、液化/变形/图案图章、裁剪与画布大小、AI 仍未做。0.74.x 全部只编译验证，无真机验收。
