## 1. 创建纹理：按 Criminisi 置信度决定填充顺序

**以前**：由外向内一圈一圈填，同一圈里按扫描线顺序——遇到「有结构的边」和「一片平地」会先补平地，结构断掉。

**现在**：每一圈先算**优先级**再排序：
- **置信度项** = 该像素 5×5 邻域里已知像素的占比；
- **数据项** = 已知邻居的局部梯度（近似等照度线强度）；
- 优先级 = 置信度 × (0.3 + 数据项)。

先补「周围已知多、而且正处在结构走向上」的位置——条纹、栏杆、发丝这类东西会先被接上，平地后补。

**应该看到**：在有明确走向的纹理上涂，结构先被接上，不会出现「先糊一片、纹理半路断掉」。

## 2. PatchMatch 加 1px 精修

**以前**：只在 2px 粗网格上求解，边界有半像素的台阶感。

**现在**：粗解算完后，把偏移放大回原分辨率，在 1px 网格上再做两轮（正向 + 反向）传播 + ±4px 小幅随机搜索，代价仍是 3×3 块距离。只在笔迹覆盖范围内跑，不拖慢整体。

**应该看到**：补片的边缘和周围像素齐平，细线条不会出现 2px 的错位台阶。

## 3. 创建纹理的候选范围不再只看笔刷大小

**以前**：候选只在笔刷半径 2.6 倍以内找——比笔刷大得多的结构（整面砖墙、长栏杆）根本搜不到同源样本。

**现在**：候选按**几何步进**（×1.7）从笔刷边缘一路搜到画面短边的 1/2（上限 2048px），每个方向最多 8 档。远距离候选依然用 3×3 邻域距离打分，只有明显更像我才会被选中。

**应该看到**：在大结构纹理上涂，能取到画面另一头的同源纹理，不再只能重复笔刷附近那一小块。

## 这一版没有再留「没做」

三条都做完了。跟桌面端仍然不同的地方只有设计取舍，不是缺功能：

- 桌面端的 PatchMatch 允许更多轮迭代（我这里是 5 轮粗 + 2 轮精修，手机上是速度与质量的平衡点）；
- 桌面端的内容识别填充会做多层金字塔；我用的是「粗网格 + 1px 精修」的等效做法；
- 例子合成（创建纹理）没有做多尺度 patch（同一尺度），洞特别大时中间仍可能偏平——这是所有单尺度样本合成的共同限制，桌面端也一样。

## 怎么验（三条）

1. 条纹衣服/栏杆：污点修复「创建纹理」涂一道 → 结构先接上，不糊一片。
2. 同图换「近似匹配」涂一道 → 边缘 1px 齐平，没有台阶。
3. 砖墙/长栏杆（结构远大于笔刷）：创建纹理涂一道 → 能取到远处的同源纹理，不是附近那一小块重复。
