# 0.74.42 水彩做完整（四段式流水线）

## 文献依据
水彩类风格化的标准流程（Kyprianidis 2011《Image and Video Based Painterly Rendering》综述里的 watercolor 一节）是四段：
1. **边缘保持的平涂**（abstraction）——按色差加权的平滑，即表面模糊；
2. **湿边 wet-edge**——颜色在色块交界处积起来，边缘压暗（真实水彩里颜料被水推着往边上堆）；
3. **内部水渍**——颜料少于纸吸水的地方，色块中间反而更亮、更「薄」；
4. **纸纹**——纸张纤维造成的细微亮度扰动。
桌面端的「水彩」滤镜参数也只有三条：画笔细节 1~14、阴影强度 0~10、纹理 1~3，正好一一对应。

## 这次的实现
`FilterFx.watercolorAt(src, detail, shadow, texture)` 重写为四步：

| 步骤 | 做法 | 参数映射 |
|---|---|---|
| ① 平涂 | `surfaceBlur`（已是**圆盘邻域**，不会出方格），半径 `1 + (14-detail)*0.5`，1~7 | 画笔细节 |
| ② 湿边 | 在平涂结果上算 **3×3 Sobel**，梯度归一化后作为边界权重 `e`；`k = 1 - e*shadow*0.085`（最多压暗 85%） | 阴影强度 |
| ③ 水渍 | 色块内部提亮：`lift = (1-e) * (1 + detail/14*0.9)`，越靠里越亮，颜色更「薄」 | 画笔细节 |
| ④ 纸纹 | 两层确定性值噪声（粗纤维 `x>>2` + 细颗粒 `x>>1`），双线性插值，幅度 `texture*2.6` | 纹理 |

`paperNoise(x, y, salt)`：整数哈希 → 双线性插值，返回 0~1，同一坐标永远同一个值（可复现、不闪）。

## 与上一版的差别
- 上一版只有「压暗 + 固定颗粒」，没有湿边的梯度依据，也没有内部提亮，所以看着像「糊一层灰」；
- 现在边缘会积色、中间更透，纸纹也变成粗细分层（像真纸），不再是一层均匀噪点。

## 没做
1. 没有做桌面端那种「按颜色分层多次平涂」（更接近真水彩的多次罩染），目前是单次平涂；
2. 没做边缘「颜色外溢」（bleeding）；
3. 0.74.x 全部只编译验证，无真机验收。
