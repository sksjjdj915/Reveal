# 0.68.7 修复记录 · 形状参数按种类分开（矩形长宽 / 椭圆直径 / 直线长度角度）

用户 2026-11-09：「形状的参数应该不一样，矩形是长宽，点椭圆应该变成直径，还有圆形开关点一下就是标准圆形，不点就是随意椭圆，就是有关椭圆的参数，直线是直线的参数」

原来参数区不看种类，一律 `宽 / 高`，椭圆和直线都显示成「宽 / 高」，语义不对。

## 一、参数按种类显示（`ui\ShapePaths.kt`）

| 形状 | 显示的参数 |
| --- | --- |
| 矩形 | 长度、宽度 |
| 圆角矩形 | 长度、宽度、圆角半径 |
| 椭圆 | 横直径、纵直径 + `圆形：开/关` 芯片 |
| 直线 | 长度、角度（-180~180 度） |
| 多边形 | 长度、宽度（外接框）、边数 |
| 星形 | 长度、宽度、边数、星形内径 |
| 所有 | 线宽（0=跟笔刷） |

- 椭圆的「圆形」开关：开 → 横纵直径强制相等（改一个另一个跟着变），新画的椭圆也是正圆；关 → 自由椭圆，两个直径分别调。
- 直线的「角度」：以起点为锚点、长度不变，直接转过去；配合 0.68.6 的拖动吸附（靠近 0/45/90 自动吸）。
- 参数条改完立刻重画（沿用 0.68.2 的实时预览），松手 0.45 秒压成一步撤销。

## 二、数据与渲染（`ui\SketchView.kt`）

- `ShapeSpec` 新增 `var circle: Boolean = false`（椭圆专用），`copyOf()` 一并带上。
- `renderShapeInto()` 传 `sp.circle && sp.kind == 1` 给 `buildShapePathEx(..., equal, ...)`，所以切圆形开关立刻变正圆。
- 新增 `var shapeCircle: Boolean`（新画的椭圆默认是否正圆）、`var shapeLineAngle: Float`（「按尺寸生成」直线用的角度）。
- 拖动预览与提交的 equal 判断改为 `shapeSquare || (shapeKind == 1 && shapeCircle)`，两根手指的「正方形/正圆」手势仍然有效。
- `makeShapeAtSize()`：直线在角度非 0 时按角度生成（以画布中心为中点的定长线）；椭圆在 `shapeCircle` 开时生成正圆。

## 验法

1. 形状 → 矩形：参数是 `长度 / 宽度`，没有圆角、没有边数。
2. 换椭圆的芯片：参数变 `横直径 / 纵直径`，多出一个 `圆形：关`；点成开 → 画面变正圆，两个直径联动；关掉 → 又能拉成扁椭圆。
3. 换直线：参数变 `长度 / 角度（度）`；把角度填 90 → 变成竖线；填 45 → 斜线。
4. 选一个已经画好的形状层：参数条显示的是这一层真实的数字，改一下画面立刻跟着变；松手后按撤销能退回。
5. 「按尺寸生成」：矩形按长宽、直线按角度+长度、椭圆按直径（圆形开着就是正圆）。

## 没做的

- 参数区没有 X / Y 位置输入（只能拖）。
- 椭圆没有了「旋转角度」参数，斜椭圆只能靠变换工具转（转完参数条只显示外接宽高）。
- 直线「长度/角度」改的是以起点为锚点的那一端，不能选锚哪一头。
