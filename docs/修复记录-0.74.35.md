# 0.74.35 补齐最后三个滤镜的并行

## 已接
- **添加杂色**：原来用共享一个 `Random` 顺序遍历所有像素（既慢、又没法并行）。现在按行分块并行，每行用 `seed*31+y` 独立播种——**同 seed 同图必得同一结果**（可复现），同时没有共享 RNG 的数据竞争。
- **蒙尘与划痕**：先算中值图（本身已并行）再逐像素比较，比较这段按行区间并行。
- **减少杂色**：它本身就是转调 `surfaceBlur(半径, 阈值)`，而 `surfaceBlur` 已并行，所以这一个不需要额外改。

## 现在的整体状态
预览链路三层：
1. 常驻泵（只算最新快照，`delay 20ms`，天然丢过期帧）；
2. 自适应预览分辨率（算得慢就 900→640→480；「应用」始终全分辨率）；
3. 行区间并行（`Parallel.chunks`，核数线程池）+ 个别算法本身的常数化（动感模糊采样封顶 33）。

所有 30 个子滤镜里，除「查找边缘/浮雕/高反差/曝光」这类每像素 O(1) 的，其余重滤镜都已经是并行的了。

## 没做
`Parallel` 目前没有做「按设备负载动态调线程数」；曲线吸管、液化/变形/图案图章、裁剪与画布大小、AI 仍未做。0.74.x 全部只编译验证，无真机验收。
