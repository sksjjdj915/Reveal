# 0.71.7 画布随参数区伸缩 + 顶栏重排 + 文件入口

1. **参数区改成挤压画布**：参数区从「浮在画布上」改成画布下方的一行——有参数区时画布变小（固定成你截图里那个大小），再点一次同一个工具就收起，收起后画布回到满屏；点别的工具又会出来。
2. **顶栏重排**：左边 菜单 / ←撤销 / →重做（都是 36dp 圆角方块，浅灰底），右边 文件夹图标（导入导出）/ 蓝色「保存」/ 图层。
3. **文件入口**：点文件夹弹出小面板，里面先放 导入图片 / PSD、导出 PNG、导出 JPG、导出 PSD 四个入口（**目前只有界面，功能还没接**，面板底部有说明）。
4. **工程名**：不再占顶栏一整行，改成画布左上角一颗半透明白色小标签（和右上角分辨率标签同样式）。
5. **模式栏**：60dp 宽，收起箭头放进框里（不再贴屏幕边）；收起后只剩一颗贴边的圆角箭头（按你第一张图那样），点一下展开。

没做：导入导出只做了界面；模式栏收起状态不记忆；画布缩放手势沿用引擎原有的双指缩放。
