# 0.74.49 目标⑦：油画补画笔样式 + 光照闪耀

## 文献依据
桌面端「油画」参数表：**画笔样式、描边细节、清洁度、缩放、硬毛刷细节、光照（角度 + 闪耀）**。
底子是 Kuwahara（1976）分箱取众数；画笔样式决定笔触的**形状**（各向异性 / 稀疏），光照闪耀是**镜面项**（颜料反光）。

## 旧实现
`oilAt(src, brush, detail, cleanliness, lightAngle, lightStrength)`：5 个参数，笔尖固定圆形，光照只有「按梯度整体加亮」一种，没有镜面高光。

## 新增（现在 7 个参数）
| 参数 | 范围 | 作用 |
|---|---|---|
| 画笔样式 | 0 简单 / 1 轻描 / 2 湿润 / 3 干笔 / 4 浓重 | 0 圆笔尖；1/2 把采样点沿光方向拉长 2×/3×（长条笔触）；3 按确定性哈希留缝（枯笔）；4 半径 ×1.6（厚涂） |
| 光照闪耀 | 0~100 | 亮度梯度朝光的部分做平方衰减的镜面高光（`spec² × 210`），做出「油亮」反光 |

各向异性变换：把采样偏移 `(kx,ky)` 分解到「沿光方向 u / 垂直光方向 v」，`u×stretch`、`v/stretch`，再转回坐标——笔触变成拉长的椭圆，方向跟随光照角度。

## 没做
1. 桌面端的「画笔样式」有 5 种预设（简单/轻涂/轻描/湿涂/涂描），我们实现 0~4 五档但形状是参数化的（拉伸/稀疏），不是逐个复刻；
2. 没有做笔触方向的手动画笔角度（沿光照角度）；
3. 0.74.x 全部只编译验证，无真机验收。
