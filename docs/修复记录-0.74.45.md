# 0.74.45 目标③：彩色半调补四通道网角

## 文献依据
传统**半调网屏**（halftone screen）是印刷的成像原理：每个色版按各自的**网角**旋转方格网屏，网点面积与油墨量成正比，四种油墨（青/洋红/黄/黑）叠加还原颜色。桌面端的「彩色半调」参数就是「**最大半径 + 通道1~4 的网角**」，默认 **108 / 162 / 90 / 45 度**——四个角度必须错开，否则四色网屏会撞在一起产生龟纹（moiré）。

## 旧实现
`colorHalftone(src, cell)`：只有「网点」一个参数，而且网屏**不旋转**（全部 0 度），并且直接用 RGB 当三色版。结果就是三个同角度的黑白点阵叠在 RGB 上，看起来像马赛克加颗粒，不是半调。

## 新实现 `FilterFx.colorHalftone(src, maxRadius, a1, a2, a3, a4)`
| 参数 | 范围 | 说明 |
|---|---|---|
| 最大半径 | 2~60 | 网点最大半径，决定网屏粗细 |
| 网角 1（青） | 0~360° | 默认 108° |
| 网角 2（洋红） | 0~360° | 默认 162° |
| 网角 3（黄） | 0~360° | 默认 90° |
| 网角 4（黑） | 0~360° | 默认 45° |

算法：
1. RGB → **CMYK 油墨量**（C=1-R、M=1-G、Y=1-B、K=min(C,M,Y)）；
2. 每个色版用自己的角度旋转坐标系，取格心距离 `d`；
3. 点面积 ∝ 油墨量 ⇒ 半径 `r = 最大半径 × sqrt(油墨量)`，`d ≤ r` 判为着墨；
4. 四色叠加取各分量最大油墨，还原 RGB。
全程行区间并行。

## 没做
1. 没有做桌面端的「灰度半调」单色版本（我们固定 CMYK 四色）；
2. 网屏形状固定圆形点（桌面端也是圆点，这点一致）；
3. 0.74.x 全部只编译验证，无真机验收。
