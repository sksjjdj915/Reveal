# 0.68.6 修复记录 · 直线吸附（拉得出水平/垂直/45°）

用户 2026-11-09：「形状用手拉不出水平的直线」——手指拖直线永远差几度，画出来的分割线是歪的。

## 改法

`ui\SketchView.kt`

- 新增 `var shapeSnapAngle: Boolean = true`（默认开）与 `private var shapeSnapDeg: Float`（本次吸附的角度，-999 表示没吸）。
- 拖动分支（`ACTION_MOVE`，`tool == Tool.SHAPE`）里，当 `shapeKind == 2`（直线）且吸附开着时：
  - 用**屏幕坐标**算手指到起点的角度（视图只有缩放/平移，屏幕角 = 文档角）；
  - 取最近的 45° 整数倍，误差 ≤ 9° 就把终点投影到那条方向上（长度不变）；
  - 记下吸附角度。
  - 提交时 `commitShape()` 本来就用屏幕坐标重算落点，所以吸过的位置不会回弹。
- 画预览时（`drawShapePreview`）在终点旁边显示实际角度：吸住了写整数并变蓝（`0°` / `45°` / `90°`），没吸住显示实际角度、橙色。

`ui\ShapePaths.kt`

- 参数区新增芯片 `吸附 45°：开 / 关`（放在「新建图层」左边），关掉就是自由角度。

## 验法

1. 形状 → 直线 → 大致横着拖：**画出来是水平的 0°**，终点旁显示蓝色的 `0°`。
2. 大致竖着拖 → `90°` / `-90°`。
3. 斜着拖到接近 45° → 吸成 `45°`；偏得多（>9°）就不吸，显示橙色真实角度。
4. 点「吸附 45°：关」→ 再拖就是原来那样随意角度。
5. 画完的分割线用变换看，角度是整的。

## 没做的

- 只吸 45° 的整数倍，没有任意角度吸附，也没有「按住第二根手指锁角度」。
- 矩形/椭圆没做「拖成正方形/正圆」的吸附（那个仍要两根手指按住，容易误触）。
- 吸附阈值固定 9°，没做成可调参数。
