## 这一版做了什么（2 项）

### D1 双指平移惯性
- 以前：两指甩一下，手指抬起画面立刻定住，要「翻到画布另一头」得反复拖好几次。
- 现在：抬手后按最后的速度继续滑，每 16ms 衰减 10%，低于 40px/s 停住；手指一落下立即停止。
- 覆盖：只作用于双指缩放/平移手势（`applyTransform` 的质心速度），画笔不受影响。

### B5 羽化 / 扩张 / 收缩 改距离变换
- 以前：`Selection.feather` / `grow` / `shrink` 都是「盒式模糊 + 阈值化」的近似——
  半径一大就糊边，扩张收缩的拐角圆得不像真实膨胀/腐蚀。
- 现在：Felzenszwalb & Huttenlocher《Distance Transforms of Sampled Functions》(2012) 的有符号距离变换：
  内部为正、外部为负，再做 smoothstep 过渡。
  - 羽化 = `smoothstep((s+r)/2r)`，过渡平滑、边缘不发硬
  - 扩张 = `s >= -r`，收缩 = `s > r`（真膨胀/真腐蚀）
  - 复杂度与半径无关，100px 半径也不会变慢
- 同一套代码，1-06「修改选区」五项、选择并遮住面板都直接受益。

## 怎么验（3 条）

1. **惯性**：双指按住画布快速划一下就抬手 —— 画面应当继续滑行一段再慢慢停；手指再落下立刻停。
2. **羽化**：随便套一个矩形选区 → 修改选区 → 羽化拖到 40~80 → 反选后删掉/填色，边缘应是一段连续的软过渡，没有台阶、没有硬边。
3. **扩张/收缩**：套一个圆 → 收缩 30px，圆应变小但仍是圆形（拐角不会出现方块或凹陷）；再扩张 30px 应回到接近原来的大小。
