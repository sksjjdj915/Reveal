# 0.74.84 参数条问题 ③：色彩平衡「拖了没反应」的真因

## 真因（下标错位）
预览泵里把三组滑块塞进三个 `FloatArray` 时写成了：

```kotlin
floatArrayOf(all[0], all[3], all[6])   // 原写法
floatArrayOf(all[1], all[4], all[7])
floatArrayOf(all[2], all[5], all[8])
```

而 `all` 是 `cr(0..2) + mg(3..5) + yb(6..8)` 的顺序拼接。于是：
- 「青-红」那组拿到的是 `cr[0] / mg[0] / yb[0]`——三个通道的**阴影值**；
- 「洋红-绿」拿到三个通道的**中间调**，「黄-蓝」拿到三个通道的**高光**。

结果就是：你在「中间调」页拖「青-红」，被写进 `cr[1]`，但预览读的是 `all[1]`＝`mg[0]`……所以拖半天画面不动。

## 修法
改成各通道连续取：

```kotlin
floatArrayOf(all[0], all[1], all[2])   // cr
floatArrayOf(all[3], all[4], all[5])   // mg
floatArrayOf(all[6], all[7], all[8])   // yb
```

「应用」那条路本来就是 `r0/g0/b0` 各自 `toList()`，是对的，所以之前是「应用后有效、预览无效」——现在两边一致。

## 没做
自然饱和度卡顿、照片滤镜卡顿、渐变映射缺参数。0.74.x 仅编译验证，无真机验收。
