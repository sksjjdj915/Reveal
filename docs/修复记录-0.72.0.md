# 0.72.0 导入 / 导出 / 置入图片接通

1. **导入图片**：文件面板第一项，调系统相册选择器（`ActivityResultContracts.PickVisualMedia`），选完解码成 Bitmap 交给 `sketch.addImageLayer(bmp, "置入图片")`，新图层直接叠在最上面。
2. **置入图片**：图层面板标题行新增「置入图」按钮，走同一个选择器，效果同上（这就是旧界面「图层 → 置入图」那条路）。
3. **导出 PNG / 导出 JPG**：走系统「保存到」对话框（`CreateDocument`），确认后 `sketch.flatten()` 取合成图，交给 `ImageExporter.export(context, uri, bmp, ExportFormat.PNG/JPEG, 95)` 写文件，完成后 Toast 提示「已导出 PNG / JPG」，失败提示具体原因。
4. **导出 PSD / 导入 PSD**：面板里仍在，但点了只提示「PSD 导出下一步接」——PSD 那条链要串 `buildPsdNow()`（在旧 `EditorScreen` 里，依赖它的一堆状态），下一步单独搬。

没做：PSD 读写；导出的尺寸/质量还没做选项。
