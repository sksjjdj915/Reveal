# 0.74.76 圈外永远不消失：调色一律不许改不透明度

## 你的复现路径
「选好范围 → 调色 → 应用」和「选好范围后拖圈」两条路都会让圈外变透明。前者走 `applyFilterToActive` 的遮罩合成，后者走 `previewRegionComposite`。两处的 alpha 都取自「滤镜结果」，而调色类滤镜返回的新位图不保证 alpha 是 255（有的是 0 或半透明），于是过渡带和圈外就被吃成透明。

## 这次把规则写死
1. `applyFilterToActive(filter, label, allowAlpha = false)`：新增 `allowAlpha` 参数。
   - **默认 false**：遮罩合成里 alpha 恒等于「原像素的 alpha」，调色只改 RGB；
   - 只有确实要改不透明度的滤镜（色带抠图）调用时传 `allowAlpha = true`；
   - 连 `ma >= 250`（完全不透明的那块）也强制用原像素 alpha，不再直接搬滤镜结果的 alpha。
2. `previewRegionComposite` 同样处理：`ma >= 250` 也用原像素 alpha，只有 RGB 换成滤镜结果。
3. 范围外（`ma <= 5`）直接整像素沿用原图。

## 结果
范围/羽化/强度只影响颜色，**任何情况下都不改变不透明度**；圈外、羽化带、圈内都不会出现棋盘格。

## 没做
「橡皮擦/背景橡皮」这类真的要去掉像素的操作仍走各自工具路径（不经过这里）；0.74.x 只做编译验证，无真机验收。
