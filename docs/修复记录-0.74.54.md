# 0.74.54 调色面板也加滚动条

## 补充
上一版（0.74.53）的滚动条先接在子滤镜面板；这一版把 `ui/ColorDocks.kt` 的 `ColorDockShell`（曝光度 / 色彩平衡 / 色调分离 / 色相饱和度等共用外壳）也接上：
- 内容区右侧留 4dp 给滚动条，`ScrollBar(scroll)` 显示 3dp 细竖条；
- 短面板（内容不满一屏）不显示滚动条，不会多出一根线。

## 已经完成（0.74.53）
1. 油画「光照强度」改成有符号方向光（中心差分投影到光方向 ×260），朝光变亮、背光变暗，拉滑块现在有明显反应；
2. 点任意工具后左侧模式栏自动收起（点「滤镜」本身不收起，因为还要选子工具）；
3. 参数面板右上角的 ✕ 已去掉，关闭方式统一为「再点一次同一个工具」；
4. 可滚动面板右侧加 3dp 滚动条（按可视比例算长度、跟随滚动位置）。

## 没做
滚动条只显示、不能拖动；曲线/色阶那两个自定义面板还没接（它们自己画直方图/曲线，需要单独处理）。0.74.x 全部只编译验证，无真机验收。
