# 0.74.9 色相饱和度：通道参数终于能动、重置按当前通道

## 一、红/黄/绿… 拖动没反应（真因）
`HueSat.Band` 是个带 `var` 字段的 data class，之前滑块直接写 `cur.hue = …`：
- 改的是对象内部字段，**Compose 感知不到**（没有状态写入，不会重组）；
- 预览泵读的是 `rememberUpdatedState` 里打包的快照，也不会因为字段变化而更新。
→ 所以拖动时数值在变、画面永远不动。
改法：一律写回列表 —— `bands[channel - 1] = cur.copy(hue = …)`。`mutableStateListOf` 的写入会触发重组，预览泵立刻拿到新快照（这也是 Compose 官方推荐的「不可变数据 + 状态容器」写法：`data class` + `SnapshotStateList`，不要用可变字段直接改）。

## 二、重置按「当前所在页/通道」
- 全图页：按钮文字是「**重置全图**」，清 `masterHue/masterSat/masterLight`；
- 某个色相带页：按钮文字是「**重置本通道**」，把 `bands[channel-1]` 换成空的 `Band()`。
两边都能重置了，不再出现「全图点了没反应」。

## 三、口径说明（面板里也写了）
每个色相带只影响「该中心色相 ±60°」的像素（余弦窗权重），改「红」不会把「黄」拉走；要整体动色相用「全图」通道。

没做：液化/变形/图案图章专属参数、裁剪与画布大小、AI、曲线吸管。
