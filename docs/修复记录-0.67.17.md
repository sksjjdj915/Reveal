# Reveal 0.67.17 修复记录（修复画笔：整条笔迹一次泊松）

版本：versionCode 282 / versionName 0.67.17
APK：42348769 字节（com.reveal.editor），桌面只留这一个。

## 改了什么

以前修复画笔是「每一下笔触各自算一次低频搬移」，所以一路拖过去会出现三件事：色调一路漂（像在抹）、密集涂有斑块、边界只对得齐「这一下笔触」而不是「整条笔迹」。

现在分两段：

1. **拖动时**：照旧每一下笔触做「低频从源图搬、高频留目标」的预览。这一段是 O(半径²)，不影响手感。
2. **抬手时**：对**整条笔迹**解一次泊松方程
   - 边界值 = **落笔前的原图像素**（`beforeArr`，即 commit 前抓的那块）→ 和周围零接缝；
   - 内部梯度 = **取样源**（用落笔时拍好的 1/8 小图，梯度只要低频）→ 纹理是真的；
   - 先降到 1/2 分辨率的粗网格上解，再把「修正量 = 泊松解 − 预览」双线性放大、按覆盖度羽化贴回。

依据：Pérez、Gangnet、Blake《Poisson Image Editing》SIGGRAPH 2003（无缝克隆就是解这个方程）；Bertalmío 等《Image Inpainting》SIGGRAPH 2000（无源时退化成拉普拉斯/调和插值）。

## 求解细节

- 粗网格步长 2px；高斯-赛德尔 + SOR（ω=1.85），40 轮。
- 未知域 = 笔迹覆盖过的像素（含羽化边），边界 = 覆盖度 0 的像素。
- 贴回权重 = 覆盖度/255，所以笔迹外一圈像素**完全不动**（数值验证过：外侧差 0.0）。

## 离线数值验证

用 Python 复刻同一套公式跑合成图（竖直渐变目标 + 斜纹源 + 羽化笔迹）：
- 笔迹外相邻一圈与目标差异 **0.0**（不动）；
- 羽化带与目标的平均差约 **5**（渐变正常过渡，不是硬边）；
- 无 NaN，修正量有界。

这只是公式层面的自检，真机手感和效果还得你看。

## 怎么验

1. 修复画笔，Alt 取样一块皮肤/天空，然后在一片渐变上拖一道——**抬手后**看边界：应该没有方形的笔触印，也没有颜色突然跳一档。
2. 同一块地方来回涂三遍，以前会越来越糊/越来越偏色，现在应该基本不变。
3. 大幅面（4096）也试一下：抬手时最多几十毫秒，不该有明显卡顿。

## 没做 / 已知边界

- 只在「修复画笔 + 非蒙版 + 无选区 + 非阿尔法锁定」时走泊松；带选区时仍用每笔触预览（避免和选区裁切打架）。
- 超过 1200 万像素的文档（比如 4096×4096 以上再放大）不启用覆盖度缓冲，退回逐笔触预览。
- 完整 PatchMatch（Barnes 2009）仍未上：多轮传播无法在拖动时逐段实时跑。
