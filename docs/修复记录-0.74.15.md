# 0.74.15 预览清晰度 / 模式栏箭头下移 / 滤镜工具

## 一、点工具后面板出现图像变模糊
- 真因：0.74.13 我把预览底图上限从 900 降到 560（为了流畅），而预览位图会被**放大**贴到整张画布上——1620 高的文档只用 560 的图，放大 3 倍必然糊。
- 改法：上限回到 **900**。这次不再有性能问题，因为所有调色已经改成查表/矩阵（3D LUT / ColorMatrix / 1D LUT），算 900 的预览也就几十毫秒。
- 说明：仍然不是 1:1 像素级清晰，因为预览是降采样再放大的；真正落盘（应用）时用的是全分辨率，导出/保存不受影响。

## 二、模式栏收起箭头挪到最下面
- `ui/NewShell.kt` 的 `ModeRailPinned`：把原来的顶部 `ChevronLeft` 删掉，在六个模式之后加一颗 34×24dp 的收起按钮。
- 理由：拇指够得到（手机单手持机时下沿最容易点）。

## 三、调色里新增「滤镜」工具
- 工具行加了一颗「滤镜」（原来的「照片滤镜」保持独立，改名对齐）。
- 点「滤镜」**不出现参数面板**，而是在工具行上方展开一排子滤镜（横向可滚），一共 33 个：高斯模糊 / 动感模糊 / 径向模糊 / 方框模糊 / 表面模糊 / USM 锐化 / 智能锐化 / 查找边缘 / 浮雕 / 油画 / 水彩 / 马赛克 / 晶格化 / 点状化 / 彩色半调 / 添加杂色 / 蒙尘划痕 / 中间值 / 减少杂色 / 波纹 / 球面化 / 旋转扭曲 / 挤压 / 极坐标 / 云彩 / 镜头光晕 / 高反差保留 / 最小值 / 最大值 / 位移 / 胶片颗粒 / 剪纸 / 碎片。
- 点其中任意一个 → 拉出该项自己的参数面板（复用原来的 `ColorFxDialog` + `filterSpec` 参数表），确定后落到当前层并进撤销。
