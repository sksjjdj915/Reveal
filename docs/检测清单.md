### v0.30.3 自检与蒙版工具

1. **自检**：帮助 →「自检…」，应弹出「18 通过 / 0 失败」，点「复制」能把整页贴出去。
2. **蒙版只认画笔**：加蒙版 → 切「减淡」在画布上涂 → 红色遮罩不应消失（说明没涂到蒙版）；切回画笔涂黑 → 红色应跟着变。
3. **网格随图缩放**：开网格 → 双指放大 → 网格线跟着图片一起变大（格数不变），不再是屏幕上固定 40dp。
4. **减淡/加深**：拿一张有灰阶的照片，减淡来回涂 3~4 遍应该逐渐变亮，不会一下变纯白；加深同理。
5. **涂抹**：在两色交界处涂，颜色应被拖着走，强度滑块从 0.05 到 1 变化明显。
6. **欢迎页**：重开 App，更新日志应能看到 0.30.3 和 0.21–0.30 两段。

### 1. 蒙版基本遮罩

## v0.18.0 已发布的新增/修复

### 1. 向下合并（修「合并完图层消失」）
- **目的**：合并后下面那层的像素不能被吞掉；合并完只该少一层，画面看起来不变。
- **操作**：
  1. 打开/新建一张图，加两层：下层用画笔涂一块，上层也涂一块（两块不要完全重叠）。
  2. 选中上层 → 图层菜单「向下合并」。
  3. 再把下层不透明度拉到 60%，重复一次合并。
  4. 极端情况：把下层点「隐藏」（眼睛关掉）再合并一次。
- **通过**：①合并后图层数 -1；②两块颜色都还在、位置没变；③合并后那层的可见性是开的、不透明度回到 100%；④照片能继续画、能撤销到合并前一次。
- **不通过就告诉我**：是哪种情况丢的（隐藏的层 / 半透明的层 / 普通层）。

### 2. 反相
- **目的**：每个像素颜色取反，黑白互换。
- **操作**：打开一张图 → 菜单 滤镜 → 反相。
- **通过**：整张图变成负片效果（黑的变白、白的变黑），彩色区域颜色也随之翻转；按撤销能立刻复原。

### 3. 去色
- **目的**：去颜色留明暗，红绿蓝应该换算成同一个灰度，不能偏色。
- **操作**：打开彩色图 → 菜单 滤镜 → 去色。
- **通过**：画面变黑白；原来亮的地方依然亮、暗的依然暗（不是简单三个通道平均到发灰）；撤销能复原。

### 4. 高斯模糊
- **目的**：整张图（或选区内）平滑虚化，边缘不能出现黑边或硬台阶。
- **操作**：菜单 滤镜 → 高斯模糊… → 拉滑块到 10 左右 → 确定。再做一次：先框一个选区，再模糊。

- **目的**：让边缘更清楚（线条、发丝变挺），不能整体变亮变脏。
- **操作**：菜单 滤镜 → 锐化。
- **通过**：边缘对比变强、细节更「干脆」；整体亮度和色相基本不变；没有出现彩色噪点或白边；撤销可复原。

### 6. 阈值
- **目的**：按亮度二值化，是做抠图/线稿的常用前置。
- **操作**：菜单 滤镜 → 阈值… → 滑块左右拖（默认 128）→ 确定。
- **通过**：图只剩纯黑纯白两色；滑块调小黑色变多、调大白色变多；撤销可复原。

### 7. 画布大小
