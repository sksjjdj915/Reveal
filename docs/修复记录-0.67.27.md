# 修复记录 0.67.27

用户说「取舍你按适合手机的来做就行」。下面是 5 条「跟桌面端不同」的处置结论，以及这一版做了什么。

## 处置结论

| 条目 | 决定 | 理由 |
| --- | --- | --- |
| 缺「输出到：新建文档」 | **不做** | 手机上「把选区变成一张新图」用得极少，还要多一层文档栈；真需要可以抠成新图层后导出。 |
| 缺「输出到：新建带蒙版图层」 | **做了** | 手机做合成/换背景最常用的就是这一项，成本也不高。 |
| 智能半径阈值写死 0.22 | **改成可调** | 手机拍的照片画质差异大（有噪点、有虚焦），固定阈值不通用。 |
| 污点修复只有「近似匹配」走完整 PatchMatch | **保持** | 另外两种走样本合成，比在手机上跑 20 万像素 PatchMatch 快一个量级，效果够用。 |
| >800 万像素「源=所有图层」第一笔可能先用当前层 | **保持** | 拍平一张 4096 全图要几百毫秒，落笔前硬等会卡住第一次下笔；后台拍平完成后第二笔就是全图。 |
| 橡皮用自己的大小字段 | **保持** | 故意分开：擦除和画画的最优笔刷大小本来就不一样。 |

## 这一版改了什么

**1. 选择并遮住新增输出「新图层+蒙版」**
整层内容复制成新层，再挂一张选区蒙版。跟「新图层」的区别：新图层是把选区外的像素删掉（硬切），这个是保留整层、用蒙版遮住（可以再擦蒙版找回来）。

**2. 选择并遮住新增「边缘灵敏度」滑块**（智能半径开启时出现，5~55，默认 22）
控制「多弱的边就算边」。默认 22 适合常见照片；噪点多/边缘虚的图调到 30~40，线条硬朗的插画调到 10~15。

## 怎么验

1. 选一块 → 选择并遮住 → 输出选「新图层+蒙版」→ 应用：新层上有内容、蒙版遮住了选区外；涂黑蒙版能把外面找回来。
2. 同样的选区，把「边缘灵敏度」从 10 拖到 45，看边缘咬合位置明显变化（10 更贴细节、45 更敢跳过弱边）。
3. 输出选项里没有「新建文档」是故意的，不是漏了。
