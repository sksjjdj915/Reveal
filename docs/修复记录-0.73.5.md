# 0.73.5 曲线图形化 + 全调色实时预览

## 一、曲线换成真正的曲线（`ui/CurvesDock.kt` 新建）
- **图形化编辑**：150dp 高的曲线框，画 4×4 网格 + 实时曲线；控制点显示成白心蓝圈。
- **拖点**：按住控制点上下（端点只能上下）、中间点可左右；相邻点之间保持 0.02 的最小间隔，不会穿模。
- **加点**：点空白处直接插入新控制点（自动按 x 排序）。
- **四通道**：RGB / 红 / 绿 / 蓝 四颗胶囊，各自维护一组控制点，互不影响。
- **和最终效果一致**：画线用的是引擎自己的 `Curves.lutOf(points)`，不是另写一套近似曲线。
- 「应用」写入图层（可撤销）；「重置」把当前通道拉回直线。
- 内容没少：`Curves.Params(points, redPoints, greenPoints, bluePoints)` 四个通道全在，应用时一起生效。

## 二、全部调色改成「参数一动就预览」
- **曲线**：`LaunchedEffect(ptsRgb, ptsR, ptsG, ptsB)` 里直接算（无 delay，靠 effect 自动取消合并），`setPreview` + `invalidate()`。
- **色相饱和度 / 亮度对比**：新增底图（`sketch.flatten()` 的副本）+ 同样的实时预览，走 `AdjustOp` + `AdjustApply.applyInPlace`；「应用」前先 `clearPreview()`，「取消」也清。
- **色阶**：节流 70ms → **16ms**（基本等于跟手）。
- 三个面板都加了 `DisposableEffect { onDispose { clearPreview() } }`，退出面板不会把预览图留在画布上。

## 三、没做
- 曲线没有「吸管取样」「自动」按钮（旧界面那两个是配合直方图用的，等直方图进曲线面板再加）。
- 文字参数、液化变形、裁剪与图像大小、AI 仍未接。
