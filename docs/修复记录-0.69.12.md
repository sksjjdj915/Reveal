# 0.69.12 界面改版 · AI 模式占位页

## 一、这次做了什么
1. **AI 模式不再是空白**：切到「AI」时，画布中间浮出一张白色说明卡（`AiPlaceholder`，在 `ui/ModeShell.kt`）：
   - 标题「AI 模式还没接入」；
   - 说明这里以后放什么：文生图、局部重绘、抠图/扩图、智能放大、风格化；
   - 说明现在能用的在哪：另外五个模式；
   - 底部四个胶囊直接切到 抠图 / 调色 / 绘制 / 修图，不用回头再点顶部模式栏。
2. 卡片是 20dp 圆角白卡 + 12dp 阴影，浮在画布上方居中，不挡左上角的状态栏和右下角图层按钮。

## 二、这次没做
1. AI 模式仍然没有任何真实功能（只有入口和说明）。
2. 曲线面板其余部分（数值框 / 取样 / 参考曲线 / 网格）没重排。
3. 左栏逐项错开动画没做。
4. 没跑模拟器。

## 三、怎么验
1. 进编辑器 → 顶部点「AI」→ 画布中间出现说明卡，写明还没接入、以后放什么。
2. 点卡片里的「抠图」→ 立刻切回抠图模式，左栏变成选区类工具，卡片消失。
