# 0.69.4 界面改版 · 第三级（面板统一 + 左栏切换动效）

## 一、这次做了什么
1. **三块主力面板统一成新外壳**（`ui/Panels.kt`）：
   - 调色/滤镜那一组参数面板（原 `PanelColorAdjust` 深色贴边条）→ 白色卡片、20dp 圆角、10dp 阴影、左右各留 10dp、内部上下留白加大；
   - 带标题行的面板（标题 + ✕ 那一类）→ 同样白卡片；
   - 文字面板（添加文字/编辑文字）→ 同样白卡片，内边距 14/8。
   至此「参数条 / 图层样式 / 调色面板 / 文字面板」四种容器视觉一致。
2. **切模式时左栏整列淡入**：`ToolRail` 里加了 `Animatable(1f)`，`LaunchedEffect(mode)` 时从 0.35 用 220ms 强调缓动淡到 1.0。整套工具换掉时不再像被直接刷掉。

## 二、这次没做
1. 色阶 / 曲线 / 色相饱和度 / 渐变映射这几个**独立大面板**内部结构没重排（外壳已跟随变化，但内部还是原来的行布局，没按「分组小标题 + 分隔线」重组）。
2. 左栏的淡入是整体透明度，不是逐项错开滑入（staggered）。
3. 首页（工程列表）版式没重排。
4. 没跑模拟器。

## 三、怎么验
1. 点「调色」→ 打开任意调色面板 → 白色圆角卡片、有阴影、四周留白。
2. 打开文字工具面板 → 同样白卡片。
3. 顶部切换「抠图 / 调色 / 绘制」→ 左侧栏内容换掉时整列有一次淡入，不再瞬间闪现。
