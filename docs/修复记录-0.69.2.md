# 0.69.2 界面改版 · 第三级（参数条重做）

## 一、这次做了什么
1. **打开软件底部是空的**：`barHidden` 初值改成 true，进编辑器不再默认挂着画笔那一条。点任意工具才浮出该工具的参数条（`onTool` 里 `barHidden = false`）。
2. **参数条改成白色浮层卡片**：左右各留 8dp、底 10dp，圆角 20dp，纯白底 + 10dp 阴影，内边距 14/10/8/8。不再是一条贴边的深色横条。
3. **进出场动画**（Material 3 强调缓动 `cubic-bezier(0.2,0,0,1)`）：
   - 出现：从下方整条滑上来 + 淡入，220ms / 180ms；
   - 收起：向下滑出 + 淡出，160ms / 120ms（退出比进入快，符合 M3 规范）。
4. 参数条不再自己判断显示/隐藏（`if (!barHidden)` 挪到外层 `AnimatedVisibility`），避免动画和状态打架。

## 二、这次没做
1. 参数面板（色阶/曲线/调色这些弹窗）还是旧版式，只换了配色，没重做成「标题行 + 分组 + 细线滑块 + 数值左右拖」的统一结构。
2. 模式切换时左栏没有整列滑入/淡入动画（只有模式胶囊的过渡）。
3. 首页（工程列表）版式没重排。
4. 没跑模拟器。

## 三、怎么验
1. 打开一个工程 → 底部**不应该**有参数条，画布应该更完整。
2. 点左侧任意绘制工具 → 参数条从下方滑上来，白色圆角卡片带阴影。
3. 点右上角「参数」或条上的 ✕ → 向下滑出收起。
4. 再点另一个工具 → 又从下方滑上来，参数是那个工具的。
