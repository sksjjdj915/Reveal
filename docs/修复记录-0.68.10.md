# 0.68.10 多选补齐（合并混合模式 / 成组折叠 / 记住勾选）

版本：0.68.10（code 368）
日期：2026-11-09

## 做了什么（相对 0.68.9 的三条「没做的」）

1. **合并现在按每层的混合模式合成**。以前不管哪层都按正常模式叠，现在逐层套用该层的混合模式（正片叠底/滤色/叠加/柔光…），合并出来的样子和画面上看到的一致。
2. **成组后自动折叠**。多选点「成组」生成的「组 N」默认是收起的（▶），一眼看到整包，不用再手动点一下。
3. **多选状态记住了**：勾了哪些层、是否在多选模式，都存进 `SketchView`；关掉图层面板再打开、切工具再回来，勾选还在，只有点「退出多选」才清。

## 怎么改的

- `SketchView.kt`
  - `mergeLayersAt()`：每层画之前 `applyBlendMode(p, l.blendMode)`，画完把画笔重置成 SRC_OVER。
  - `groupLayersAt()`：组头 `header.sectionType = 2`（折叠态），原来是 1（展开）。
  - 新增 `var multiSelectMode` / `val multiPicked` / `fun setMultiState(mode, picked)`。
- `Dialogs.kt`（`LayerPanel`）：新增参数 `multiMode0` / `picked0` / `onMultiState`；所有会改勾选的地方（进/出多选、点行、全选、反选、批量执行完）都调 `syncMulti()` 回写。
- `LayerPanelHost.kt`：把 `sketch.multiSelectMode` / `sketch.multiPicked` 传进去，回写走 `setMultiState`。

## 怎么验

1. 勾两层（其中一层设成「正片叠底」）→ 合并 → 结果应该和合并前的画面一致，不是变成普通叠加。
2. 勾三层 → 成组 → 新组是收起的（▶），点开能看到三层。
3. 勾两层 → 收起图层面板 → 重新打开 → 勾选还在、还在多选模式。
4. 切到画笔再回图层面板 → 勾选仍然在。
5. 点「退出多选」→ 勾选全清。

## 没做的

- 勾选状态不进工程文件（关掉工程再打开不会恢复；桌面端本身也不存）。要存的话得改工程包格式，说一声再加。
- 批量删除/合并/成组仍是一步撤销，没有更细的粒度。
