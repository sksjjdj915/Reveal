# 0.73.8 色阶两页（直方图拖黑白场）+ 曲线第二页放参数 + 左右滑动翻页

## 一、色阶重做成两页（`ui/LevelsDock.kt` 新文件）
- **第 1 页**：直方图铺满，上面两根竖线就是**输入黑场 / 输入白场**，直接拖（顶部两个蓝点可抓）；黑场只能往右拉到白场左边界，反之亦然；标题行实时显示「黑 12 · 白 243」。区间内的柱子深、区间外浅，一眼看出哪段被切掉。
- **第 2 页**：伽马（0.05~3，两位小数）、输出黑场（0~254）、输出白场（1~255），一行一个参数 + 说明文字。
- 底部按钮：取消（回到 0/255/1/0/255）/ 应用。

## 二、曲线第二页不放图，改成参数
- 第 1 页仍是曲线编辑（拖点 / 双击加点 / 四通道）。
- 第 2 页改成**预设 + 信息**：线性、S 形、提亮、压暗、反相、加对比，点一下直接套到当前通道；下面显示当前通道控制点数。
- 直方图从曲线里去掉（要看直方图去色阶第 1 页）。

## 三、翻页改成左右滑动
- 色阶、曲线两个面板都在外层 Column 上挂 `detectHorizontalDragGestures`：左右滑 > 40dp 就翻页。
- 原来只能点底部两条细线，现在细线仍可点（保留作为指示 + 快捷方式）。
- 曲线第 1 页拖控制点不会误翻页（子层的拖动会消费事件，父层收不到）。

没做：文字参数、液化变形、裁剪与图像大小、AI；曲线吸管/自动按钮。
