# 0.74.61 目标⑤：液化 / 变形 / 图案图章 专属参数

这三把工具原先共用「画笔」那套只有大小/不透明度，现在各有自己的参数卡。

## 液化
| 参数 | 范围 | 说明 |
|---|---|---|
| 大小 | 4~300 | 笔刷半径（写的是引擎的 `brushSize`） |
| 力度 | 0~100 | `liquifyStrength` |
| 模式 | 推挤 / 膨胀 / 收缩 | `liquifyMode` 0/1/2 |

推挤 = 按拖动方向推着像素走；膨胀/收缩 = 朝笔尖中心放大或收紧。

## 变形
- 「网格：开/关」：开 → `warpStart()`（当前层生成 4×4 默认网格并打开 warpOn），关 → `warpOff()`（画面回原样，网格保留）；
- 「复位网格」：`warpResetMesh()`，把 16 个控制点还原成标准田字格；
- 网格点在画布上拖动即可扭曲，提交由引擎现有的烘焙逻辑处理。

## 图案图章
| 参数 | 范围 | 说明 |
|---|---|---|
| 大小 | 4~300 | 笔尖大小 |
| 对齐 / 不对齐 | 开关 | 对齐 = 图案跟着画布走；不对齐 = 每笔重新起图案 |
| 图案 | 横向可滚列表 | `Patterns.all()` 的全部图案名，点选切换 `patternIndex` |

## 实现备注
新增统一卡片外壳 `DockCard(title, hint, modifier, content)`（白卡 20dp 圆角 + 8dp 阴影 + 420dp 上限），三个面板都用它，样式与其它参数卡一致。

## 没做
1. 液化没有「冻结/解冻蒙版」「重构/恢复全部」；
2. 变形没有「拆分网格」（网格固定 4×4），也没有「网格线显示开关」；
3. 图案图章没有「压印模式/再次变换」扩展。
