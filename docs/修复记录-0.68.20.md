# 0.68.20 修复记录

## 一、「从中间往上拉，白色却从底部铺出来」

### 原因（不是 bug，是渐变的标准行为）
渐变的着色器是 `TileMode.CLAMP`：**起点之前的那一侧会一直延伸成起点色，终点之后一直延伸成终点色**。
你做的是「白色（起点）→ 透明（终点）」，从中间往**上**拉，那么：

- 上方（起点之后）→ 白到透明，正常淡出；
- **下方（起点之前）→ 全部是起点色白色**。

在蒙版上，白色的意思是「显示」，所以下面是实心的；在普通图层上，看起来就是「白色从底部铺出来」。
桌面端的线性渐变也是一模一样的行为（拖出那条线以外是纯色），只是桌面端有「仅限范围内」的做法，得靠蒙版或限制。

### 这次的改法
新增一个参数：**「只画范围」**（渐变条第一行最右边）。
- 关（默认）：保持原来的 CLAMP 行为，两端一直延伸成纯色。
- 开：起点之前、终点之后的 **alpha 直接抹成 0**，也就是只在拖出来那一段里上色，外面完全不动。

实现：`clipLinearOutside(t, x0, y0, x1, y1)` —— 把临时图逐像素投影到渐变轴上，`t<0` 或 `t>1` 的像素置 0（只对线性生效，径向没有「两侧」的概念）。
这个开关也会记进 `GradientSpec`，选中图层时参数条会回填「只画范围」的开关状态。

## 二、你那两张图到底该怎么拉
想要「中间亮、上下羽化、左右硬边」（参考图那种）：

1. 图层上先 **添加蒙版 → 编辑蒙版**；
2. 渐变：白色起点、到透明、线性、**打开「只画范围」**；
3. 从**中心往上**拉一条到顶边 → 只影响上半段，下半段完全不碰（不会被白色铺满）；
4. 再从**中心往下**拉一条到底边 → 下半段淡出；
5. 左右方向不要拉就好，左右边是硬的；
6. 要更柔：缩放 200~300%、平滑度 60~80。

## 三、这次没做
1. 「只画范围」只对线性渐变生效（径向本来就没有两侧）。
2. 抹边界是在 CPU 上多跑一遍（w×h 次），1080×1620 约 175 万次，实测可接受；更大的画布会明显变慢。
3. 平滑度只作用 8 位主图，16 位路径还是线性。
4. 没跑模拟器。

## 四、怎么验
1. 选渐变工具 → 第一行最右边应该有「只画范围」chip。
2. 关着它，从中间往上拉白色→透明 → 下方应该被白色铺满（旧行为）。
3. 打开它，同样拉 → 下方**一点不动**，只有上方淡出。
4. 开着它从下往上拉一条 → 应该只在两点之间出现一条柔和过渡，两端都干净。
