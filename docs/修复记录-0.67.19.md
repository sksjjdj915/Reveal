## 一、缩放期间不再建派生位图（`rebuildEdge` 分两档）

`rebuildEdge()` 原来一口气做四件重活：`tracedOutline` 全图描边、`maskHasContent` 扫描、
`Selection.edgeBitmap` 全幅、`buildDimMask` 全幅（还要再铺一次整图 + DST_OUT 挖洞）。

现在加了 `edgeDeferred` 标记：
- `rebuildEdge()` 一进来先看 `zooming`：正在双指缩放/平移时，只置 `edgeDeferred = true`、
  停掉蚂蚁线计时器，**什么位图都不建**（`drawSelection` 在 `zooming` 时本来就整块跳过，
  建了也画不出来）。
- 抬手 `zoomning = false` 处（以及 `ACTION_CANCEL` 被系统打断处）补一次完整重建，只补一次。

结果：缩放过程中主线程不再有任何全幅分配；派生位图在手指离开时一次性补齐，
用户看到的是「松手瞬间选区线/压暗同时出现」，而不是卡在中间。

## 二、撤销/重做换掉选区时，面板基准作废

`选择并遮住` 打开时会拍一张 `selEditBase` 当基准，之后所有预览都从这张算。
但撤销/重做会通过 `applySelectionSnapshot` 换掉当前选区 —— 基准还停在「撤销前」，
下一次拖动预览就会把撤销结果又盖回去。

现在 `undo()` / `redo()` 里凡是带选区快照的 `stroke`（`stroke.selW > 0`），
还原完立刻调 `recycleSelEditBase()` 作废基准；下一次预览会拿**当前**选区重新取基准。

## 三、怎么验

1. 拉个大点的选区（或导入 4096 图再选区）→ 双指放大缩小：全程跟手，松手时选区线和压暗一起出现。
2. 缩放一半时按返回/被通知打断（触发 ACTION_CANCEL）：回来后选区和压暗都应该还在，不残影。
3. 打开 `选择并遮住` → 拖一下羽化 → 按撤销（两指轻点或撤销按钮）→ 再拖羽化：
   画面应该基于撤销后的选区变化，而不是又跳回撤销前那块。
