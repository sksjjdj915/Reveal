# 0.74.21 子工具目标 ③：旋转扭曲

## 文献/成熟算法
旋转扭曲的通用写法是「角度随半径衰减的极坐标旋转」：`θ' = θ + A·(1 − t)`，`t` 为归一化半径，半径外 `A·0 = 0` 完全不动。这是桌面端「旋转扭曲」以及各种 swirl shader 的共同做法，衰减连续所以不会出现环状硬边。
本次实现用 `A·(1−t)²`（平方衰减），更接近桌面端观感：中心拧得多、靠近边界迅速归零。

## 补的参数（`FilterFx.twirlAt`）
| 参数 | 范围 | 说明 |
|---|---|---|
| 角度 | −720~720° | 中心处旋转量（桌面端只到 ±360，这里放宽到两圈） |
| 中心 X % / 中心 Y % | 0~100 | 拧的中心位置 |
| 半径 % | 5~200 | 影响范围 |
