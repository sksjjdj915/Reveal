# 0.74.92 有范围时调色变成「活的处理链」，只有「烧录」才落像素

## 你要的行为
1. 应用之后不烤死；换工具再调，**叠在上一次结果上**继续算；
2. 范围是活蒙版：拖圈，效果跟着走、旧位置恢复原样；
3. 只有当你在范围里选中那个圈、点「烧录」，才真正写像素——**圈消失、画面变成真像素**。

## 实现（对应影视调色软件节点 / 桌面端调整图层+蒙版的语义）
- `SketchView` 新增一条处理链：`chainBase`（链底原图）+ `chainSteps`（每步的名字和滤镜闭包，参数被闭包带住）；
- `applyFilterToActive`：**只要画面上有范围**，就不再写像素，而是 `pushChainStep(name, filter)` 往链上压一步；
- 预览：`previewRegionComposite()` 从链底重放整条链 → 按 `regionMask()` 合成（`base + (corrected−base)×mask`，alpha 取原图）→ 交给预览层；
- 拖圈：100ms 节流重算预览；**松手不再烧像素**（0.74.91 的松手烘焙已撤掉），所以一直是活的；
- `commitChain()`：后台全分辨率重放整条链 + 蒙版合成 → 写回图层像素 → 清链 → **清空所有范围（圈消失）** → 记一条撤销。

## 面板新增（范围面板里，链上有步骤时才出现）
| 按钮 | 作用 |
|---|---|
| 处理链：N 步（活的…） | 提示当前有几层叠加 |
| 烧录 | 真正写进像素、删掉圈 |
| 退一步 | 撤销链上最后一步（参数调错不用从头来） |
| 放弃 | 丢掉整条链，像素还原成链底原图 |

## 边界
- 链绑在「当前图层」上，换图层即作废；撤销/重开工程不保留链（链只活在内存里）；
- 没有范围时，调色还是老行为（直接写像素）；
- 烧录要全分辨率重放，1080×1620 加几个滤镜会有一两秒，期间显示「正在烧录…」。

0.74.x 仅编译验证，无真机验收。
