# 0.67.90 修复记录（2026-11-09）

## 1. 渐变映射改成「色带」
原来是 10 个固定色块，选不到想要的颜色。现在（入口不变：调色 → 专业调色 → 渐变映射…）：

- 一条**横向色带**，左端是最暗处的颜色、右端是最亮处的颜色，中间是插值；
- 色带两端各一个**正方形取色块**（38dp，和画笔取色一样），点一下展开取色面板，拖动实时预览；
- 标注写清了：`左 · 暗部（最黑处）`、`右 · 亮部（最白处）`，标题行也写了「按亮度取色：最黑用左端，最白用右端」。

重申一次语义：这是**按亮度**换色，不是上下/左右渐变。想要方向渐变要用「渐变」工具。

## 2. 删掉了「新建调整图层」里的渐变映射
上一版（0.67.89）我把渐变映射做成了调整图层版，还多开了一个入口。已按你说的删掉那个入口，
渐变映射现在只有一处（滤镜版，就是上面那条色带）。
代码里 `AdjustOp.KIND_GRADIENT_MAP` 的渲染分支先留着（旧工程里已有的那种层还能正常显示），但入口不再出现。

## 3. 没做（下一步）
「新建调整图层」那个**通用按钮**：先建一个空的调整层，再往里叠任意调色/滤镜。
这不是加个按钮的事 —— 现在每个调色要么直接改像素、要么是固定一种调整层；
要支持「一个层里挂多个效果」，得新增一条渲染路径（把这个层下面的画面当成输入，依次套效果再画出来），
以及存工程的格式、PSD 导出的处理。我按一步一个版来做，下一版专门做它。

## 怎么验
1. 调色 → 专业调色 → 渐变映射…：应看到一条色带 + 左右两个方色块；
2. 点左边方色块 → 取色面板 → 选一个深蓝，画面实时变；
3. 点右边方色块 → 选一个暖金；色带本身也应跟着变；
4. 点确定后生效；点取消画面恢复。
