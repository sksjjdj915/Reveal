# 0.69.10 界面改版 · 首页多选态

## 一、这次做了什么
1. **多选态标题行重排**：
   - 「已选 N」从灰字改成蓝色胶囊（浅蓝底 + 蓝字），一眼能看到选了几个；
   - 「全选 / 删除 / 取消」从 Material TextButton（带默认内边距、48dp 最小高）换成和全站一致的胶囊 chip；
   - 「删除」原来用 Material 的红色文字按钮，现在改成和别的按钮同一套形态。
2. 解决的实际问题：原来三个 TextButton 挤在标题行右侧，小屏上「取消」几乎贴边，且和左边的「已选 N」混在一起；现在有间距、有视觉分组。

## 二、这次没做
1. 卡片上的勾选角标没换样式（仍是原来的圆形勾）。
2. 曲线面板其余部分（数值框 / 取样 / 参考曲线 / 网格）没重排。
3. 左栏逐项错开动画没做。
4. 没跑模拟器。

## 三、怎么验
1. 首页长按任意工程 → 进入多选；标题行出现蓝色「已选 0」胶囊，右侧「全选 / 删除 / 取消」三个胶囊。
2. 点几张卡片 → 数字实时变。
3. 点「取消」→ 退出多选。
