# 0.72.7 PSD 导入 + 图层组

## 一、PSD 导入（真接上了）
文件面板新增「导入 PSD」：
- 用系统文件选择器（`GetContent("*/*")`）拿 uri；
- `Psd.openSmart(inputStream, cacheDir)` 解析（支持 8 位 RGB / 灰度、PSD 与 PSB）；
- 逐层转成 `SketchView.Layer`，带上名称、可见性、不透明度、混合模式、剪贴蒙版、锁定透明、蒙版；
- 新增 `SketchView.replaceLayersWith(layers, w, h)` 一次性替换整份文档（清撤销栈、清选区、清 mip、`fitToView`）；
- 失败会明确说是「读不出来」还是「没有可读图层」，并把异常类名带出来。

## 二、图层组
图层面板：
- 标题行新增「组+」，把当前层包成一个组（`groupLayersAt`）。
- 组头显示折叠箭头：`▾` 展开 / `▸` 收起（切换 `layer.sectionType` 1↔2，引擎按 2 跳过成员绘制）。
- 组成员按层级缩进（每层 10dp），组底分隔层不再显示成一行空条目。
- 折叠时成员行直接隐藏，列表只留组头。

## 三、没做
1. **PSD 导出**仍是提示「下一步接」：需要把 `Psd.encode` 的图层打包规则（含蒙版、调整块、smart 源）搬进新界面，是一整块活。
2. 调色剩色阶、曲线两项；文字参数、液化/变形、裁剪/图像大小未接（按你说的先放着）。
