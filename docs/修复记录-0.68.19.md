# 0.68.19 修复记录

## 一、「修改没变化」的真因（0.68.18 我自己引入的）

- `canEditGradient()` 的条件是 `gradStamp == pixelEpoch`，`pixelEpoch` 在 `touchPixels()` 和 `pushPatch()` 里各 +1。
- 0.68.18 为了减少卡顿，把「压撤销」从每次滑动改成手停 420ms 后压一次：
  `endGradientSpecEdit()` 里调 `pushPatch(...)` → `pixelEpoch +1`，
  **但 `layer.gradStamp` 没跟着更新** → 下一个瞬间 `canEditGradient()` 就变 false，
  `edit` 变 null，渐变条退回「准备拉新的一条」模式，滑块只改预设值 ⇒ 表现就是「改参数没变化」。
- 修法：`endGradientSpecEdit()` 与 `revertGradient()` 里，`pushPatch` 之后补 `layer.gradStamp = pixelEpoch`，
  保证「压撤销」这件事本身不会把可回改状态判死。

## 二、应用按钮被挤成一条竖线
- 第一行原来是：线性 / 径向 / 色块 → 色块 / 到透明 / 反向 / 取消 / 应用，
  1080 宽的竖屏装不下，`应用` 被挤成了一根蓝色竖条（截图里右边那条）。
- 改法：第一行只留 线性 / 径向 / 两个色块 / 到透明 / 反向；
  `取消` 和 `应用` 挪到最后一行，和提示文字并排（提示 `weight(1f)` + 省略号，按钮固定宽度不参与挤压）。
- 提示文字从两行压成一行：「点色块取色（与画笔颜色分开）」，有选区时换成橙色的「有选区：渐变只画在选区内」。

## 三、这次没做
1. 渐变重画仍在主线程（只是次数少了），超大画布拖平滑度可能还不够跟手。
2. 平滑度只作用 8 位主图；16 位缓冲那条路径还是线性。
3. 渐变仍只有两端色标、没有角度数字。
4. 没跑模拟器。

## 四、怎么验
1. 拉一条渐变 → 参数条底部应看到 `取消`（灰）和 `应用`（蓝底横条），不能再是一根竖线。
2. 别切工具，直接拖「平滑度」→ 画面应实时变柔和。
3. 松手 1 秒后再拖「缩放」→ 仍然实时生效（不能变成「第一次有效、之后没反应」）。
4. 点「取消」→ 整层回到拉渐变之前；再点撤销 → 渐变回来。
