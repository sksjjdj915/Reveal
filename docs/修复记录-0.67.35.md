# 修复记录 0.67.35（code 300）

日期：2026-11-08

## 这次改了什么（1 条：加深怎么工作）

用户的验收标准：**减淡在蓝底上出蓝、黄底上出黄**（只变亮不改色），那加深就应该同理——红底上出深红、蓝底上出深蓝。0.67.34 的加深不满足这一条，所以重做。

### 问题（0.67.34 版加深）

1. **红色几乎没反应**：上一版为了「不压成纯黑」，用每个像素**最暗通道**反推系数（`f = 地板 / 最暗通道`）。饱和红的最暗通道接近 0，反推出来的系数被放大到把压暗抵消掉了 → 红看着没变。
2. **一片黑**：线性光乘 0.53 在暗部等于砍掉大半亮度，几十个大笔头叠在一起，一堆像素同时到底 → 只剩黑块，看不出色相。

### 新做法（0.67.35）

**减淡：线性光曝光**（不变，用户已确认对味）
`线性RGB × 2^(+1.4×曝光×覆盖度)`，三通道同乘，色相严格不变。

**加深：在 Lab 的 L\* 上减**
- 先把 sRGB 转线性，用 Y 求 L\* = 116·Y^(1/3) − 16；
- 目标 L\* = L\* − 34×曝光×覆盖度（满覆盖、100% 时约 30 个 L\*，观感约 1.5 档）；
- 再由目标 L\* 反推 Y'，按 `k = Y'/Y` 三通道同比例乘（保色相、保彩度方向）；
- 下限：保护色调时 L\* ≥ 12，不保护时 ≥ 2.5。

为什么加深要单独用 L\*：曝光乘法是「按比例压暗」，亮的东西压得多、暗的东西压得少，饱和色（红、纯蓝）压完看着变化不大、而中灰直接掉一半。L\* 是感知明度，减同样的 L\* 看到的变化才一致，同时 a\*/b\*（色相与彩度方向）不动 —— 所以红只会变深红，不会褪成黑。

### 数值验证（离线复刻同一公式）

| 原色 | 加深（满覆盖、66% 曝光） |
|---|---|
| 红 (200,30,45) | (106,11,19) 深红 |
| 蓝 (90,150,220) | (54,94,140) 深蓝 |
| 肤 (230,190,170) | (162,133,119) |
| 深发 (40,35,40) | (14,11,14) 略深（暗部按感知少减） |
| 黄 (230,180,90) | (160,124,60) |

减淡同理：红 → 更亮的红，蓝 → 更亮的蓝，不会发白。

## 怎么验

1. 纯色红块上拖一道加深：应该变成**深红**，不是没反应，也不是黑块。
2. 蓝块、黄块上各拖一道：蓝变深蓝、黄变暗金，色相都要在。
3. 同一条笔迹反复涂：会越来越深（桌面端也一样，这是正常的叠加），但每一下都能看出色相。
4. 打开「保护色调」在深色区域涂：应该明显更晚变黑。
5. 减淡保持现在的表现（不该回退）。

## 仍存边界

- 饱和色压到很暗时，sRGB 会被裁掉一个通道（比如红压深后蓝通道归零），这是 8 位色域的物理限制，桌面端同样如此。
- 反复涂很多遍最终会接近黑：这是叠加的必然结果，靠「保护色调」或降低曝光控制。
