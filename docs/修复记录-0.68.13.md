# 0.68.13 参数条跟「选中的对象」走 + 渐变可以回头改

## 现象（用户 m18769）
「工具都有一个通病，我拉好渐变再想更改参数没办法回到工具面板，别的只要是新建图层的都有这种情况。」
即：参数条只绑当前工具，切走就没了；重选工具又是新建一个，不能编辑已经做出来的那个。

## 根因
1. `EditorScreen.kt` 的 `optionsStrip` 是 `when (tool) { Tool.SHAPE -> ShapeToolBar(...) }`，条子的显示完全由当前工具决定。
2. `applyGradient()`（`SketchView.kt`）把渐变直接画进 `activeLayer` 的像素，**没有记任何参数**，所以改参数对已经画好的渐变毫无作用。

## 改法

### `SketchView.kt`
- 新增 `class GradientSpec(x0, y0, x1, y1, radial, c1, c2)` + `copyOf()`。
- `Layer` 加三个字段：`gradSpec`（最近一次渐变参数）、`gradBase`（画渐变之前的像素快照）、`gradStamp`（应用时的像素版本）。
- 新增 `private var pixelEpoch`：任何一处像素被改（`touchPixels()` / `pushPatch()`）都 +1，用来判断「这层之后有没有被画过」。
- `applyGradient()` 末尾记下 `gradSpec` / `gradBase`（`before.copyOf()`，只在这一笔记录得到像素时才存）/ `gradStamp`。
- 新增三个公开方法：
  - `activeGradientSpec(): GradientSpec?` —— 当前层的渐变参数。
  - `canEditGradient(): Boolean` —— 这层还能不能回改（层被画过就 false）。
  - `updateGradientSpec(sp): Boolean` —— 参数没变直接返回；变了就「还原到 gradBase → 按新参数整层重画 → 压一条撤销（label「改渐变」）」。

### `EditorScreen.kt`
- 新增 `specTick`：`onActiveLayerChanged` 里 +1。
- `val optTool = remember(tool, specTick) { if (tool != SHAPE && sketch?.activeShapeSpec() != null) SHAPE else tool }`，
  `optionsStrip` 改用 `when (optTool)` —— 选中形状层时，即便当前是移动/画笔工具，底部也显示形状参数条。
- 渐变条条件从 `tool == GRADIENT` 改成 `tool == GRADIENT || 当前层有 gradSpec`；
  选中带渐变的层时，把 `gradRadial / color / gradColor2 / gradToTransparent` 从 spec 回填；
  切线性/径向、改颜色都直接调 `updateGradientSpec()`，画面立刻重画。

## 验法
1. 选渐变工具，在画布上拉一条 → 参数条还在；点「径向」→ 画面立刻从线性变径向。
2. 换回画笔，在图层列表里点中那个渐变层 → 底部又出现渐变条，颜色是这层用的颜色。
3. 改颜色 → 渐变整层重画，颜色跟着变；撤销能回退这一步。
4. 在渐变层上再用画笔画一笔 → 再点这层，改参数会被拒绝（不会把笔画抹掉）。
5. 画个矩形形状（会新建一层），切到移动工具，点中这个形状层 → 底部显示形状参数条，改宽高/圆角实时生效。
6. 点别的图层 → 参数条跟着换；点空白处/切工具 → 条子消失。

## 没做的
- 渐变快照只在像素数 ≤ 600 万时保存，超大画布上改不了参数（会提示）。
- 渐变没有做「颜色标尺多色」和「不透明度/混合模式」，仍是两色 + 线性/径向。
- 形状参数条在非形状工具下显示时，画布拖拽仍是当前工具的行为（不会误建第二个形状）。
- 未真机验证。
