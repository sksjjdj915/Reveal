# 0.74.30 修复：所有滤镜参数条消失（0.74.29 引入）

## 真因
0.74.29 为了「参数区独立滚动、按钮固定」，我在参数区外面套了 `Column(Modifier.weight(1f, fill = false).verticalScroll(...))`。
`weight()` 只有在**父容器高度是确定的**时候才会分配空间；而这里的父 Column 只有 `heightIn(max = …)`（wrap content），没有固定高度，于是 weight 子项被算成 0 高 —— 所有滑块行都被压成 0，看起来就是「参数条全没了」。

## 改法
把 `weight(1f, fill = false)` 换成 `heightIn(max = (maxHeightDp - 110).dp)`：
- 参数区最多只能长到这个高度，超出内部滚动；
- 标题行、底部「应用 / 复位」不参与滚动，永远可见；
- 父 Column 仍然是 wrap content，所以参数少的面板会自动收缩（不会再出现大片空白）。

## 关于「屏幕二分之一」
预算仍是 `panelMaxDp = 屏高/2 − 150`（再夹在 180~380dp）。150dp 是子工具栏 54 + 主工具栏 68 + 边距 28 的预留，所以「参数面板 + 两条工具栏」不超过手机屏幕高度的一半。

## 没做
色阶/曲线等独立大面板仍按顶部两段分页；曲线吸管、液化/变形/图案图章、裁剪与画布大小、AI 未做。0.74.x 全部只编译验证，无真机验收。
