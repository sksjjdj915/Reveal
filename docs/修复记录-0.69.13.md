# 0.69.13 界面改版 · 曲线面板操作行

## 一、这次做了什么
1. 曲线面板操作行的三处纯文字按钮换成统一的胶囊 chip：
   - 「自动」→ 胶囊（点一下按直方图切掉最暗/最亮 0.5%）；
   - 「吸管」→ 胶囊；
   - 「取样 图层 / 取样 混合」→ 胶囊，选中态（混合）会亮起蓝底。
   原来这三个是裸文字，跟旁边的滑块、数值挤成一片，点起来没有「按钮」的感觉。

## 二、这次没做
1. 曲线面板的数值输入框、参考曲线叠加、网格开关视觉没进一步调整（功能都在）。
2. 左栏逐项错开动画没做。
3. 没跑模拟器。

## 三、怎么验
1. 打开曲线 → 右边一排应该是「自动」「吸管」「取样 图层」三个胶囊。
2. 点「取样 图层」→ 变成「取样 混合」并且蓝底高亮；再点回到图层取样。
