# 0.74.62 目标⑧ 第 1 步：区域范围的「定义 / 绘制 / 描边显示 / 可再编辑」

## 数据模型（`SketchView`）
`class RegionSpec(kind, cx, cy, rx, ry, feather, name)`：kind 0 圆 / 1 椭圆 / 2 矩形，坐标是文档像素。
引擎侧：
- `regions: List<RegionSpec>`（底层 `mutableStateListOf`，面板能直接观察）
- `activeRegion: Int`（-1 = 没有）
- `regionKind / regionFeather`（工具参数）
- `regionBegin / regionDragTo / regionEnd`（按下-拖动-抬手生成；小于 4px 丢弃）
- `regionRemove` / `regionSetFeather`
- `regionMask(): Bitmap?`：按当前区域画一张全画布 alpha 遮罩（羽化用 `BlurMaskFilter`）——**下一步给调色当遮罩用**

## 交互
- 新增引擎工具 `Tool.REGION`，触摸走「按下记起点、移动改半径、抬手成范围」，不参与画笔逻辑；
- 工具栏最左侧固定一颗「范围」图标（`PINNED_TOOLS`，`tool.region`），**图标右侧一条 1dp 竖线**把它和其余工具隔开；
- 画面上已有的范围一律**高饱和描边**（选中 `#FF2D9A`，未选中淡蓝 `#33D1FF`），带很淡的填充，方便一眼看出边界。

## 参数面板
`RegionDock`：形状三选（圆/椭圆/矩形）、羽化 0~80、已有范围的横向列表（点一条就切到它）、「删除当前」。
