# 0.74.74 范围参数的真实时预览（③④）

## 做法：记住「这一刀怎么切的」
`applyFilterToActive` 里新增三样：
- `lastFilterBase`：应用前那层的原图（一份拷贝）；
- `lastFilterFn`：这次用的滤镜闭包（含全部参数）；
- `lastFilterLabel`：名字（日志/后续智能滤镜用）。

## 新函数 `previewRegionComposite(maxSide = 900)`
1. 把原图缩到 900px 以内；
2. 用**同一个滤镜**重算一次 → 得到「如果整张都调过」的结果；
3. 按**当前**范围参数（cx/cy/rx/ry/kind/feather/invert/opacity）生成一张缩小版遮罩：羽化用 `BlurMaskFilter`、反转先铺白再用 `DST_OUT` 挖洞、强度按 alpha 减淡；
4. 逐像素按遮罩 alpha 混合「滤镜结果」和「原像素」，`setPreview` 显示。

所以：**颜色不会移动**（原像素位置固定），改的只是遮罩；范围内是调过的、范围外是原样。

## 触发时机
- 羽化 / 宽 / 高 / 强度 / 反转，任何一个改动 → 立刻重算一版；
- 拖动圈的边（改大小、整体移动）→ 200ms 节流重算，圈走效果跟着走。

## 没做
1. 预览只到 900px，全分辨率要按「应用」；
2. 只在「最近一次滤镜」上生效：换工具/撤销后 `lastFilterFn` 失效（撤销会把预览清掉，这是对的）；
3. 强度仍是遮罩系数，不是调整图层的「可回改参数」；
4. 0.74.x 只做编译验证，无真机验收。
