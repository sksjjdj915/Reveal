# 修复记录 0.67.21（286）

这一版只改你报的三条（第 3、4 条按你说的不动：不同功能就是不同工具，形状类是同一个工具）。

## 1. 「选择并遮住」跑到了屏幕上方

- 原因：这个面板是直接挂在根布局里的，没有给对齐位置，所以堆在左上角。
- 改法：不再浮在根布局，而是**接管画布下方那条参数栏的位置**（`EditorScreen.kt` 里
  `if (showSelMask) SelectMaskPanel(...) else optionsStrip()`）。
- 面板本体加了高度上限 232dp + 内部可滚动（`SelectMaskPanel.kt`），内容再多也不会铺满屏幕。
- 应该看到：打开后它出现在画布下方、跟以前的工具参数条同一位置，画布完整露出来。

## 2. 打开它时，之前的工具没退

- 原因：底部选区工具的参数条还在渲染，面板又叠上来，两个界面挤在一起。
- 改法：面板打开期间底部这一条由面板独占，工具参数条整条不渲染；关掉面板（✕）后参数条回来。
- 应该看到：点「选择并遮住」→ 底部只剩这一个面板，之前那排参数不见了；点 ✕ 关掉 → 参数条回来。

## 3. 色彩范围：缩放时手指一碰就把选区改了

- 原因：`选择主体` 和 `色彩范围` 是「点一下就算」的工具，代码里在**手指按下**那一刻就执行了。
  想双指缩放时，第一根手指落下去的那一下就已经重选了一次。
- 改法（`SketchView.kt`）：按下只记位置和颜色（`shotMode` / `shotColor` 挂起），
  抬手时才判断「只有一根手指、而且移动距离小于 24px」才真的执行；
  双指抬手、手势取消都会清掉这次挂起。
- 应该看到：色彩范围/选择主体 状态下双指缩放不再改选区；单指点一下还是照常生效。

## 验证清单

1. 打开「选择并遮住」→ 面板在**下方**，画布完整；底部没有两层参数条。
2. 面板里拖羽化 → 画布实时变；点 ✕ → 参数条恢复。
3. 选「色彩范围」→ 双指放大缩小 → 选区**不变**；松手后再单点一下 → 选区才变。
4. 选「选择主体」→ 同样：双指不动选区，单点才执行。
5. 面板内容多时能上下滚，不会顶到屏幕上沿。

## 没做的

- 面板里仍是那 4 个滑块（羽化/平滑/位移/对比），没加桌面端的「智能半径 / 净化颜色 / 输出到…」其余项。
- 打开面板时左侧工具仍停在「选区」类工具（没有自动切回画笔），因为切回去反而会让画布点击变成涂色。
