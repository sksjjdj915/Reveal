# 0.74.83 参数条问题 ①：色相饱和度跟手

## 现状核对
代码里其实已经有三条路径：全图走颜色矩阵（`HueSat.applyMatrix`）、单色相带走 3D LUT（`HueSat.applyBandsLut`）、着色调色走逐像素 HSV（`HueSat.apply`）。所以「全图饱和度没反应」不是算错，而是**预览每帧都在重建 24³ 的 LUT**：LUT 表本身要 13824 次 HSV 换算，每帧都建一次，拖动时帧率被吃掉，看上去就是「不跟手、像没反应」。

## 这次改的
`HueSat.applyBandsLut` 加了 LUT 缓存：
- 用色相带六个三元的参数拼成 key；
- key 不变就直接复用上次的表（拖动同一档、重绘、拖圈都会命中）；
- key 变了才重建。

## 预期效果
- 色相带拖动：每帧只做「查表 + 三线性插值」，不再重建表，跟手明显改善；
- 全图通道：本来就是矩阵路径，一帧 < 1ms；
- 色彩平衡 / 照片滤镜：下一批再动（它们是逐像素 HSV，需要同样处理）。

## 没做
自然饱和度、色彩平衡、照片滤镜、渐变映射缺的参数；0.74.x 仅编译验证，无真机验收。
