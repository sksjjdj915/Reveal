# 0.74.43 目标①：光照效果做完整

## 文献依据
桌面端「光照效果」本质是 **bump-map 重打光**：拿一个通道当高度场，求法线，再用 Blinn-Phong 算漫反射 + 高光。参数表（桌面端）：光照类型（点光/全光/聚光）、强度、曝光度、光泽、金属质感、环境、纹理通道。

## 旧实现的问题
`lighting(src, intensity, ambient)` 只是「中心提亮、四周压暗」的径向渐变——跟光照没有关系，参数也只有两项。

## 新实现 `FilterFx.lightingAt(...)`
| 参数 | 范围 | 作用 |
|---|---|---|
| 类型 | 0 点光 / 1 全光 / 2 聚光 | 点光按距离轻微衰减；聚光衰减更强；全光正对画面（平光） |
| 强度 | 0~100 | 漫反射权重 |
| 曝光 | −100~100 | 整体明暗（`2^(曝光/60)`） |
| 光泽 | −100~100 | 高光锐度（指数 2~122，越大越硬） |
| 金属质感 | −100~100 | 正数高光染底色（金属），负数高光偏白（塑料/陶瓷） |
| 环境 | 0~100 | 暗部底噪亮度 |
| 方位角 / 仰角 | −180~180 / 0~90 | 光源方向 |
| 纹理通道 | 0 亮度 / 1 红 / 2 绿 / 3 蓝 | 用哪个通道当**高度场**（bump 高度） |

算法：`hgt = 通道亮度` → 中心差分求 `(nx,ny)`、`nz=1` 归一化 → `diffuse = max(0, n·L)` → `spec = (n·H)^光泽` → `out = base*(环境 + 漫反射*强度*曝光) + 高光*(金属?底色:白)`。全程行区间并行。

## 没做
1. 没有桌面端里的「样式预设」（三点光、日光、手电筒等 17 种）；
2. 没有「纹理通道」之外的凹凸贴图导入；
3. 光源位置固定按方位角/仰角（桌面端可直接拖光点）；
4. 0.74.x 全部只编译验证，无真机验收。
