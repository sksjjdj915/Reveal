# 0.73.9 拖动跟手（预览降采样）+ 曲线手势不再被打断 + 页标变小

## 一、色阶黑白场拖不动 / 卡
- 原因：每次参数变化都在**原尺寸合成图**（1080×1620）上跑一遍 `Levels.apply`，一帧几十毫秒，手指一动就排队。
- 改法：新增公用 `previewBase(bmp, maxSide = 900)`——把预览底图先缩到长边 ≤900，再在它上面算；`setPreview` 本来就是拉伸回图层大小绘制的，视觉一致但快了 4~5 倍。色阶、曲线、色相饱和度、亮度对比四处统一用它。

## 二、曲线加点/拖点「只能调一点点」
- 原因：`pointerInput(points)` 把点表当 key，每次 `onPoints()` 更新点表 → pointerInput 被重建 → 进行中的拖动手势被取消，所以只能动一下。
- 改法：`.pointerInput(Unit)`，手势内部用 `rememberUpdatedState(points)` 读最新值；拖动中改的是自己的 `dragList`，不再因为重组中断。

## 三、页标太小像进度条的解决方案
- 底部两条指示从「各占一半宽」改成 **两条 18×4dp 的小短条，居中排列**，一眼就是分页点，不会被误认成参数进度条。色阶、曲线都改。

没做：文字参数、液化变形、裁剪与图像大小、AI；曲线吸管/自动。
