# 0.74.66 目标⑧ 第 4 步（下半）：范围随工程保存

## 做法
- 新增 `data/RegionStore.kt`：把范围列表写成工程目录下的 **`regions.json`**（`kind/cx/cy/rx/ry/feather/name` + 当前选中下标）。
  为什么不塞进 `project.rvl`：那是图层像素包，改结构风险大；单独一个文件坏了也不影响图层。
- `SketchView.setRegions(list, active)`：清空后灌入并恢复选中项。
- `CanvasPage`：
  - 点「保存」时 `ProjectStore.save(...)` 之后紧接着 `RegionStore.save(context, projectId, v.regions, v.activeRegion)`；
  - 导入图片 / 打开文档后 `RegionStore.load(...)`，有就 `setRegions(...)` 恢复。

## 现在的完整闭环
画范围 → 拖动/改大小 → 羽化 → 调色只作用在范围内 → 保存工程 → 重开工程范围还在。
选区也能一键变范围（「由选区生成」/「由选区生成矩形」）。

## 没做
1. 范围**不进撤销栈**（画错范围只能删掉重画，不能用撤销回退）；
2. 范围名称固定（「范围」/「选区范围」），不能重命名；
3. 一个工程只存「当前选中」那一项的状态位，多选范围的关系没做（本来就是单选语义）。
