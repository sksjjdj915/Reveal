# 修复记录 0.67.31（减淡/加深：停着不动继续加深 + 白色条纹）

## 现象
- 手指停在原地不动，颜色会一直变深/变亮。
- 笔迹里出现一条条过曝的白纹。

## 根因
上一版为了消掉「竹节」，把明暗的计算从「每段新增的覆盖度」改成了「累计覆盖度」。
累计覆盖度是「这一笔到目前为止最大的覆盖值」，手指不动时它不变、但每一帧都拿它重新算一次，
于是同一处被一遍遍叠加 → 停着不动越来越深；笔迹边缘几帧的覆盖度差正好形成一条条竖直的亮纹。

## 改法
改回按「新增的覆盖度」逐段应用：
- 手指不动 → 新增覆盖度 = 0 → 画面不再变化（停留多久都不会加深）。
- 一笔之内所有「新增」加起来正好等于最终覆盖度 → 笔迹内部依旧平滑，不会再有竹节。
- 同时去掉了为累计覆盖度设计的「摊薄系数」（新增量之和本来就约等于 1，不需要再摊）。

## 怎么验
1. 在色块上按住不动 5 秒：颜色应该停在按下时的样子，不再继续变深。
2. 横着拖一道：笔迹内部均匀，没有竹节、没有竖直白纹。
3. 同一处来回涂两三道：每道重新加深一点（正常，桌面端也一样），但不会一次就过曝。
