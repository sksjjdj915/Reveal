## 02_组套组

用户观察：
1. 打开时只看到「组外的层」（白底 + 3 个圆）；
2. 关掉下面几层的小眼睛，画面没变化；
3. 关掉最上层（组外的层）的小眼睛后，出现「组套组」红色文字；

待办（未改）：语料改成「每层只在图形处有像素、其余透明」才好判断组到底有没有被画出来。已生成透明版：
`Reveal-测试PSD\透明版\A1_三层_透明.psd`、`A2_组套组_透明.psd`、`A3_三组三十层_透明.psd`（未验证）。

## 04_剪贴蒙版

用户观察：打开后是「白底 + 蓝椭圆」，剪贴层（渐变）整幅铺满，**没有剪贴效果**。

分析：**又是我的语料问题**。剪贴按的是**底层的 alpha**，我给底层画的是「整张不透明白底 + 椭圆」，alpha 全 255 → 等于没剪。用户原话：「你如果白色部分是透明通道才会有剪贴蒙版的效果」。

已补造正确版本（底层透明背景 + 椭圆）：`Reveal-测试PSD\透明版\A4_剪贴蒙版_透明.psd`（含一个不剪贴的绿点做对照）。
