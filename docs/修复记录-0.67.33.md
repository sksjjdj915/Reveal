# 修复记录 0.67.33（减淡/加深拆成两个独立工具）

## 这一版做了什么

1. **两个工具彻底分开**：减淡、加深各自一份「曝光 / 色调范围 / 保护色调」，互不影响；面板提示也分开写。
2. **减淡算法重写**：增益只跟「这一笔的累计覆盖度」有关。
   - 以前：每一小段都乘一次增益，同一像素被 8 个笔头盖到就乘 8 次 → 增益跑到 4~8 倍，暗部噪点被一起放大（花屏），笔头交叠处出现一圈圈竹节。
   - 现在：先算「涂满时的目标增益」，再按累计覆盖度只走剩下那一点。结果只跟最终覆盖度有关，与「被几个笔头盖到、算了几帧」无关。
   - 手指按住不动 → 覆盖度不再增长 → 完全不叠加。
3. **加深**：保持「三通道减同一个量」（这条你已经认可），按本帧新增覆盖度算，不会越停越深。
4. **保护色调真的生效了**：以前这个开关只改了界面文字，没进算法；现在减淡会收窄增益上限（250→238）、加深会多留暗部余量（2→26）。

## 怎么验

1. 深色头发上涂减淡：变亮、仍是蓝色，没有彩色颗粒，没有一圈圈竹节。
2. 同一处按住不动 3 秒：不变（不会越按越亮）。
3. 在平涂的浅色块上涂减淡：整道均匀，没有斑驳。
4. 减淡、加深分别把「曝光」调成 20% 和 80%：互不影响（各记各的）。
5. 开「保护色调」再涂：比关着更不容易顶到纯白/纯黑。
