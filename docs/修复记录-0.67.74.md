# 0.67.74 修复记录（笔迹跟手第一刀：间距按桌面端口径 + 描线兜底）

## 一句话
4096 上一笔画四千个笔头的老账：间距被当成「还要再乘 0.28」，实际只有笔刷直径的 3%，一笔要盖上千下。这版把间距改回桌面端口径（默认 22% 直径），并把「描一条线」的适用范围从硬度 ≥0.8 放宽到 ≥0.55（带一点柔边模糊）。

## 改了什么（都在 `app/src/main/java/com/reveal/editor/ui/SketchView.kt`）

1. **笔头间距（A2）**
   - `var brushSpacing: Float = 0.12f` → `0.22f`（桌面端默认 25%，取 22% 兼顾连续感与速度）
   - `stampQuad` 里 `brushSize * brushSpacing * 0.28f` → `brushSize * brushSpacing`
   - 删掉「大图强制 0.22」那行（已经等价，不再重复）
   - 效果：225 号笔刷一厘米的笔画，笔头数从上百个降到十几个；实测过的 4104 个笔头/一笔，预计降到 500~700。

2. **描线兜底（A1 的第一半）**
   - `canStrokeAsPath()` 的硬度门槛 `>= 0.8f` → `>= 0.55f`：半硬、半软的圆笔不再靠密集盖章，直接画一条圆头描边。
   - 硬度 0.55~0.8 时给描边加 `BlurMaskFilter`（半径 = 线宽 × (0.8-硬度) × 0.9），边缘才不会被看成「硬边直线」。
   - 仍然只对「纯圆、无纹理、无抖动、无湿边、无双笔尖、正常混合、无渐隐」的笔头生效——其余笔型照旧盖章，避免观感回退。

## 怎么验（真机）

1. 4096 那张图上，缩到整幅，用 200 号左右软圆笔快速划一道：应该**立刻跟手**，不再一段一段冒出来。
2. 同一笔放大看边缘：硬度 100 的应该是干净硬边；硬度 40~70 的应有柔和过渡，不能出现「一条硬线外面套一圈糊边」。
3. 换成纹理笔刷/湿边/双笔尖再画：观感必须和 0.67.73 一致（这些没走描线）。
4. 50 号小笔刷画细节：线条应连续，不能出现「一串珠子」（间距变大后最需要看的就是这个）。
5. 若出现珠子或断线：把「间距」滑块往小拖到 8~12% 即可，这版把间距做成了真正生效的参数。
