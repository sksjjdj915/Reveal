# 0.74.90 应用时也不再依赖「当前选中了范围」

## 问题
`applyFilterToActive` 里判断要不要按范围裁，用的是 `if (activeRegion >= 0)`。但 `activeRegion` 只在**点选了某一条范围**时才 ≥ 0；画面上有范围、你没点它的时候它是 −1。

结果：这种情况下「应用」会**完全忽略范围**，整张图都被调色——和「范围只改圈内」的预期正好相反。（这不是透明问题，但同一类判断错误：把「存在」写成了「被选中」。）

## 修法
改成 `if (regionsS.isNotEmpty())`：只要画面上有范围就按范围裁。

现在这四项判断全部统一成「看存在」：
| 位置 | 判断 |
|---|---|
| `setPreview` 叠底 | `regionsS.isNotEmpty()` |
| `drawLayerPixels` 画原层 | 无条件 |
| `applyFilterToActive` 取蒙版 | `regionsS.isNotEmpty()` |
| `previewRegionComposite` | 用 `lastFilterBase`，与范围是否存在无关 |

## 没做
0.74.x 仅编译验证，无真机验收。
