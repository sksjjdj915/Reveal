# 0.74.52 竖条纹修复 + 去掉界面品牌字样

## 一、添加杂色的竖条纹
**真因**：噪声原来按行播种 `java.util.Random(seed*31L + y)`。Java 的 `Random` 是线性同余，**相邻种子的前几个输出高度相关** —— 每行用递增 seed，同一列位置取到的值几乎一样，于是排出规则的**竖直条纹**（截图里那条条就是它）。平均分布因为取值是线性的，条纹最明显；单色只是让三个通道同偏移，条仍在。
**改法**：噪声不再用 `Random`，改成**逐像素哈希** `hashNoise(x, y, salt)`：
- 平均分布：`(hash*2-1) * 数量`；
- 高斯分布：Box-Muller（两个独立均匀 → 正态），`sqrt(-2ln u1)·cos(2πu2) * 0.35 * 数量`。
同坐标恒定、彼此独立，条纹消失，且同 seed 结果可复现。
