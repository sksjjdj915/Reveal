# 0.69.5 界面改版 · 第三级（面板继续统一）

## 一、这次做了什么
1. **渐变映射面板重做成新外壳**：改成 `RvPanel`（白色 20dp 圆角卡片、10dp 阴影），标题行右侧是 ✕；「取消 / 确定」挪到底部右侧两个胶囊按钮；副标题「按亮度取色：最黑用左端，最白用右端」跟在标题下面。
2. **色阶 / 曲线等 4 个面板统一外观**：这几块原来用的是 `MaterialTheme.colorScheme.surface` + 顶端圆角 12dp + 3dp tonal 高度（贴边、无阴影），现在全部改成纯白底 + 20dp 全圆角 + 10dp 阴影，和参数条、图层样式、调色面板保持一致。

## 二、这次没做
1. 色阶 / 曲线内部仍是原来的行布局，**没有**按「分组小标题 + 分隔线」重组（`RvGroup` 已经写好，但还没套进去）。
2. 色相饱和度、色彩平衡、照片滤镜这些面板内部没动。
3. 首页（工程列表）版式没重排。
4. 没跑模拟器。

## 三、怎么验
1. 打开渐变映射 → 白色圆角卡片、有阴影、标题带 ✕、底部有「取消 / 确定」两个胶囊。
2. 打开色阶 → 同样是白卡片圆角带阴影（不再贴边）。
3. 打开曲线 → 同上。
