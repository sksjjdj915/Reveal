# 0.70.0 布局重排（按新设计稿）

## 一、这次改了什么
1. **模式移到左侧**：新增 `ModeRail`（`ui/ModeShell.kt`），六个模式竖排、选中浅蓝圆角块；顶部那排模式栏删掉。
2. **工具移到底部**：`ToolRail` 的容器从「竖列 58dp」改成「横排整宽、高 66dp、可横向滚动」，位置从画布左侧挪到参数区上方；切模式时仍保留淡入 + 8dp 滑入。
3. **删掉左栏三颗功能入口**：「类别」「搜索」「修改」整段移除（类别层级由模式接管）。
4. **删掉重复的图层按钮**：底部条最右边那个小图层图标去掉，只留右下角那颗蓝色圆形按钮。
5. **画布和白底分开了**：`SketchView.onDraw` 先铺工作区灰 `#E7EAEE`，再按文档尺寸画白色纸张 + 1px 描边 `#CFD4DB` + 投影（投影半径随缩放折算，放大缩小都不会变成一圈黑边）。棋盘格只在文档区域外不再铺满。
6. 左栏宽度不再是 58dp 的工具列，画布横向可用宽度变大。

## 二、这次没做
1. 参数区还是旧的 `BottomBar` 形态（画笔大小/颜色那一行），**没有**做成设计稿里「工具行上方常驻参数行、可加高」的样子——用户要求「参数界面做高一点、修图模式参数面板调高」还没落。
2. 「搜索」「修改」两个入口这次直接删了，功能暂时没有新入口（`modify` 面板代码还在，只是没按钮开）。
3. 图层面板仍是旧样式，没做右侧抽屉。
4. 没跑模拟器。

## 三、怎么验
1. 进编辑器：左侧是六个模式竖排；顶部没有模式栏了。
2. 底部：工具横排（画笔/选区/橡皮…，多了左右滑动），最右是蓝色图层按钮；底部条不再有第二个图层图标。
3. 画布：外圈浅灰、里面白色纸张带描边和投影，一眼能找到画布边界。
4. 切模式：底部工具换掉，且有一次淡入滑入。
