## 目标
之前「应用」和「预览」各有一段逐像素混合代码，两段逻辑一样但分散在两处，改了这边忘了那边就会再次出现「圈外变透明」。这一版把它们合成**唯一实现**：

```kotlin
private fun compositeWithMask(base, corrected, maskA, allowAlpha, out) {
    // out.rgb   = base + (corrected − base) × mask
    // out.alpha = base.alpha        （allowAlpha 只给色带抠图用）
}
```

- `applyFilterToActive`：算出 `maskA` 后直接调用；
- `previewRegionComposite`：同样调用；
- 两处的 `ma>=250`、`ma<=5` 边界特例也收进这一个函数，不再各写一份。

## 与影视调色软件/桌面端/局部调整工具 的对应
- 蒙版只决定「这条修正算多少」→ `maskA`；
- 画面不透明度永远来自原图 → `alpha = base.alpha`；
- 羽化带就是 `maskA` 的中间值，不需要特殊处理。
