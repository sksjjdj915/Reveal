# 0.74.63 目标⑧ 第 2 步：调色/滤镜只作用于范围内

## 做法
`applyFilterToActive`（所有调色面板「应用」都走它）原来只认选区，现在多了「区域范围」这一层：
1. 主线程先取 `regionMask()`（当前选中的范围 → 全画布 alpha 遮罩，羽化已在遮罩里）；
2. 后台合成时，遮罩 alpha = **选区 alpha × 区域 alpha / 255**（求交）；
3. 没有选区、只有区域时，遮罩直接用区域 alpha（以前这种情况会走「整幅直接替换」的分支，所以范围会被忽略）；
4. 区域外一律保留原像素，区域内按 alpha 与原图做线性混合（羽化边缘因此是渐变过渡）。

## 现在能做到的
- 画一个圆 → 调色（比如色相饱和度降饱和）→ 点「应用」→ **只有圆里变灰，圆外完全不动**；
- 羽化拉到 30 → 圆的边缘是渐变过渡，不是硬边；
- 同时有选区 + 区域 → 只作用在两者交集里。

## 没做（还是分步）
1. **预览还没有按范围裁切**：拖动参数时预览图仍是整幅效果，只有点「应用」后才只落在范围里（下一步可以在 `setPreview` 里也套遮罩）；
2. 范围不能拖动/拉伸改位置与大小（第 3 步）；
3. 选区映射成范围、范围随工程保存（第 4 步）。
