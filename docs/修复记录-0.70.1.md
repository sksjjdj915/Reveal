# 0.70.1 修黑条 + 工具行归位

## 一、黑条是怎么来的
不是新界面写错了，是**旧主题一直是深色**：`ui/theme/Theme.kt` 里用的是 `darkColorScheme(...)`（background #121212、surface #1A1A1A）。之前换白只替换了代码里写死的颜色字面量，凡是用 `MaterialTheme.colorScheme.surface` / `onSurface` 的地方（底部条、部分面板、图标颜色）仍然是黑的 —— 你截图里画布上下的两条黑带就是这个。

## 二、这次改了
1. `Theme.kt` 整体换成 `lightColorScheme`：主色 #2D69FF、背景 #F7F8FA、面板白、文字 #1C2026、次级文字 #6E747C、分隔线 #DCE0E6。**所有**用主题色的旧组件（底栏、对话框、图标）一次性变白，不用一个个改。
2. 工具行挪到最底部（参数行在它上面），符合设计稿「参数在上、工具在下」的顺序。
3. 之前那次搬动把 `ToolRail(...)` 的参数缩进打平了，这次重新整理过，代码可读性恢复。

## 三、这次没做
1. 参数区还是旧的画笔条形态（颜色球 + 数值 + 笔型），没有做成设计稿那种一行两个细线滑块的常驻参数行；「修图模式参数面板调高」还没落。
2. 「搜索」「修改」入口仍是删掉状态。
3. 图层面板仍不是右侧抽屉。
4. 没跑模拟器。

## 四、怎么验
1. 进编辑器：应看不到任何黑带，底部从上到下依次是 参数行 → 工具行（白底）。
2. 工具行可左右滑，最右是蓝色图层按钮。
3. 侧边模式竖栏、画布灰底白纸都应正常。
