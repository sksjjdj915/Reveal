# 0.74.85 参数条问题 ②④：自然饱和度、照片滤镜提速

## 自然饱和度
底层本来就是 3D LUT 路径（`Vibrance.applyLut`），卡顿跟前两项同源：**每次调用都重建 24³ 表**（13824 项 × 一次 HSV 换算）。加了 LUT 缓存，key = `振动/饱和度/保护肤色` 三个值，参数不变就复用。

## 照片滤镜
原来是逐像素 `map()`：`out = base*(1-k) + filterColor*k`，900px 预览每帧 120 万次运算。
但这个式子本身是**纯线性**的，等价于一个 4×5 颜色矩阵：
```
[1-k, 0,   0,   0, fr*k]
[0,   1-k, 0,   0, fg*k]
[0,   0,   1-k, 0, fb*k]
[0,   0,   0,   1, 0   ]
```
改成 `ColorMatrixColorFilter` 一次 drawBitmap 画完（GPU 走），拖动浓度不再掉帧。数值等价，画面结果不变。
