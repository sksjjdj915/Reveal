# 0.74.73 「范围」六项改造 + 光晕入口归位

## 做了什么
1. **背景不再被隐藏**：之前预览是「用预览图顶替整层」，范围外没画任何东西，所以看起来背景被掏空/变暗。现在先按原样画一遍整层，再把预览图**裁到范围里**叠上去 —— 范围外保持原样。
2. **范围参数补「大小」**：选中范围后，参数卡里多出「宽」「高」两个滑块（4~4000px），拖了圈立即变。
3. **羽化可视化**：选中的范围多画一条**内缩虚线**，边界就是羽化带的起点，一眼能看出从哪开始渐隐。
4. **「范围」按钮固定在最左**：底部工具行改成「左侧固定区 + 竖线 + 右侧滚动区」，范围和竖线不随滚动跑，右边工具才横向滚动。
5. **圈随时能拖**：除了选中「范围」工具，调色面板开着（引擎工具退成 MOVE）时，按在圈里也能拖动；拖动即改圈，描边实时跟手。
6. **光晕工作室挪进镜头光晕面板**：调色工具栏里那颗按钮撤了，改成「滤镜 → 镜头光晕」面板里的「光晕工作室」胶囊（预设行下面），点它进工作室。滤镜子工具行里那份也撤了，避免两处入口。

## 没做（下一版继续）
1. **范围参数还没有「实时效果预览」**：改羽化/大小只是圈在变，已经烤进像素的颜色不会跟着重算 —— 因为滤镜结果是一次性写进图层的，引擎没有保存「上一次用了什么滤镜」。要做真正的实时，需要把最近一次滤镜存成可重算的「智能滤镜」，这是下一项工作。
2. **「调过的颜色留在原地」这一条还没验证到位**：现在的行为是颜色写完就固定（不会再移动），但拖圈时到底该不该重算遮罩，取决于上一条的实现方式。
0.74.x 只做编译验证，无真机验收。
