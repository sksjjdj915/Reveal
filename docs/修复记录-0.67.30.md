# 修复记录 0.67.30（减淡/加深重写）

三条反馈：竹节、近黑处花屏、加深对深色没反应。

## 根因

**1. 密集竹节**
明暗笔迹是「每一小段各算一次」，用的是「这一段新增的覆盖度」。同一处被好几个笔头盖到，就一层层各叠一次，笔迹上出现一排密集的月牙/竹节。

**2. 近黑处彩色花屏**
两个原因叠加：
- 旧算法是「三个通道乘同一个系数」提亮。暗部像素只有 1~2 的差值，乘 2~8 倍后被放大成十几、二十几，相邻像素立刻差得很明显，看着就是彩色雪花。
- 半透明像素（alpha 很小）存回位图时会被预乘再反算，误差本来就大，再被放大就成了乱七八糟的彩色点。

**3. 加深对深色没反应**
旧算法把「目标明度」定成 0.32，比 0.32 更暗的颜色算出来「剩余空间 = 0」直接被跳过——所以深色完全不动。

## 改法

- **加减同一个量**（桌面端的曝光本质）：减淡 `+ (255−亮度)×强度`，加深 `− 亮度×强度`。三个通道加/减同一个数，通道之间的差不变，暗部就不会被放大成噪点；暗处加得少、亮处加得多，像曝光。
- **不许撞墙**：加量不超过最亮通道的余量（防先撞 255），减量保留最暗通道 2 的余量（防色相被抹平）。
- **改按累计覆盖度算**，并按「一个像素会被几个笔头盖到」把单次强度摊薄（`spacing / 2r`，默认约 0.125）。这样笔迹内部平滑，没有竹节。
- **跳过 alpha < 12 的像素**：太透的像素存回时误差大，不碰它。
- 力度带改成平滑权重（阴影 `(0.62−L)/0.62`、高光 `(L−0.38)/0.62`、中间调 `1−|L−0.5|×1.6`），不再有「最低 25%」的保底，选阴影时亮部真的不动。

## 怎么验

1. 中灰上横拖一道减淡：笔迹内部均匀，没有一排月牙。
2. 近黑处（比如暗部阴影）用减淡涂：变亮，但没有彩色噪点/雪花。
3. 深红、深蓝上用加深涂：能变暗且还是深红、深蓝，不是不动、也不是变黑。
4. 切「阴影 / 高光」再涂：应该只影响对应的亮度带。
