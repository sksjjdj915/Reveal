# 0.74.20 子工具目标 ②：球面化

## 文献/成熟算法
桌面端的「球面化」是把画面当成贴在球面上：半径映射用 `sin(π/2 · t)`（正值为向外顶成球，负值用 `tan` 的反向映射向内凹），端点 `t=0` 与 `t=1` 都连续，因此不会出现一圈硬边。这正是常见 bulging shader 的写法（`r' = sin(r · π/2)`），也是球面折射的正交投影近似。
旧实现：中心写死画面正中、半径写死 `min(w,h)/2`、没有方向模式。

## 这次补的参数（`FilterFx.spherizeAt`）
| 参数 | 范围 | 说明 |
|---|---|---|
| 数量 | −100~100 | 正数向外顶、负数向内凹 |
| 模式 | 0 正常 / 1 水平 / 2 垂直 | 对应桌面端的三种球面化方向 |
| 中心 X % | 0~100 | 球心横向位置 |
| 中心 Y % | 0~100 | 球心纵向位置 |
| 半径 % | 5~200 | 影响范围（相对 min(w,h)） |

水平/垂直模式是把另一轴的距离压到 0，只在单方向产生球形位移（和桌面端的效果一致：像把画面卷成圆柱而不是球）。
