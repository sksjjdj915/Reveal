# 0.74.2 调色面板：参数一行一个 + 跟手预览 + 照片滤镜取色

## 一、色相饱和度 / 亮度对比不再挤
两个面板的参数从「并排三列」改成**一行一个**（`LevelRow`：标签 56dp + 滑块撑满 + 数值 48dp）：
- 色相饱和度：色相 / 饱和度 / 明度
- 亮度对比：亮度 / 对比度
拖一格变化小了一个数量级，容易微调。

## 二、曝光/自然饱和度/黑白/色彩平衡/照片滤镜/色调分离 的预览为什么「抬手才变」
这些走的是通用面板 `FxSpecDialog`，它的预览里写了 `delay(60)`——手一直动，每次都被下一个事件取消掉，等到停手 60ms 才真正算了一次。
- 改法：**删掉 delay**，参数一变立刻算并 `setPreview`，再补一次 `invalidate()` 确保引擎马上重绘。
- 底图仍是缩到长边 700 的小图，单帧只算这一份，不会因为全尺寸而卡。

## 三、照片滤镜的滤镜色改成取色面板
- 原来是一排 9 个小圆点（只能在这 9 个色里挑）。
- 现在独立成一个面板：一个 34dp 色块，**点它弹完整取色器**（方形色板 + 色带，和画笔取色同一套），选完立刻按新颜色重算预览；浓度滑块 0~100% 也是实时。
- 「应用」写入图层（可撤销），「取消」清预览。

## 没做
- 单独的「自然饱和度」仍是 `FxSpecDialog`（已无 delay，应跟手）；若还慢，下一步把它也拆成独立 Dock。
- 文字参数、液化变形、裁剪与图像大小、AI 未接。
