# 0.72.3 首张图片＝打开图片，之后＝置入

## 一、改了什么
1. `SketchView` 新增 `fun openImageAsDocument(src: Bitmap): Boolean`：把这张图直接做成**整份文档**（一个「图片」图层，尺寸＝图片尺寸，清空撤销栈，`fitToView()`，通知界面刷新）。不再先 `newDocument` 建一张白纸 —— 之前「导入后多出一个空白图层」就是 `newDocument` 建的白底 + `addImageLayer` 叠上去。
2. 导入回调按状态分流：
   - 画布还没有图层（`v.layers.isEmpty()` 或活动层没位图）→ `v.openImageAsDocument(bmp)` = **打开图片**
   - 已经有内容 → `v.addImageLayer(bmp, "置入图片")` = **置入图片**
3. 保存/图层/导出都沿用原路径（`openImageAsDocument` 同样设 `hasDocument = true` 并触发 `onDocChanged` / `onActiveLayerChanged`）。

## 二、这次没做
1. 其余功能还没接：色阶 / 曲线 / 色相饱和度 / 亮度对比 面板、文字参数、液化与变形专属参数、裁剪与图像大小、PSD 读写、AI。
2. 打开软件时画布区仍是浅灰空白 + 白纸（`hasDocument=false` 时引擎不画纸），没有「导入提示」文字。
