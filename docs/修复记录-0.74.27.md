# 0.74.27 说明不再单开一页 / 查找边缘文案修正

## 一、说明从「隐藏的一页」挪到参数面板里
- 删掉子滤镜面板的「参数 / 说明」两个页签，**默认就是全部参数**，不再要多点一下才能看到说明。
- 说明文字放到**底部「应用 / 复位」右边的空白区**（`weight(1f)`、10sp、最多 3 行）——那块本来就空着，正好放简短描述。
- 面板高度改成按屏幕算：`(屏幕高 / 2) − 130dp`，再夹在 200~460dp 之间。130dp 就是子工具栏(54) + 主工具栏(68) + 边距的预算，所以**面板 + 两条工具栏不会超过屏幕一半**，同时面板比之前略高（参数多时不会被挤成一条缝）。

## 二、查找边缘没有参数却像有参数说明
- `findEdges` 的说明原来写「把轮廓勾勒成黑线，效果像铅笔描边」，看起来像还有别的可调项。现在改成：
  「把轮廓勾勒成黑线（3×3 Sobel 梯度）。这个效果本身没有可调参数，直接点「应用」」。
- 这类「无参数滤镜」面板现在只有一行提示 + 应用/复位，高度自动缩到最小。

## 三、没做
色阶 / 曲线 / 色相饱和度这些**独立大面板**的分页仍然是顶部两段（直方图｜伽马、曲线｜预设），这次只动了子滤镜面板；曲线吸管、液化/变形/图案图章、裁剪与画布大小、AI 仍未做。0.74.x 全部只编译验证，无真机验收。
