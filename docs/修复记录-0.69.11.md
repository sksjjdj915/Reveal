# 0.69.11 界面改版 · 顶部状态栏

## 一、这次做了什么
1. **顶部状态栏按浅色重做**（`ui/TopStatusBar.kt`）：
   - 背景改成纯白（原来是浅灰 #F4F5F7，和模式栏、画布糊在一起分不出层）；
   - 高度 32 → 36dp，左右内边距 12/4 → 14/6；
   - 工程名 11sp 浅灰 → 12.5sp 深色中等字重 —— 原来是给深色底用的 #C9CED6，浅底上几乎看不见；
   - 撤销 / 重做 / 保存 / ? / ⚙ 五个按钮：文字颜色改成正文灰（可用）/ 更浅的灰（不可用），按钮改成 10dp 圆角热区，宽 58/34 → 54/32，禁用态不再拦点击事件（统一走 clickable 与否）。
2. 这样「顶部状态栏（白）→ 模式栏（浅灰）→ 画布（棋盘格）」三层有了明确分界。

## 二、这次没做
1. 模式栏自身的背景/选中态没跟着微调（当前态是蓝底白字，已可用）。
2. 曲线面板其余部分（数值框 / 取样 / 参考曲线 / 网格）没重排。
3. 左栏逐项错开动画没做。
4. 没跑模拟器。

## 三、怎么验
1. 进编辑器 → 顶部一条白底状态栏，左边工程名是深色、清楚可读。
2. 有可撤销步骤时「↶ 撤销」是正常灰，没有时明显变浅。
3. 三个层级（状态栏白 / 模式栏浅灰 / 画布棋盘）应该有分界，不再糊成一片。
