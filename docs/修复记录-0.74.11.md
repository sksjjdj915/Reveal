# 0.74.11 照片滤镜跟手 / 自然饱和度不卡

## 一、照片滤镜：先在主线程逐像素算，还在每帧重开
- 旧写法 `LaunchedEffect(color, density, base) { … }`：`LaunchedEffect` 默认跑在**主线程**，而且每拖一下就被取消重开，上一次没算完就丢；480px 逐像素插值 + 主线程 = 卡顿 + 抬手才看到结果。
- 改法两条：
  1. **算法**：照片滤镜本质是 `out = c*(1-k) + f*k`，是纯线性缩放 —— 可以直接写成 4×5 颜色矩阵（`ColorFx.photoFilterMatrix`），用 `ColorMatrixColorFilter` 一次画完（GPU）。
  2. **调度**：改成常驻循环 + `Dispatchers.Default`，只在快照变化时重算，12ms 一轮。

## 二、自然饱和度：同样是「每帧取消 + 主线程」
- 自然饱和度没法完全矩阵化（要按「已有饱和度」加权、还要护肤色），逐像素不可避免；但原来也写成了 `LaunchedEffect(vib, sat, protect, base)`，等于每拖一下取消重开、且在主线程算 → 卡。
- 改法：换成常驻泵 + `Dispatchers.Default`，参数打包进 `rememberUpdatedState` 快照，只有数值真变了才算。
