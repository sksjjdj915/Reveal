# 0.68.5 修复记录 · 变换条挤掉按钮 + 放大后变换框跑出屏幕

用户 2026-11-09 反馈两条：
1. 「变换的其他参数没有了」——加了角度滑块后，那一行塞不下，`取消 / 应用` 被挤到屏幕外，看着等于参数没了。
2. 「放大画面变换的部分会跑到画布外」——画布放大到 200% 以上再进变换，图层四角的把手在屏幕外，抓不到。

## 一、变换条改两行（`ui\EditorScreen.kt`）

原来一行：标题 + 150dp 角度滑块 + `TextButton` × 4。Material 的 `TextButton` 最小宽度 64dp、`ThinSlider` 固定 150dp，1080 宽竖屏（约 393dp）装不下，右边两个按钮直接跑出屏幕。

改成两行，全部放进去：

- 第一行：`自由变换` 标题 + `角度 12°` + 细线滑块（112dp）+ `归零`
- 第二行：提示文字（`拖角等比 · 拖边拉伸 · 双指缩放旋转 · 双击确认`，超长省略）+ `切透视` /（透视时）`复位` / `取消` / `应用`

按钮全部换成 `Text + Modifier.clickable`（不再用 `TextButton`，没有 64dp 最小宽），字 11~12sp。

## 二、进变换时自动缩到能看全（`ui\SketchView.kt`）

- 新增 `private var tfViewSaved: Matrix?`：进变换时记下当前视图矩阵。
- 新增 `private fun ensureTransformVisible()`：取变换后四角的文档包围盒，乘当前 `viewScale()` 得到屏幕尺寸；超出可用区（宽高各留 46px 边距、上方再多留 44px 给模式标签）就 `viewMatrix.postScale(f, f, 中心)` 等比缩到刚好装下（`f` 夹在 0.05~1，只缩不放）。
- `beginTransform()` 末尾调用它。
- 新增 `private fun restoreTfView()`：`cancelTransform()`、`applyTransform()`（普通分支与透视分支）退出时还原进变换前的缩放，不改变用户原来的视图。

## 验法

1. 变换 → **两行都能看到，「取消 / 应用」在屏幕内**。
2. 缩放到 400% → 进变换 → 画布自动缩小到整个变换框都在屏幕里，四角和 ↻ 都能抓。
3. 取消 → 缩放回到 400%（原来的视图没被改）。
4. 应用 → 同上，视图也还原。
5. 拖角度滑块、拖 ↻、双指旋转，底部角度数字都实时跟。

## 没做的

- 变换条里没有「位置 X/Y、宽/高」数字框（桌面端的变换选项栏有）；现在只能用手指拖。
- `ensureTransformVisible()` 只在**进变换那一刻**做一次；进去以后再拖到很大，框还是会顶出屏幕。
