# 0.69.7 界面改版 · 参数面板分组

## 一、这次做了什么
1. **色阶面板按功能分组**：加了三处小标题 + 1dp 分隔线 ——
   - `通道`（RGB / 红 / 绿 / 蓝）
   - `输入色阶`（黑场 / 灰点 / 白场）
   - `输出色阶`（黑场 / 白场）
   原来这三段只有一行灰色小字，没有分隔，跟滑块混在一起读不出层次。
2. **曲线面板通道行对齐新规范**：通道标签字号 11 → 10sp、颜色改用 `Rv.textFaint`，跟色阶的分组标签统一。

## 二、这次没做
1. 曲线的其余部分（数值框、取样、参考曲线、网格开关）内部结构没重排。
2. 色相饱和度 / 色彩平衡 / 照片滤镜 / 色彩范围 内部没动。
3. 首页「QQ/微信发来的」卡片区、多选态没跟着重排。
4. 左栏逐项错开动画没做。
5. 没跑模拟器。

## 三、怎么验
1. 打开色阶 → 能看到「通道 ─────」「输入色阶 ─────」「输出色阶 ─────」三条分段标题。
2. 打开曲线 → 通道标签变淡变小，其余功能不变。
