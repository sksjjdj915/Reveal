# 0.68.12 组样式改成「整组算一个轮廓」

## 现象
给组加投影/描边/外发光，组里的图层看起来还是各投各的，stacked 一圈圈叠加，
不像桌面端那样整组只有一圈轮廓（0.68.11 是先把样式逐层写到成员身上，所以每层各来一份）。

## 根因
- 组头（`sectionType == 1/2`）的位图是空的，它只是「书签」。
- 0.68.11 的做法是：把样式复制给组内每个成员 → 每个成员各自算自己的影子/描边，再各自合成。
  结果就是三个字的组会出现三层影子，边上的还互相盖。

## 改法（`app/src/main/java/com/reveal/editor/ui/SketchView.kt`）
1. 新字段挂在 `Layer` 上：`groupCache`（拍平后的缓冲图）、`groupKey`（缓存键）、
   `groupProxy`（借它跑 `styleOverlay`/`styleTop` 的缓存）、`groupProxyStamp`。
2. `private fun groupBitmapFor(header, from, until): Bitmap?`
   —— 把组成员画进一张同尺寸的 ARGB 图，缓存键 = `compositePixelStamp * 1000003 + styleVer`；
   画面或样式没变就直接复用，不每帧重算。绘制期间置 `renderFullDoc = true`，
   让 `layerInViewport()` 不做屏幕剔除（否则画面外的成员会被漏掉）。
3. `private fun groupStyledLayer(h, bmp): Layer`
   —— 组样式用的临时层：位图 = 整组拍平结果，样式参数由 `applyStyleTo(proxy, styleParamsOf(h))` 照抄，
   只在 `styleVer` 变化时才重抄一次，缓存不会每帧失效。
4. `drawLayerRun()` 的组分支：`hasStyle(h)` 为真时改走
   `saveLayer → styleOverlay(proxy) → 画拍平图 → styleTop(proxy) → restore`，
   即「整组当一层」算阴影/描边/发光，然后组自己的 `alpha` 与混合模式照旧作用在这一层上。
5. `setLayerStyle()` 回退成「只写组头这一层」，不再往成员身上复制；
   顺手清掉 0.68.11 留下的残留：成员样式 == 组头旧样式的那些层清回默认
   （用户自己单独设过样式的成员不会被误清）。组样式一变同时把 `groupKey`/`groupProxyStamp` 作废。

## 验法
1. 组里放两个有重叠的图层，给组加投影（模糊 30、左右 6、上下 8）→ 只看到整组一圈影子，不是两层各一圈。
2. 组里放文字，加描边 4px → 描边只包住整组的边界，两块之间的接缝里没有多余描边线。
3. 外发光 40 → 一圈柔和光晕，不是每个成员各一圈。
4. 加完样式后往组里画一笔 → 影子跟着更新（缓存按合成版本失效）。
5. 拖动组整体移动 → 影子跟着走，不残留在原位。
6. 组头不透明度调到 50% → 影子跟着一起变淡。

## 没做的
- 组样式的「内阴影/内发光/斜面浮雕/光泽/图案叠加」也是按拍平图算的，但它们是在组内部生效，
  效果和桌面端基本一致，没有单独验。
- 组有蒙版时，样式与蒙版的叠加顺序未特殊处理（先样式后蒙版，和单层一致）。
- 未真机验证，只在模拟器外的编译层面通过。
