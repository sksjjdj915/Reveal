# 0.74.46 目标④：浮雕效果补角度/高度/数量

## 文献依据
桌面端「浮雕效果」三个参数：**角度 −360~360、高度 1~10、数量 1~500%**。
原理是**方向导数**：沿光照方向取亮度差分（前 − 后），「斜面朝光」为正、「背光」为负，再叠到中灰 128 上——所以出来是灰底浮雕。高度决定差分采样距离（浮雕的厚薄），数量决定对比强度。

## 旧实现
`emboss(src, amount)`：固定沿 45° 取 `(x-1,y-1) − (x+1,y+1)`，只有「强度」一个参数。角度和厚度都锁死，所以只能出「一种斜度、一种厚度」。

## 新实现 `FilterFx.embossAt(src, angleDeg, height, amount)`
| 参数 | 范围 | 作用 |
|---|---|---|
| 角度 | −360~360 | 光从哪个方向来（差分方向） |
| 高度 | 1~10 | 差分采样距离，越大浮雕越厚 |
| 数量 | 1~500% | 对比强度 |

差分偏移 `dx = cos(角度)*高度`、`dy = sin(角度)*高度`，亮度差 `(前 − 后) * 数量/100 * 3/高度` 后叠 128。行区间并行。

## 没做
桌面端还有个细节：浮雕会把结果当「灰色 + 保留原色可选」；我们一直是灰度输出（与桌面端默认一致），没有做「保留颜色」变体。0.74.x 全部只编译验证，无真机验收。
