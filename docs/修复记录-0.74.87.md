# 0.74.87 自检：调色把不透明像素写成半透明就记日志

## 为什么加
「圈外消失」这件事已经改了五版，每次都是靠猜哪条路径在改 alpha。现在让程序自己查：每次**正式应用**调色类滤镜（`allowAlpha = false`）之后，逐像素比较「应用前 alpha == 255」和「应用后 alpha < 255」：

- 数出来 > 0 就往诊断日志写一条：
  `alpha 警告：<滤镜名> 把 N 个不透明像素写成半透明（共 M）`
- 右上角「日志」按钮里能看到，配合版本号能定位是哪一版、哪一条路径在漏。

## 不做什么
- 不自动修正（宁可暴露问题，也不悄悄盖掉）；
- 色带抠图这类**本来就要改 alpha** 的滤镜跳过检查（`allowAlpha = true`）；
- 预览路径不查（预览每帧都跑，加扫描会拖慢拖动）。

## 怎么用
1. 选范围 → 调一个色阶/色相 → 点「应用」；
2. 打开「日志」，搜 `alpha`；
3. 有警告行＝这条路径还在漏 alpha，把那行发我，我直接定位；
4. 没有警告行、但画面还是透 → 那就是绘制/预览层的问题，不是像素被改坏。

0.74.x 仅编译验证，无真机验收。
