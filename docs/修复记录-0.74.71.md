# 0.74.71 顶栏常显版本号（排查「和上一版一样」）

## 为什么加这个
上一版我改了三处（色带抠图、范围反转/强度、光晕工作室），但反馈「一个变化都没有」。我核对过安装包本身：解开 `Reveal-0.74.70-debug.apk` 的 dex 能搜到 `光晕工作室`、`色带抠图`、`flareStudio`、`bandCut` 这些字符串，说明**包里的确是新代码**。那问题只可能出在「实际跑的不是这个包」——最常见就是：
1. 手机上还留着旧安装包，装的是旧的；
2. 应用分身 / 两个图标，点开的是另一个；
3. 装完没重启应用。

为了以后一眼能确认，顶栏中间现在常显 `版本名 (versionCode)`，例如 `0.74.71 (499)`。

## 没做
版本号只是显示，没有做「检查更新」；也没法从代码侧判断用户装的是不是最新包。
