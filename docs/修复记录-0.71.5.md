# 0.71.5 模式栏固定左侧 + 参数卡片圆角

1. 去掉左下角悬浮窗，换成**固定在屏幕左侧中间**的模式栏（`ModeRailPinned`）：白色圆角竖栏，六项带图标 + 文字，选中项浅蓝底；顶部一颗 `‹` 收起按钮。
2. 收起后只剩一颗 44dp 圆按钮（显示当前模式图标），点一下重新展开。
3. 参数区从「贴底直角条」改成**四周圆角的浮动卡片**（左右各 8dp、底下 8dp、圆角 20dp），和画布、模式栏的收边一致。
4. 六个模式都套上同一张参数卡：
   - 抠图：容差 / 羽化 + 羽化应用 / 全选 / 反选 / 取消 / 到新层
   - 绘制：大小 / 不透明
   - 修图：沿用「大小 / 不透明」这一套（内容下一步细分）
   - 调色 / 排版 / AI：同样的卡片外壳，里面先写「参数面板还没接」

没做：调色 / 排版 / 修图参数的具体项；模式栏收起状态不做记忆（重启恢复展开）。
