# 修复记录 0.67.28

三条反馈的处理。

## 1. 加深还是像黑笔（用户：「画到不同颜色都是黑色，没有色相变化」）

原因：上一版给加深加了「收敛」，但收敛的目标是明度 0，也就是反复涂一定压到全黑；色相虽然乘的是同一个系数（理论上不变），可明度到 0 之后就没有色相可看了。

改法：加深的目标明度改成 **0.22**（暗但还看得见颜色），并缩小每段的下压幅度（0.55 系数）。减淡目标仍是 0.94。

应该看到：彩色块上涂加深，颜色越来越暗但仍是同一个色相（红变深红、蓝变深蓝），不会变纯黑块。

## 2. 颜色替换有边缘，像描了一道轮廓

原因：替换时按笔尖覆盖度线性混合（`c/255`），笔尖软边会把边缘像素混成「半新半旧」的中间色，一圈下来就是一道浅轮廓。

改法：覆盖度改成陡曲线（`c/110` 到满），软边只留 1~2px，中间直接给满色。

应该看到：替换区域的边缘干净，不再有一圈淡淡的描边。

## 3. 背景橡皮的效果（看截图判断）

**结论：不对，有两处问题。**

- **一串月牙/珠子**（截图里天空被擦出的那些白色椭圆链）：真 bug。每一小段擦的时候都是按「这一段新增的覆盖度」往下减 alpha，同一处被反复经过就一层层往下擦，笔尖的软边因此被一段段印出来。
  改法：一笔之内每个像素记「这一笔吃到的最大覆盖度」+「下笔前的 alpha」，永远按这两个值算目标 alpha。反复经过同一处不会叠加，擦除一次到位。
- **整块的方形硬边**（截图里天空和栏杆那几块直边）：容差以前是硬开关，超一点点就整像素跳过，所以被「限制」框住的那片边界是笔直的。
  改法：超出容差还有一段软过渡（宽约容差的 0.8 倍），边缘不再是一条直线。

另外要说明「一次」和「连续」的区别，这是取样方式本身的差异，不是 bug：

- **取样：一次** —— 落笔时取一次颜色，之后整笔都按这个颜色擦。底色是渐变（比如这张图的天空，从紫到橙）时，只有和落点颜色相近的那一带会被擦掉，其它颜色擦不动，所以边界会跟着色带形状走，看着一块一块。想擦渐变就用「连续」。
- **取样：连续** —— 每一小段都重新取笔下的颜色，所以能跟着渐变一路擦过去。截图右下角那种大片擦除应该用这个。

裙子上那片透明如果是同一支笔擦的，这一版也会一起变干净（同样的月牙问题）。

## 怎么验

1. 彩色块上用加深涂五下：应该变深但仍是原色相，不是黑。
2. 红块用颜色替换涂一道：边缘没有浅色描边。
3. 渐变天空上用背景橡皮**连续**取样横着拖一道：整片均匀擦掉，没有珠子、没有方块边。
4. 换回「一次」取样再拖：会看到只擦掉同色那一片（这是正常的），但边界应该是软的、不是刀切。
