# 模拟器测试记录（0.66.24 起）

真机没有，先在 Windows 上的 Android 13（API 37）模拟器里跑，设备名 `Medium_Phone_API_37.0`，
1080×2400 / density 420 / 堆上限 576 MB。每轮都在 `app-debug.apk` 装上之后跑。

## 二、界面上点过的（0.66.24）

- 左栏 13 个类别都能展开；「绘制 / 选区 / 图层 / 变换 / 调色」逐个条目点过，**没有崩溃**。
- 调色类面板都正常弹出（曝光度、自然饱和度、色彩平衡、照片滤镜、色调分离、渐变映射、通道混合器、色调均化、替换颜色…），标题和提示文字都对。
- 变换类：图像大小 / 画布大小 / 拉直 / 内容识别缩放 面板都能开。
- 图层：新建、删除、上移下移、拼合、盖印、栅格化、拷贝样式 都能点。
- **存盘 → 杀进程 → 重开**：工程还在，图层数 3（含一个「亮度/对比度」调整层，说明调整层也随工程存下来了），图层筛选条（共 3 / 显示 3）正常。
- **滤镜 → 反相**：诊断日志记到 `filter name=反相 depth=8`，画面确实变了；再反相一次回到原样。
- 导出面板：PNG / WebP 无损 / WebP 有损 / JPEG / BMP / TIFF / PDF 七种格式列得出来，有「输出尺寸 100%」。

## 四、release 构建（打商店包用）实测

`gradlew assembleRelease` 能过（R8 混淆 + 资源压缩），产物 `app-release.apk` **2.41 MB**（debug 是 18.5 MB）。
装到模拟器上跑：**自检 67 通过 / 0 失败**，说明混淆没有破坏 PSD 解析、算法和存储。

但 release 目前**用 debug 证书签名**（`apksigner verify` 读出来 `CN=Android Debug`），
因为工程里只有 `.keys/debug.keystore`，没有 `keystore.properties` + 正式 keystore。
商店不收 debug 证书的包，这是上架前必须解决的。
