# 0.74.88 找到「圈外变透明」的真凶：先 clip 再画原层，等于范围外什么都没画

## 真凶（绘制层，之前几版都没改到点子上）
`SketchView.drawLayerPixels` 画预览时是这么写的：

```
if (rg != null) { canvas.save(); canvas.clipPath(椭圆) }   // ← 先裁剪
canvas.drawBitmap(bmp, ...)                                // ← 再画原层
canvas.drawBitmap(preview, ...)                            // ← 再盖预览
canvas.restore()
```

**原层也被画在裁剪区里**。所以一旦选了范围：
- 圈内：原层 + 预览 → 有内容；
- 圈外：整块被 clip 掉，**原层根本没画** → 露出棋盘格。

这跟 alpha、跟蒙版公式都没关系，是「画顺序 + 裁剪范围」写错了。前几版一直在改 alpha，所以怎么改都还是透。

## 修法
把原层移到 clip **之前** 画：

```
画整层原样（无裁剪）
if (有范围) { canvas.save(); clip(范围) }
画预览（只能往上盖）
restore()
```

结果：预览图无论在不在范围内、带不带透明，**画面上都不会出现缺口**——它只能覆盖，不能擦除。

## 为什么前几版没发现
我一直在「谁把 alpha 写成 0」这条线上排查（也加了自检日志），而实际是「谁根本没画」。这条教训记下了：**画面缺块的第二类成因是绘制顺序/裁剪，不是像素值**。

## 没做
0.74.x 仅编译验证，无真机验收。
