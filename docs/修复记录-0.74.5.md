# 0.74.5 全图通道补参数 / 预览提速 / 黑白独立面板

1. **色相饱和度「全图」通道有参数条了**：新增 `masterHue/masterSat/masterLight`，全图显示 色相/饱和度/明度 三行；六个色相带各自仍是三行，互不干扰。
2. **「拉参数没反应、几分钟后才变」**：`FxHueSatDock` 的预览也换成常驻循环（`rememberUpdatedState` 快照 + `while(true){…delay(12)}`），不再被下一次参数变化取消；计算放 `Dispatchers.Default`。
3. **预览底图 900 → 480**：六色相带、自然饱和度、黑白这些全像素算法都在这张缩图上跑，单帧成本降到原来的约 1/3.5，拖动跟手。
4. **黑白做成独立面板**（原来走通用面板，只有点应用才变）：
   - 红/绿/蓝 三个权重滑块（0~300，默认 30/59/11），一行一个；
   - 参数一动立刻预览（同样是常驻循环）；
   - 按钮：应用 / **重置（回 30/59/11）** / 取消；
   - 面板顶部有说明：「三个权重决定红绿蓝各占多少亮度」。

没做：曝光度/色彩平衡/照片滤镜/色调分离/渐变映射的说明文字与参数补全（下一步按颜色类面板逐个补）。
