# 0.74.44 目标②：胶片颗粒补「高光区域」

## 文献依据
桌面端「胶片颗粒」三个参数：**颗粒 0~20、高光区域 0~10、强度 0~10**。它和「添加杂色」的区别有两点：
1. 颗粒是**成团**的（低频 + 高频两层噪声），不是逐像素白噪声；
2. **高光区域**控制亮部保留多少颗粒——真实胶片的银盐颗粒在亮部反而更明显。

## 旧实现
只有「数量」一个参数，`amount*42*(0.4+0.6*(1-l))` 是逐像素 `nextGaussian` 白噪声，而且用共享 `Random` 顺序遍历（无法并行、也不可复现）。

## 新实现 `FilterFx.filmGrain(src, grain, highlight, strength, seed)`
| 参数 | 范围 | 作用 |
|---|---|---|
| 颗粒 | 0~20 | 颗粒尺度：0 细如砂纸、20 明显成团 |
| 高光区域 | 0~10 | 0 亮部几乎无颗粒；10 亮部与暗部等量 |
| 强度 | 0~10 | 总幅度 |

算法：两层确定性哈希噪声（`hashNoise(x/3, y/3)` 低频 + `hashNoise(x, y)` 高频，比例 0.6/0.4）→ 权重 `(1-l) + l*高光区域` → 幅度 `(2+颗粒*26)*强度*权重`。全部行区间并行，且同一 seed 同图结果恒定（不再每帧跳）。

## 没做
没有桌面端的「单色颗粒」开关（我们一直是三通道同偏移，等同单色）；0.74.x 全部只编译验证，无真机验收。
