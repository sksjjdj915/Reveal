## 一、这一版的核心：参数条跟不跟手（新的，先测这块）

改的根因：参数存在普通 `var` 里，画笔读它有效果，但参数条读同一个值 Compose 不知道它变了 → 界面永不刷新。现在 89 个参数全部换成 Compose 状态托底。

判据统一是：**拖滑块时，滑块本身和右边数字要实时跟着动；点开关时，文字/颜色要立刻变。**

| # | 怎么做 | 应该看到 |
|---|---|---|
| 1 | 画笔 → 参数：拖 大小 / 不透明度 / 硬度 / 流量 / 间距 | 滑块和数字一起动，笔迹大小/软硬同步变 |
| 2 | 画笔 → 参数：拖 角度、抖动那几项、纹理深度 | 同上；笔迹形态跟着变 |
| 3 | 橡皮：拖 大小 / 硬度 / 不透明度；点 画笔 / 铅笔 / 块 | 数字动；点模式时选中项变蓝 |
| 4 | 仿制图章 / 修复画笔：拖 不透明度、修正半径 | 数字动，落笔效果跟着变 |
| 5 | 色彩替换：拖 容差；背景橡皮：拖 容差、边缘阈值 | 数字动 |
| 6 | 混合器：拖 湿度 / 载入 / 混合 / 前景色 / 流量（四个滑块都在） | 四个都能拖、数字都动 |
| 7 | 魔棒：拖 容差；快速选择：拖 笔刷大小 / 容差 | 数字动 |
| 8 | 减淡 / 加深：拖 曝光、大小；点 保护色调 | 数字动；「保护色调：开/关」文字切换 |
| 9 | 视图：切 网格开关、拖 格数、切 标尺开关 | 画面网格/标尺立刻出现或消失 |
| 10 | 点 通道：红 / 绿 / 蓝 / RGB | 画面立刻变对应灰度，回 RGB 恢复彩色 |

> 如果某一项拖了还是不动，直接告诉我「第几条 + 哪个参数」，我单点修。

| # | 怎么做 | 应该看到 |
