# 0.74.23 / 0.74.24 子工具目标 ⑥⑦：镜头光晕 · 水彩

## ⑥ 镜头光晕（0.74.23，`FilterFx.lensFlareAt`）
**文献**：经典 flare 模型（Knoll 等人的镜头光晕生成）＝ 中央辉光 + 沿「光源→画面中心」轴排布的一串鬼影圆盘 + 一圈彩虹光环；桌面端「镜头光晕」正是这套参数化。
**补的参数**
| 参数 | 范围 | 说明 |
|---|---|---|
| 亮度 | 0~300% | 同桌面端 |
| 镜头类型 | 0 变焦(多鬼影) / 1 35mm / 2 105mm / 3 电影 | 决定鬼影数量与分布 |
| 中心 X % / 中心 Y % | 0~100 | 桌面端是点击画面指定，这里先给两个滑块 |
| 光晕半径 % | 20~200 | 我们额外加的，可只做小范围光斑 |

## ⑦ 水彩（0.74.24，`FilterFx.watercolorAt`）
**文献**：桌面端滤镜库「水彩」的三个参数是**画笔细节 1~14 / 阴影强度 0~10 / 纹理 1~3**；实现按数字水彩常用的三步：中值平涂（细节越大中值半径越小）+ 亮度梯度压暗（颜料堆积的暗边）+ 纸纹噪声。
- 纸纹用**确定性伪随机**（`(x*p1) xor (y*p2) xor (x*y*p3)`），保证预览与应用结果一致。
- 旧的 `watercolor(radius, saturation)` 保留，新参数的入口走 `watercolorAt`。

## 踩坑
- `cl(v: Float)` 收 Float，我先写成 `cl(r.toInt())` 报类型不匹配；
- `Float.coerceAtMost(255)` 传 Int 也报 mismatch（要写 `255f`）。
- 报错行被 gradle 控制台按 119 字符截断，`^e: file` 只看得到前半句——要用 read 工具打开那一行看真实表达式。
