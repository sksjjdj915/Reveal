# 0.67.99 修复记录

针对用户 2026-11-09 的两条反馈：
1. 图层样式「没有模糊参数、也没标清」
2. 「色卡去掉，只留开关旁那个取色，点一下出现和画笔取色一样的色板和色带」

## 一、投影/外发光：假模糊 → 真模糊

**原来**：`SketchView.styleOverlay()` 的投影是把**同一张图层位图**按 `ringDirs` 8 个方向偏移后各画一遍（每张 alpha=70），再额外叠一张 alpha=255 的原图。边缘是硬的，8 张叠起来就是一圈硬边重影；用户看到的「字后面一块深灰重影、像两层」即此。

**现在**：新增 `softSilhouette(src, color, blur)` + `boxBlurAlpha(...)`
- 先把图层缩到 1/4 并用 `SRC_IN` 染成单色（剪影）；
- 对 alpha 做两趟一维盒式模糊（半径 = blur/4，1~24）；
- 再 `FILTER_BITMAP_FLAG` 放大、按 dx/dy 铺在层下面。
- `shadowBlur = 0` 时走原来的锐利位移拷贝；`<=1` 也不模糊。
- 外发光同一条链路，不带位移，半径按 `glowSize*1.6`。

顺带：`setLayerStyle` 的上限放开 —— `shadowBlur` 0→60（原 0→30）、`glowSize` 1→60（原 1→40）。

## 二、滑块全部带名字

新增 `StyleSlider(label, value, range, text, onChange)`：左边 52dp 文字标签、中间细线滑块、右边数值。12 组里每根滑条都配了名字：

| 组 | 参数 |
| --- | --- |
| 描边 | 大小 |
| 投影 | 模糊 0~60 / 左右 -60~60 / 上下 -60~60 |
| 外发光 | 大小 1~60 |
| 内阴影 | 大小 0~40 / 左右 / 上下 |
| 内发光 | 大小 1~40 |
| 渐变叠加 | 角度 0~180° + 第二个色标 |
| 斜面和浮雕 | 大小 / 深度 0~100% |
| 光泽 | 大小 / 距离 / 角度 |
| 图案叠加 | 图案（第 N 种）/ 缩放 / 不透明度 |
| 纹理 | 图案 / 缩放 / 深度 |
| 等高线 | 形状（线性/锥形/平滑/环形/圆角/锯齿） |

面板高度上限 280→320dp，仍可滚动。

## 三、色卡删除，色块点开用画笔同一套取色

- 删掉 `ColorSwatchRow`（两行预设色块）及全部 12 处调用。
- `StyleHead` 右侧那个小色块改为**可点**，点一下把面板切成取色模式：直接复用画笔的 `ColorPickerPanel`（方形 `SvSquare` + 色带 + 前景/背景 + 常用色 + 最近用过），滚轮/点击都和画笔一致。
- 取色槽位 1~9 分别对应：描边 / 投影 / 外发光 / 内阴影 / 内发光 / 颜色叠加 / 渐变叠加第一色 / 渐变叠加第二色 / 光泽；`onColorChange` 边拖边预览，点「确定」收起取色回到参数列表。
- 拖任意滑块仍会自动把该组打开（`xxxOn = true`）。

## 出厂验法

1. 字图层 → 长按 → 图层样式 → 开「投影」，拖「模糊」到 40：阴影应该是柔的渐变，**不再出现一圈硬边重影**。
2. 同一面板看每根滑条左边都有字（模糊/左右/上下…），不再是一根光秃秃的线。
3. 点「描边」右边的小色块 → 出现方形色板 + 色带（和画笔取色长得一样），拖动时画面实时变。
4. 点「取消」回到参数列表；点「应用」落到图层。
5. 外发光「大小」拖到 60：光晕是软的，边缘不糊死也不见方框。

## 没做的

- 描边仍是环形偏移叠加（描边本来就该是硬边，这条不算缺陷）。
- 模糊在 1/4 缩略图上算，超大画布（4096）拖动时会有 80ms 防抖延迟，不做实时 1:1 模糊（性能代价太高）。
- 图层样式的改动本身不进撤销栈（沿用上一版结论）。
