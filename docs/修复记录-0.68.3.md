# 0.68.3 修复记录 · 变换加旋转手柄 + 角度参数

用户 2026-11-09：「变换功能里面没有旋转，变换框外面没有旋转，加个旋转」；随后补充「有的不用删就是在加一个手柄，还有角度」——原来拖框外/双指可以转，但没有手柄、没有角度数字，等于看不见。

## 一、变换框外新增旋转手柄（`ui\SketchView.kt`）

- `tfRotHandlePoint()`：取顶边中点，沿「框心 → 顶边中点」方向再往外挪 `34 / viewScale`（跟画布缩放无关，永远固定屏幕距离）。
- `drawTransformFrame()` 里画：顶中点 → 圆点的连接线 + 圆点（`13/scale` 半径，里面一个 `↻` 字）。
- `tfBeginDrag()`：先判旋转手柄（`44/viewScale` 命中半径，比顶边手柄优先），命中即 `hit = 8` → `tfMode = 3`（旋转），走原有绕中心旋转的逻辑，双指旋转照旧可用。
- 顶部标签实时显示角度：`自由变换 · 100% · 12° · 拖角等比 / 拖顶圆点旋转 · 双击确认`。

## 二、底部变换条加「角度」参数（`ui\EditorScreen.kt`）

变换接管底部那条时，在「切透视」左边新加：

- `角度 N°` 文字 + `ThinSlider`（-180 ~ 180，细线滑块），拖动直接调用 `sketch.setTransformRotation(deg)`，画面实时转。
- **「归零」** 按钮：角度回 0。
- 每次进变换自动把角度重置为 0（`if (active) { perspMode = false; tfAngle = 0f }`）。

新增 SketchView 公开接口：`currentTransformRotation(): Float`、`setTransformRotation(deg: Float)`。

## 出厂验法

1. 选一层 → 变换 → 框**顶上正中出现一个带 ↻ 的圆点**。
2. 拖那个圆点 → 内容跟着转，顶部标签角度数字实时变。
3. 底部条拖「角度」滑块 → 也能转，和手柄同一个角度。
4. 点「归零」→ 角度回 0，内容回正。
5. 双指旋转、拖框外旋转照旧可用（没删）。
6. 转完点「应用」→ 落到图层；按撤销能回去。

## 没做的

- 角度滑块与手柄拖动**单向同步**：手柄拖动时底部数字不会实时跟着变（画布顶部标签会变），松手后也没回填到滑块。
- 旋转后形状层的参数（宽/高）仍按水平包围盒算，转 90° 后宽高会互换显示。
