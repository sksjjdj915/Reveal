# 0.67.91 修复记录（2026-11-09）

## 曝光度调不到 0.3

不是算错了，是**显示和取整**的问题：滤镜面板里每个旋钮右边的数字原来一律 `roundToInt()`，
曝光度的量程是 -5 ~ +5，拖到 -0.3 时显示还是 `0`，点进去编辑框也是 `0`，
所以看起来「调不到 0.3」（实际值可能已经是 -0.3，但肉眼无法确认）。

改法（`ColorFxTools.kt`）：

- 新增 `fxText(v, range)`：**量程跨度 ≤ 12 的参数保留一位小数**（曝光度、色阶类都是两位以内），其余仍按整数显示；
- 旋钮右边的数字、以及点数字弹出的编辑框初值，都改用 `fxText`；
- 编辑框本来就按 `toFloatOrNull()` 解析，`-0.3` 能直接输入并 clamp 到量程内。

效果：曝光度现在会显示 `-0.3`、`0.0`、`1.5` 这样的值，拖到哪就是多少；
没有数值输入的需求时也能直接点数字改。
