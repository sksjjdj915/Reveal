# 0.68.11 给组加图层样式不生效

版本：0.68.11（code 369）
日期：2026-11-09

## 现象

成组之后，选中这个组打开「图层样式」，加投影 / 描边 / 发光，画面一点变化都没有，组里的图层也没反应。

## 原因

`SketchView.setLayerStyle()` 只把样式参数写到**被点中的那一层**上。组头（`sectionType == 1/2`）本身是一张空位图，只当书签用，所以：

- 样式写在组头身上 → 组头是空的 → 什么都画不出来；
- 组里的成员层一个字段都没改 → 成员自然没变化。

## 改法

- `setLayerStyle()` 拆成两半：新的 `private fun applyStyleTo(layer, s)` 负责把参数写到一层上，`setLayerStyle()` 负责分派。
- 当目标是组头时，用 `groupSpan(index)` 求出组成员的区间，把同一份样式 `applyStyleTo` 到每个 `sectionType == 0` 的成员层上（组头的参数也照写，这样关掉再打开面板还是原来那组值）。
- 每层都 `styleVer++`，样式缓存跟着失效，画面立刻重画。

## 怎么验

1. 两层合成一个组 → 选中组 → 图层样式 → 打开「投影」，拖模糊/距离 → 组里的图立刻出现投影。
2. 打开「描边」，拖大小 → 组里的图出现描边。
3. 关掉「投影」开关 → 投影消失。
4. 组里放三层，彼此错开 → 给组加投影 → 三层各自有一圈投影（每层自己投，不是整组一个轮廓）。

## 没做的

- 组的样式是**逐层套用**，不是把整组拍平成一个轮廓再投一次影子。所以组里多层互相重叠时，重叠的地方会看到各自的投影边缘（桌面端是整组一个轮廓）。要做成桌面端那样，需要先把组渲染成一张临时位图再算样式，改动量较大。
- 已经给组成员单独设过的样式会被组样式覆盖，取消组样式不会还原成原来的值。
