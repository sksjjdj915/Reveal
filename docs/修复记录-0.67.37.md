# 修复记录 0.67.37（code 302）

日期：2026-11-08

## 这次改了什么：PSD 导入失败 + 首页「收到的 PSD」等半天才出来

两条现象其实是一件事的两面：**打开 PSD 时把整份文件全量解析**。

---

## 一、导入失败（点卡片报「导入失败」）

### 原因

`HomeScreen` 里导入是这样调的：

```
PsdFiles.backupBytes(context, item.name, item.file.readBytes(), names)
```

- `readBytes()` 先把整份文件读成一个字节数组（重）；
- 进了 `backupBytes` 又调 `Psd.open(raw.inputStream())`，而 `Psd.open` 内部还有一次 `readAll(stream)`（再复制一份）。

同一份文件在堆里躺两份。QQ 发来的 PSD 只要几十 MB、图层多几个，就直接 `OutOfMemoryError`；外面被 `runCatching{}.getOrNull()` 吞掉，只剩一句「导入失败 / 文件可能坏了」。

代码里其实早就有省内存的路：`Psd.openFile(file)` 对 24MB 以上的文件走内存映射（`FileChannel.map`），文件字节根本不进 Java 堆。只是导入这条路没走它。

### 改法

- 新增 `PsdFiles.backupFile(context, file, existingNames)`：传 `File`，内部用 `Psd.openFile(file)`。
- `HomeScreen` 的导入改成调它，不再 `readBytes()`。
- 原来 `backupBytes(…, raw: ByteArray, …)` 保留（其它调用方还在用），两者共用一个 `writeProject(...)` 落盘。
- 记录原件也分流：从文件来的走流式拷贝（`rememberOriginal(context, id, src: File, doc)`），整份不进堆。

## 二、首页「检测到的 PSD」要等很久

### 原因

`reloadIncoming()` 里是这么写的：

```
for (item in list) { val thumb = PsdFiles.thumbnail(item.file, 260) ... }
incoming = list
incomingThumbs = map
```

两个问题叠在一起：

1. `PsdFiles.thumbnail()` 用的是 `Psd.open()`——**为了 260px 的小图，把整份 PSD 的所有图层全解码了一遍**；
2. 全部解码完才把 `incoming` 交给界面，所以在解码结束前那一行根本不存在。

所以文件越大越多，首页空得越久。

### 改法

1. **两段式**：先 `incoming = list`（卡片立刻出现，名字 + 灰底），缩略图再一个个解码、解出一个填一个。列表每次刷新还会丢掉已删除文件留下的旧缩略图。
2. **缩略图快速路径**：新增 `PsdFiles.embeddedThumb(file)`，只读 PSD 文件头 + 图像资源段，找 **image resource 1036**（桌面端/桌面端存的时候自带的 JPEG 小图，通常 160px）直接解码，几十毫秒，完全不碰图层。
3. 取不到内嵌图时，才退回完整解析，而且**只对 24MB 以内的文件做**；更大的文件就显示灰底占位（点开照样能看全图），不再为了一个小图把整份文件解一遍。

## 三、接收中就有一张占位卡

以前 QQ 传过来时只弹一句顶部「正在接收文件…」，列表里什么都没有。现在列表最前面会出现一张「正在接收…」的卡片，复制完自动换成真卡片。

---

## 怎么验

1. **大 PSD 导入**：从 QQ 里选「用其他应用打开」→ 回到首页 → 点那张卡片。以前会「导入失败」，现在应该正常进编辑器。
2. **首页速度**：连发两三个 PSD 过去，杀掉 App 再打开。应该**立刻**看到「QQ / 微信发来的」那一行和卡片（灰底也行），缩略图随后一张张补上，不用干等。
3. **接收过程**：发一个大文件，回到首页应该先看到「正在接收…」的卡片，复制完变成正常卡片。
4. **缩略图正确性**：卡片上的小图应该是作品本身（拿桌面端存过的 PSD 一定能出内嵌图；某些第三方导出工具不写 1036，这时会退回完整解析，画面同样正确）。

## 已知边界

- 内嵌缩略图只有最大 160px，卡片上是放大的，会比以前的 260px 略糊——换来的是秒出。点进去看的是全尺寸，不影响编辑。
- 超过 24MB 且没有内嵌缩略图的 PSD，首页卡片会是灰底占位（有文件名），点开正常。
- 如果这次还是导入失败，弹窗里那段诊断现在会带上具体原因（内存不够会写「上限多少 MB / 失败时已用多少 MB」），复制发我就能定位到是不是解析器本身的问题。
