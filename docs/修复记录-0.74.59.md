# 0.74.59 目标③：镜头校正按 EXIF 自动校正

## 文献/成熟做法
镜头畸变校正的「自动」档是读照片的拍摄信息：**等效焦距（35mm 等值）与镜头型号**。等效焦距越短（广角），桶形畸变越明显；这也是 Lightroom「配置文件校正」在没有镜头库时退而使用焦距估的原因。畸变模型仍是 Brown-Conrady 的径向项 `r' = r(1 + k₁r²)`。

## 实现
1. 新增 `data/ExifInfo.kt`：
   - 导入图片时读一次 `TAG_FOCAL_LENGTH_IN_35MM_FILM` 与 `TAG_LENS_MODEL`；
   - `autoDistort()`：`k = (35 − 等效焦距)/35`，夹在 −0.6~0.9，再 ×100 变成「移去扭曲」的百分比值；
   - `summary()`：给面板显示「镜头：xx · 等效 24mm」或「这张图没有拍摄信息」。
2. 导入链路（`CanvasPage` 的图片选择回调）在解码前先 `ExifInfo.read(context, uri)`。
3. 镜头校正面板多一颗「**自动**」胶囊：点一下就按 EXIF 把「移去扭曲」设成估计值（其余参数保持不变），下面一行 9.5sp 小字显示读到的镜头/焦距或「没有拍摄信息」。
4. 为此给 `FxSpec` 加了可选 `auto: (() -> List<Float>)?`（同样必须放在 `apply` 之前），`FilterDock` 有 auto 就渲染这颗胶囊。

## 没做
1. 没有内置镜头畸变数据库（真·配置文件校正需要镜头库）；
2. 只估「移去扭曲」一项，晕影/色差没按 EXIF 自动（厂商参数差异太大）；
3. PNG/截图没有 EXIF，此时点「自动」会给出 0 并提示没有拍摄信息。
