# 0.71.2 参数区（固定高度）

## 一、这次做了什么
1. **点工具后出现的参数区**：`ParamDock`，固定高度 **72dp**，白色、顶部圆角 16dp、带 8dp 阴影，浮在画布底部——**不压缩画布**，画布大小和没点工具时一样。
2. 参数区里现在是两个参数：`大小`（1~200）与 `不透明`（0~100%），细线滑块 + 右侧数值，改完立刻作用到引擎（`brushSize` / `eraserSize` / `brushOpacity` / `eraserOpacity`）。
3. 悬浮模式按钮上移到底部 92dp，避免和参数区重叠。

## 二、这次没做
1. 参数区内容还不按工具变：画笔画笔是这两个，用到选区/文字时也是这两个（后面按工具逐个换）。
2. 高是写死 72dp，没做「修图模式更高」。
3. 没跑模拟器（按用户要求只查代码）。

## 三、怎么验
1. 进画布点任意工具 → 底部浮出白色参数条（72dp），画布不缩。
2. 拖 `大小` → 笔尖变粗变细；拖 `不透明` → 笔迹变淡变浓。
