## 还剩什么（截至 0.66.23）

1. ◐ 智能对象「原样保留」：App 内转的会连原图存进工程包；外部 PSD 里「置入的图」能抠出内嵌的 PNG/JPEG 原图并继续换内容；**抠不出来的只剩两类**——链接到外部文件的置入（文件不在 PSD 里）、以及 TIFF/PSB 置入
2. ◐ 大文件 PSB（>300MB）：结构能读；超过 24MB 的文件走内存映射（文件字节不进 Java 堆），剩下吃内存的只有解出来的图层像素——画布特别大时仍会提示内存不够，但不会崩
3. ➖ 脚本：按需求已删除（0.66.25 移除 FxScript，动作录制/智能滤镜/批处理仍在）
4. 大图 5000×5000 不卡：代码侧已就绪（大图模式 + 自检压测），**只缺真机数字**
5. 智能滤镜：App 内是真非破坏（挂在图层上、可关、随工程存）；PSD 里不写进智能对象，桌面端打开看到的是压平像素
