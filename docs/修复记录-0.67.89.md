# 0.67.89 修复记录（2026-11-08）

## 1. 先回答三个问题

**渐变映射不是方向渐变。** 它跟「上下 / 左右 / 斜着」都没关系 —— 它按**亮度**换色：

- 画面最黑的地方 → 用「暗部颜色」
- 画面最白的地方 → 用「亮部颜色」
- 中间的亮度按比例插值

所以你把暗部设成黄色，整张偏亮的图就会一片黄 —— 效果没错，是颜色选得跟预期不一样。
想要「从左上到右下的渐变」，那是**渐变工具 / 渐变填充**，不是渐变映射。

另外之前我写的 `#1B2A46`、`#E8C27A` 在面板里根本选不到：那个面板只有 10 个固定色块。这是我写错了。

## 2. 这次加了什么

**「新建调整图层」里多了「渐变映射」**（原来的滤镜版没动，两套都在）：

- 位置：类别 → 调色 →「新建调整图层」→「渐变映射」
- 它是**调整图层**：不出像素、随时改、随时关、可以拖到别的层上面；
- 参数条上给了 6 条细滑块：暗部颜色 R/G/B、亮部颜色 R/G/B（0~255），
  想用 `#1B2A46` 就把暗部填成 27 / 42 / 70，`#E8C27A` 填 232 / 194 / 122；
- 面板底部也写清了「按亮度映射，不是方向渐变」。

实现要点（给自己看）：
- `AdjustOp` 加 `KIND_GRADIENT_MAP = 3` 与 `gmLo / gmHi`，`gradLut()` 生成 256 级查表；
- 渲染在 `drawLayers` 里、跟色阶同一条通道：命中渐变映射层就调 `applyGradientToTarget()`，
  对已画好的下半部分分带（256 行）查表换色，避免整幅拷贝吃内存；
- `adjustFilterFor()` 跳过它（查表不能压成 ColorMatrix）；
- 存工程写进 manifest 的 `gmLo/gmHi`，重新打开还能继续调；
- 写 PSD 时**先不写它的附加信息块**（渐变映射对应 `GdMp` 块我还没实现，写错块会让桌面端打不开），
  所以存成 PSD 在电脑上的修图软件 里会是一个空图层 —— 这条我记在待办里。

## 3. 怎么验

1. 类别 → 调色 →「新建调整图层」→「渐变映射」→ 画面上立刻出现一层「渐变映射」；
2. 打开参数条，把暗部调成 27/42/70、亮部调成 232/194/122，画面应该变成「暗处深蓝、亮处暖金」；
3. 点这一层的眼睛，效果应能关掉；拖到别的层上下，影响范围应跟着变；
4. 存盘关掉再打开，参数应该还在。

## 4. 没做

- 渐进式多色渐变（桌面端那种可以放多个色标的渐变条）—— 现在只有两端色；
- 导出 PSD 时把这个调整层写成 `GdMp` 块（现在会变成空层）；
- 原来那个滤镜版渐变映射面板仍然只有 10 个固定色块（要不要也改成 RGB 滑块，你说一句我就改）。
