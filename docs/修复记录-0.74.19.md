# 0.74.19 分隔线 / 面板高度自适应 / 挤压补「指定位置」

## 一、你提的两处界面问题
1. **两个工具栏之间加了一条 1dp 横线**（`Rv.line` 颜色），只在滤镜组展开时出现，分隔「子工具栏 / 主工具栏」。
2. **参数面板不再硬占固定高度**：
   - 所有 `heightIn(max = 340.dp)` 统一放宽到 **420dp**（约屏幕一半的下限），并且是「按内容收缩、最多到 420」；
   - 亮度/对比度、曲线这两处原来是死写 `height(320.dp)`，所以底下留白——改成 `heightIn(max = 420.dp)`，内容多高就多高，不再有空白块。
   - 内容超了在面板内部滚动，仍然不越过屏幕一半。

## 二、第一个子工具目标：挤压（补「指定位置」）
- **文献依据**：径向变形的常用做法是「对输出半径做查表式的反演」——`s·(1 + k·(1−t)) = t`，`t` 是到中心的归一化距离；这是镜头桶形/枕形畸变（Brown-Conrady 径向项的一阶化简）以及多数 GPU bulging/pinch shader 的写法。旧实现固定 `cx = w/2, cy = h/2`、半径固定 `min(w,h)/2`，所以只能整幅变形。
- **新增参数**（`FilterFx.pinchAt`）：
  - 强度 −100~100（负值往外鼓）
  - **中心 X %** / **中心 Y %**（0~100，相对画面宽高）
  - **半径 %**（5~200，相对 `min(w,h)`）
- 边缘用 `(1−t)` 权重衰减，避免出现一圈硬边。
- 面板里的「说明」页同步写了：桌面端本体只有强度且固定中心，这里补中心与半径可以只压局部。
