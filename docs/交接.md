## 一、这是什么

**Reveal** = 安卓手机上的图片编辑器，定位「手机修图」。Kotlin + Jetpack Compose，
画布是自己写的自定义 View（`SketchView`），PSD 读写完全手写（没有第三方库）。

- 代码：`E:\deepseek\palette`，包名 `com.reveal.editor`
- 许可：PolyForm Noncommercial 1.0.0（个人/学习/研究/自用随便用改发，禁止商用；非 OSI 开源，属 source-available）
- 用户明确：**代码公开、不上架商店**，所以签名/备案/隐私政策/商店素材一律不用做
- 用户自己用 + 给朋友用

### 用户底线原话（优先级最高，别改方向）

- 「先不测，先把全部功能都做了，我的钱花完前最起码要有个框架bug慢慢修」

## 三、环境与出包秩序（照抄，别自创）

每条命令前都要设这三个变量（PowerShell）：

```powershell
$env:JAVA_HOME='%USERPROFILE%\.jdks\jbr-21.0.11'
$env:ANDROID_HOME='%USERPROFILE%\AppData\Local\Android\Sdk'
$env:GRADLE_USER_HOME='E:\deepseek\palette\.gradle-home'
```

**成败只看 `BUILD SUCCESSFUL`**——桌面端 5.1 里 `$LASTEXITCODE` 常是 1，那是假失败，别被骗。

### 出包五步（每版都这么做）

1. `node E:\deepseek\_bump2.cjs <versionCode> <versionName>` —— 同时改 `app/build.gradle.kts` 里的
   `versionCode` 和 `versionName`（老 `_bump.cjs` 只改 code，别用）
2. `.\gradlew.bat assembleDebug`
3. `aapt2 dump badging app\build\outputs\apk\debug\app-debug.apk`（在
   `%USERPROFILE%\AppData\Local\Android\Sdk\build-tools\36.0.0\`）核对版本号
4. 拷到桌面 `Reveal-<版本>-debug.apk`，**删掉旧包**
5. 写 `docs\修复记录.md`（用 node 脚本 `_docsNNNN.cjs`，条目追加在**末尾**）→
   `git -c user.name=reveal -c user.email=reveal@local commit -m "..."`

### 验证「包真的更新了」

APK 字节数两版一样是正常的（zipalign 填充）。要确认新代码进包，解包查 dex 里的符号：

```powershell
Add-Type -AssemblyName System.IO.Compression.FileSystem
[IO.Compression.ZipFile]::ExtractToDirectory($apk, $tmp)   # Expand-Archive 不认 .apk
# 然后按 ASCII 读 classes*.dex 字节，查类名/方法名字符串
```

### 构建报 `java.net.BindException: Address already in use: bind`

按顺序：`Stop-Process java` → 删 `.gradle-home\*.lock` → 删 `.gradle-home\daemon` → 删项目 `.gradle`。

## 五、核心架构（改之前必须知道）

### 1. 位深四层

```
rawPix（导入的原始通道）→ pix16 / pix32（画过之后的精度缓冲）→ bitmap（8 位显示）
```

- 16 位样本 = sRGB × 257；图层记录写进附加块 **Lr16/Lr32**（flags 0x08），**只能 RLE**（桌面端 2026 不收 ZIP）
- 32 位通道存线性光，写盘 `toLinear`、读回 `toSrgb`，必须补 hdrt 色彩块 + ICC
- 灰度/CMYK 走 planar16 + `pix16src` 回写判据（颜色对得上才原样写回）
- 蒙版、自由变换、撤销等 `dropPix16` 的操作会**按设计**退回 8 位
- 已知限制：画过的灰度/CMYK 像素仍是 8 位

### 2. 撤销

分块像素快照（脏矩形）。正确顺序：先建 Patch 抓快照 → 改像素 → `sync` → `pushUndo`。
大图模式（>12M 像素）：`maxUndo` 20 步 / 48MB，且 `ensurePix16Inner` 直接返回 null。

### 3. 图层样式 12 种

字段在 `Layer` 和 `StyleParams` 里各一份，`hasTopStyle`/`setLayerStyle` 必须同步。
`styleTop(layer)` 按 `identityHashCode(bmp)*31 + styleVer` 缓存，依次叠画。
PSD 端 lfx2 只写 FrFX/DrSh/OrGl/ISDr/IrGl/ClrO/CHFX（纹理、等高线只在 App 内生效）。

### 4. 智能对象

`smartSrc`（原图）+ `smartMatrix`，变换永远从原图采样（5 轮回缩放清晰度 100% vs 普通层 23%）。
工程包存 `smart_N.png`；从外部 PSD 导入时靠 `SoLd` 的 `Idnt` 去 `lnk2` 里按 uuid 找原图字节。

### 5. 智能滤镜（非破坏）

`Layer.smartFx: MutableList<StepRec>` + `smartFxVer` 缓存；
`drawLayerPixels` 入口 `val bmp = smartFilterBitmap(layer) ?: bmpIn` —— 屏幕/拼合/导出/缩略图
全走这一处，所以只要这里对了，其它自动一致。

### 6. 滤镜/调色统一入口

`sketch.applyFilterToActive(fn, title)` —— 自动处理选区、阿尔法锁定、图层不透明度、撤销。

## 六、干活规矩（踩过才知道的）

### 改代码

- 改 `.kt`/`.md` **一律写 node 脚本**（`readFileSync(...).replace(/\r\n/g,'\n')` → `writeFileSync(...,'utf8')`）
- **写 `.cjs` 用 write 工具**。禁止：PowerShell here-string（会碎）、`node -e "...$1..."`（桌面端吃参数）、
  `(Get-Content -Raw)|Set-Content`（把 UTF-8 写成 GBK，中文锚点全废）
- 用 write 生成 Kotlin 时**别用反引号模板**（`${...}` 会被 JS 插值），用数组 `join('\n')`
- 脚本开头一律：
  ```js
  function must(c, m) { if (!c) { console.log('MISSING ' + m); process.exit(1); } }
  ```
  锚点必须**带精确缩进**（rail 条目 12/16 空格、collectLayers 20 空格带逗号、载入映射 28 空格无逗号、
  样式拷贝 32 空格带 `st.`）——缩进错一个空格就是 MISSING
- 整块替换函数后，**用正则列一次 `fun xxx` 名集合做差**，确认没顺手删掉夹在中间的其它函数

### Compose / Kotlin 坑

- `when` 必须穷举（`ACTION_MOVE` 里漏一个 Tool 分支就 `must be exhaustive`）；分支末尾**不能带逗号**
- 只 import 已经存在的图标。**可用**：`Brush/Create/Crop/Layers/Tune/FilterAlt/AutoAwesome/Title/
  Category/Straighten/FolderOpen/Movie/Dashboard/Palette/ColorLens/WbSunny/Brightness6/Contrast/
  GridView/ScatterPlot/Gesture/Polyline/AcUnit/AdsClick/RotateRight/CenterFocusStrong/Timeline/
  Details/FitScreen/ShowChart/IosShare/OpenWith/Refresh/BlurOn`
  **不存在**：`Colorize/Photo/VisibilityOff/ContentPaste/Edit/Transform/BlurCircular/Restore/Info/
  PlayArrow/Map/FilterCenterFocus`
- `public` 属性/函数不能暴露 `internal` 类型（如 `StepRec`）→ 一起写成 `internal`
- `view.post { }` 的 lambda 没有参数，别写 `it`

### 验证方法（用户只看数字）

新算法**先用 JS 复刻公式跑数字**，过了再落 Kotlin。已有几十个 `E:\deepseek\_*test.cjs` 可参考
（`_warptest.cjs` 网格、`_pctest.cjs` 单应、`_acttest.cjs` 动作、`_mp4test.cjs` YUV、
`_smartstore.cjs` 工程后缀、`_scripttest*.cjs` 等）。
断言写错时先怀疑预期，别急着改代码（曾经两次把对的算法判成错）。

### 核对表

`docs\功能核对.md` 的 ✅/◐/❌ 是**人工维护的语义计数**，不能按表格行数自动重算
（有一类 45 项合并成一行，自动重算会算成 ✅6）。改状态时手动数。
