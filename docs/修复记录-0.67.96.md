## 用户反馈的两件事

1. 「调色里没有调整图层按钮」——不是没做，是**藏得太深**：原来「新建调整图层」只是调色弹窗中间的一个 9sp 灰字分组标题，下面两个 54dp 小方格夹在 29 项功能里，看不出是个入口。
2. 「第二段只有测没有做，画面一点没变」——我上一版把测试文本写成「挨个点开关看反应」，没有产出画面变化，不能当验收用。

## 改法

### 调色里加显眼的「调整图层…」入口

- 位置：`app/src/main/java/com/reveal/editor/ui/EditorScreen.kt`
- 分类表最前面加一格：`a("adjust:new", "调整图层…", Icons.Filled.Layers)`（不带 section，排在「普通调色」之前，单独露在最上面）。
- 新增状态 `showAdjustChooser`，动作 `"adjust:new" -> { closeAllPanels(); showAdjustChooser = true }`。
- 新增选择对话框（`AlertDialog`，插在 `if (showResize)` 之前）：标题「新建调整图层」，正文说明「调整层只影响它下面的图层；一个组里可以叠多个效果」，五个选项：
  - 空调整组（可叠加多个效果）→ `KIND_CONTAINER`
  - 亮度/对比度 → `KIND_BRIGHT_CONTRAST`
  - 色相/饱和度 → `KIND_HUE_SAT`
  - 色阶 → `KIND_LEVELS`
  - 渐变映射 → `KIND_GRADIENT_MAP`
- 选中后统一走 `addAdjustFromChooser(kind)`：建层 → `adjIndex/adjOp` → `openPanel("adjustlayer")` → 弹底部参数面板；建容器时额外提示「已建空调整组，点面板上的「＋叠加」加效果」。
- 原来的 `亮度/对比度`、`色相/饱和度` 两个小方格保留（快捷入口），`☰ → 新建调整层` 子菜单也保留。

### 第二段测试文本重写成「做中测」

- 文件：`%USERPROFILE%\Desktop\Reveal-测试步骤-第二段.txt`（0.67.96 版）
- 从「12 条 UI 开关」改成「12 步做出一张成品图」：导入照片 → 图像大小改当前层（人物变形）→ 选择主体 + 输出到新图层（背景透明）→ 椭圆选框圈脸 → 减选挖月牙 → 调整组叠色阶+渐变映射（整张变色）→ 多色标改中间调 → 动感模糊（拉丝残影）→ 删层撤销 → 撤销跳过空步骤 → 另存 PSD 回桌面端看 → 新建画布记住尺寸。
- 每一步都写明「画面会变成什么」，末尾标它在验哪一条修复，最后附 12 条对号入座表。

## 验法

- 调色 → 第一格就是「调整图层…」，点开有五个选项；选「空调整组」后底部出现「调整组（0 项）」+「＋叠加」。
- 其余 12 项按桌面第二段文本走一遍，画面每步都应有可见变化。
