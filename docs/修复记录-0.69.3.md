# 0.69.3 界面改版 · 第三级（控件与面板统一）

## 一、这次做了什么
1. **统一按钮芯片（chip）**：从「纯文字、选中变蓝字」改成胶囊：未选中浅灰底 #F0F2F5 + 灰字，选中蓝底 + 白字；底色和文字色都走 150ms 缓动过渡，不再有跳变。所有参数条、面板里的 线性/径向/反向颜色/只画范围/全部/阴影/中间调 这类开关全部自动跟着变。
2. **细线滑块重调**：圆点 10dp → 12dp，蓝底加 2.5dp 白边（在浅色底上更清楚）；轨道仍是 2dp 细线。高度不变，不挤。
3. **参数行排版**：标签 10.5sp 灰、数值 11sp 深色、数值列 34dp → 38dp（避免「300%」被截）。
4. **新增统一面板外壳 `ui/RvPanel.kt`**：`RvPanel(title, onClose, subtitle, scrollable, maxHeightDp)` = 白色 20dp 圆角卡片 + 10dp 阴影 + 标题行（左标题右 ✕）+ 内容区；`RvGroup(title)` = 折叠块小标题 + 1dp 分隔线。以后新面板一律套这两层，不再各写各的。
5. **图层样式面板改用新外壳**：白底、20dp 圆角、10dp 阴影、左右各留 10dp，标题行仍是「图层样式 · 图层名 + 取消/应用」，最大高度 320 → 340dp。

## 二、这次没做
1. 色阶 / 曲线 / 调色 / 色相饱和度 / 渐变映射 这些面板**还没套 RvPanel**（只跟着换了 chip 和滑块样式）。
2. 模式切换时左栏还没有整列滑入动画。
3. 首页（工程列表）版式没重排。
4. 没跑模拟器。

## 三、怎么验
1. 选渐变 → 参数条里「线性 / 径向」是胶囊，选中是蓝底白字，点另一个能看到颜色渐变过去。
2. 拖任意滑块 → 圆点变大、带白边。
3. 看数值列 → 「300%」「1024」这种不会被截断。
4. 图层面板 → 图层样式：面板变成白卡片、圆角、有阴影、四周留白。
