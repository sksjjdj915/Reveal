# 0.74.60 目标④：曲线吸管取样

## 成熟做法
曲线面板的吸管（目标调整工具）是：在画面上点一个位置 → 读出该点的**输入值** → 在曲线上对应位置放一个控制点，然后拖动这个点就能只改这一档亮度。这样不用猜「画面这块到底落在曲线的哪一段」。

## 这次实现
- 曲线页通道行（RGB/红/绿/蓝 后面）加了「**吸管**」胶囊；
- 点开进入取点模式（复用 `FilterPick`），在画面上点一下：
  - 按当前通道取值：RGB 用亮度 `0.299R+0.587G+0.114B`，单通道取该通道值；
  - 转成 0~1 的输入值 `t`，在曲线上插入点 `(t, t)`（即不动画面的初始位置）；
  - 插入后按 x 重新排序，保证曲线可用；
  - 若 0.02 范围内已有控制点，则不重复插入。
- 点完自动退出取点模式；点胶囊可手动退出。

## 没做
1. 没有做「按住吸管上下拖动直接改亮度」（现在要先点、再去拖曲线上的点）；
2. 没有做「吸管取样后高亮画面里受影响的亮度范围」（桌面端的目标调整会显示受影响区）；
3. 点落在 0/1 端点时不会替换端点（端点保留）。
