# 0.72.5 透明区显示棋盘格 + 顶栏日志

## 一、「到新层」后看着是白底
- `selectionToNewLayer()` 本身是对的：选区外的像素 alpha = 0（真透明）。
- 看着白，是因为我 0.70 给画布加的「白纸」底色：`SketchView.onDraw` 在图层下面先画了一张白色纸张矩形。透明区透出来的就是它。
- 改法：纸张底从「纯白填充」换成**棋盘格**（`checkerPaint`），保留 1px 描边和投影。这样删掉原图后看到的是棋盘格（透明），不会再误认为白色背景。

## 二、顶栏加「日志」
- 顶栏右侧（保存左边）加一颗小图标按钮，点开日志面板。
- 面板两页：**诊断**（`Diag.read`，含版本/机型/导入记录/滤镜耗时等）与**崩溃**（`CrashLog.read`，未捕获异常堆栈）。
- 每页可「复制」（写进剪贴板，可直接发我）和「清空」；点面板外关闭。

## 三、没做
1. 日志不自动刷新（重新打开面板才重新读），避免和现有滚动状态打架。
2. 其余功能（色阶/曲线/色相饱和/亮度对比、文字参数、液化变形、裁剪与图像大小、PSD、AI）仍未接。
