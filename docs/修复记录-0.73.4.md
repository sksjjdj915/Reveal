# 0.73.4 最后一层也能删 / 直方图放大 / 预览补 invalidate

1. **只有一个图层也能删除**：`deleteActiveLayer()` 去掉了 `layers.size <= 1` 的拦截；删到空时把 `hasDocument` 置 false、清选区、清合成缓存，画布回到空工作区；之后再导入图片就会走 `openImageAsDocument`（＝打开图片），不会再加成置入。
2. **直方图**：
   - 底图改为「整幅合成图」（`flatten()`），不再取活动层（活动层如果是调整层/空层就没数据，之前看着像没显示）；
   - 高度 44dp → **88dp**，柱子更容易看清；
   - 逻辑不变：区间外浅灰、区间内深灰。
3. **实时预览**：`setPreview` 之后再显式 `invalidate()`（某些情况下引擎不会自己重绘），保证拖滑块时画面立刻变。

没做：曲线图形化拖点；文字参数、液化变形、裁剪与图像大小、AI。
