# 0.74.41 水彩：画笔细节无效 + 小方格

## 一、画笔细节调了没反应
**真因**：参数条给的是 1~14，但实现里 `detail.coerceIn(0,10)` 先夹到 10，再算 `r = 1 + (10-detail)/3`（**整数除法**）。结果只有 4 档：detail 1→4、4→3、7→2、10→1，而 **11~14 全部被夹成 10，也就是同一档** —— 拖最右边三个位置完全没变化。
**改法**：`r = (1f + (14 - detail) * 0.5f).toInt().coerceIn(1, 7)`，1~14 每一档都对应不同半径（1→7、14→1），并且半径上限从 5 提到 7，细节拉到最小时笔触更粗、更有水彩块感。

## 二、画面上的小方格
**真因**：底层的 `surfaceBlur` 用的是**方窗邻域**（`for dy in -r..r for dx in -r..r`）。平坦区里方形窗口的边界会连成一格格网格，看起来就是「小方格」；之前用中值时同样问题（中值也是方窗），换表面模糊只是把方格变模糊，没有消失。
**改法**：`surfaceBlur` 改成**圆盘邻域**（`dx*dx + dy*dy > r*r` 的采样点跳过）。圆盘的边界是圆的，不会再排出网格。
- 这条同时修好了「表面模糊」本身的方角问题。

## 三、没做
水彩目前仍是「表面模糊 + 边缘压暗 + 纸纹」三步近似，桌面端的水彩是滤镜库里的综合效果（湿边、纸张纹理、水渍），没有完全对齐；如果观感还差，我可以再加一层「水渍扩散」（按亮度分层的多次模糊叠加）。0.74.x 全部只编译验证，无真机验收。
