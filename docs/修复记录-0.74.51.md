# 0.74.51 目标⑨⑩⑪（收尾三项）

## ⑨ 减少杂色补「锐化细节」
桌面端四项参数：强度、保留细节、减少彩色杂色、**锐化细节**。
实现：去噪后把「原亮度 − 平滑亮度」的高频按比例加回（`Y = baseY + (原Y − baseY) × 锐化 × 1.2`），只作用亮度通道、不动色度——所以既能压噪又能找回边缘锐度，不会把彩色杂点带回来。

## ⑩ 位移补「未定义区域」
桌面端三参数：水平、垂直、**未定义区域**（环绕 / 重复边缘像素 / 设置为透明）。
实现 `offsetAt(src, dx, dy, edgeMode)`：0 环绕（`% w` 取模）、1 重复边缘（坐标夹到 0..w-1）、2 透明（越界填 0）。行区间并行。

## ⑪ 中间值半径上限提到 100
`median` 的 clamp 从 1~30 放宽到 **1~100**，参数条同步为「半径 1~100」。
大半径靠已有抽样加速：`step = r/6`、采样点封顶约 13×13，所以半径 100 也只是 169 次采样/像素（不是 4 万次），配合并行仍然可用。
