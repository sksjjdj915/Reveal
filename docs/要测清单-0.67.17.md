## 一、选区（0.67.14 那批）

**1. 1-05 减选**
- 怎么做：矩形选一块 → 模式切「减选」→ 在选区里再拖一块
- 应该看到：只去掉重叠的那部分，**画布别的地方一点没变**（以前会把整块画布清掉）

**2. 1-06 修改五项（羽化/平滑/扩张/收缩/边界）**
- 怎么做：选一块 → 打开「修改」→ 只拖「羽化」到底，再只拖「扩张」
- 应该看到：只影响你拖的那一项（以前拖羽化会连扩张收缩一起算）；拖动时画面实时变；松手后**选区大小不会越调越大**（反复点「应用修改」也不叠加）

**3. 1-08② 多边形套索首点**
- 怎么做：多边形套索点第一个点，先别点第二个
- 应该看到：第一个点当场就画出顶点；点够 3 个出现绿圈

**4. 1-08③ 画布内长按**
- 怎么做：在画布**里面**长按不动
- 应该看到：**不弹菜单**（只有画布外长按才弹）

**5. 1-11 选择主体**
- 怎么做：用 `桌面\Reveal-测试图\ComfyUI_00387_.png` 这种有栏杆/渐变的图，点「选择主体」
- 应该看到：选中的是人/主体，**不是背景**（以前整片反了）

**6. 1-12 色彩范围**
- 怎么做：① 容差调到很小（0~5）点一个的颜色 ② 正常点一次看压暗 ③ 取消选区后再看
- 应该看到：① 弹一句「这个容差下没找到相近的颜色…」不是没反应 ② 选区外压暗**能看出但看得清画面**（以前 59% 太黑） ③ 没选区时**不压暗**

**7. 1-12 有选区时缩放卡顿**
- 怎么做：选一块大区域 → 双指缩放/平移
- 应该看到：跟手、不卡；蚂蚁线在缩放时暂停，停下再动

**8. 1-13 选择并遮住**
- 怎么做：选一块 → 选择并遮住 → 拖羽化 → 点两次「应用」
- 应该看到：① 拖时就预览 ② 点两次不会越点越大 ③ 选「新建图层蒙版」后**蒙版真的生效**（以前等于没蒙版） ④ 选「新建图层」抠出来的图**在最上面**，没被上层盖住 ⑤ 点「取消」回到原选区，**不是把选区删了**

**9. 1-13 打开面板不动选区**
- 怎么做：选一块 → 打开选择并遮住 → 什么都不拖，直接关掉
- 应该看到：选区跟进来时**一模一样**（以前默认值会先改一遍）

**10. 1-15 放大/缩小选区**
- 怎么做：在画面**角落**选一小块 → 放大选区
- 应该看到：以这块**自己的中心**往外长，不会被推走

## 二、修图工具（0.67.14 + 0.67.16）

**11. 1-16 污点修复**
- 怎么做：在头发/皮肤/背景交界处点一下；再试「取样圈宽」「边缘融合」两个滑块
- 应该看到：不会把一小块画面「搬走」；两个滑块都有明显作用

**12. 1-16 污点修复三种模式（0.67.16 重做）**
- 怎么做：同一个痘痘，分别用「内容识别 / 创建纹理 / 近似匹配」点
- 应该看到：三模式结果不一样；皮肤/天空这种平滑处**看不出补过的块**（以前是硬贴一块）

**13. 1-17 修复画笔（0.67.17 重做）**
- 怎么做：先点一下取样，然后在**渐变**上拖一道；抬手后再看边界
- 应该看到：抬手后有一下（几十毫秒）处理；边界**没有方块笔触印、没有颜色跳一档**

**14. 1-17 修复画笔涂三遍**
- 怎么做：同一处来回涂三遍
- 应该看到：基本不变（以前越涂越糊/越偏色）

**15. 1-17 修复画笔 4096 大图**
- 怎么做：4096 文档上拖一道
- 应该看到：抬手最多几十毫秒，不卡

**16. 1-18 仿制图章不透明度**
- 怎么做：仿制图章参数条看不透明度
- 应该看到：是**细线滑块 1~100%**，不是「100%→75%→50%→25%」循环按钮

**17. 1-19 红眼**
- 怎么做：拖框框住眼睛，**拖动过程中**看；再框一片没有红眼的区域抬手
- 应该看到：拖动时有虚线框+四角标记；处理不卡手；没命中会给「把框拉大 / 瞳孔大小调大」的提示（不再没反应）

**18. 1-20 减淡/加深**
- 怎么做：在彩色区域（红/蓝）上刷，参数试「阴影/高光」和保护色调
- 应该看到：亮的是**同色调变亮**，不发白/不发灰；参数有大小、曝光、范围、保护色调

**19. 1-21 海绵**
- 怎么做：强度拉满在彩色块上刷
- 应该看到：明显掉色（以前几乎没效果）；参数有大小、模式、强度、喷枪

**20. 1-23 艺术历史画笔**
- 怎么做：在一张风景上涂一道
- 应该看到：是**一颗颗笔触感**，不是细密噪点；一笔之内颗粒连续

**21. 1-24 涂抹**
- 怎么做：来回涂同一处
- 应该看到：越涂越透的问题没了（颜色混但**不透明**）

**22. 1-25 颜色替换**
- 怎么做：把红块换成蓝，**同一块涂两遍**；再看红块里面有没有小孔；「限制」试「连续」和「查找边缘」
- 应该看到：第二遍仍然红→蓝（不再红换红）；红块里没小孔；「查找边缘」只换色块内部、**不越过边线**（0.67.16 换成 Sobel 梯度）

**23. 1-26 混合器**
- 怎么做：参数条看有没有「混合 / 载入 / 前景色 / 流量」四项；载入 0 时刷一道
- 应该看到：四项都有且都是细线滑块；刷出来是**混合**效果，不是整片前景色；不透明

## 三、橡皮（0.67.14 那批）

**24. 1-27 橡皮擦三模式**
- 怎么做：分别切画笔/铅笔/块，各擦一道；点「铅笔」看按钮
- 应该看到：三种边缘真不一样（软/硬细/方块无缝）；点铅笔**会变蓝**；有独立的大小/硬度/不透明度

**25. 1-28 背景橡皮**
- 怎么做：看参数条提示文字；在同一处反复擦；试「保护前景色」
- 应该看到：提示是**一行**（不竖排成十字架）；擦到就**真透明**（不留灰）；反复擦**不出现竹节/深点**；有大小、硬度

## 四、通用

**26. 切工具画面不跳**
- 怎么做：把画布平移到别处 → 切几个工具 → 转屏/分屏
- 应该看到：画布**停在你平移的位置**，不弹回正中

**27. 每工具独立笔刷大小**
- 怎么做：画笔调 20 → 切污点修复调 80 → 切回画笔
- 应该看到：各自记住自己的大小（互不影响）

**28. 大图缩放流畅度**
- 怎么做：4096 文档 + 有选区，双指缩放
- 应该看到：跟手（这块 0.67.14 性能改过，属于回归测试）

## 已知没做透（测到别惊讶）

1. 污点修复「近似匹配」不是桌面端那种完整 PatchMatch（现在是 12 方向挑最像的 3×3 再解泊松）。
2. 修复画笔在「带选区 / 蒙版 / 阿尔法锁定」时仍走逐笔触预览，不走整笔泊松。
3. 修复画笔「源=所有图层」+ 超大文档（>4000px 且>1200 万像素）第一笔可能有一两百毫秒顿感。
4. 颜色替换的「连续 / 不连续」差别仍不大，靠「查找边缘」起作用。
5. 每个工具独立大小已生效，但橡皮/背景橡皮用的是自己那套字段（有意为之）。
