# 0.74.58 目标②：木刻边缘沿色块轮廓

## 文献/成熟思路
木刻（剪影/版画）类效果的标准做法是**先分割再描边**：先把画面简化成有限个色块（区域），边缘画在**区域边界**上，而不是对原始亮度做梯度阈值。梯度阈值在纹理区（毛发、草地、噪点）会得到一片碎线；区域边界则是一条连续的粗线——这就是版画的观感。

## 旧实现的问题
对原图做 Sobel，`gx + gy > 阈值` 就压黑。所以：
- 细节区域全是碎边（毛边）；
- 平滑区域反而没有线（因为过渡被阈值吃掉）；
- 「简化度」只是对边缘图做均值，线变粗但也变糊。

## 新实现（区域分割路径）
1. **边缘保持平滑**：`surfaceBlur(rad, 28)`，`rad = 1 + 简化度/5`（1~3）——简化度越大，色块越少；
2. **量化标签**：亮度按 `色阶数` 分成 N 个整数标签，得到区域图；
3. **边缘 = 相邻像素标签不同**（4 邻域或 8 邻域）；
4. **边缘逼真度**：
   - 3 → 8 邻域（细节多、线更贴合原图）；
   - 2 → 4 邻域；
   - 1 → 4 邻域 + 去掉孤立细边（只留成规模的边界，最概括）。
5. 色块按量化灰阶上色、边界压纯黑。

这样毛发/草地这类高频区不会再碎成一片，线条是一条连续的轮廓。

## 没做
1. 没有做真正的 meanshift 分割（现在是「平滑 + 量化」，对渐变过渡区仍可能出现层状边界）；
2. 没有「沿轮廓加粗」的线宽参数（线固定 1px）；
3. 0.74.x 全部只编译验证，无真机验收。
