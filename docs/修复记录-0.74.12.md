# 0.74.12 渐变映射补齐参数（对照桌面端）

## 参考到的桌面端事实
桌面端的「渐变映射」调整面板本体只有一个渐变条 + 「仿色(Dither)」开关；参数都在**渐变编辑器**里：色标（位置 0~100%、不透明度）、中点、以及一组预设渐变。所以「缺参数」缺的是这三样，不是滑块。

## 这次补的
1. **点色带任意位置直接加色标**（之前只能加在 50%）：命中位置取该处当前渐变的颜色做初值，加完自动打开取色器。
2. **四组预设渐变**：黑→白 / 紫→橙 / 青→粉 / 冷调，点一下整体替换（会清掉中间色标）。
3. **仿色（Dither）开关**：8 位查表最容易出色带，用 **Bayer 4×4 有序抖动**把量化误差打散成细噪点（`ColorFx.gradientMap(..., dither=true)`），渐变过渡里的断层会明显减少。这是桌面端同名开关的同一原理。
4. **预览改常驻泵**：原来 `LaunchedEffect(lo, hi, stopsKey)` 拖色标时不断被取消，现在常驻循环 + 后台线程 + 16ms 节拍，拖色标位置能实时看到变化。

## 这次没做
1. 「不透明度色标」（桌面端里每个色标还有单独 alpha）——我们的 LUT 走 RGB，接 alpha 要改 `gradLut`，单独一轮做。
2. 中点（两个色标之间的位置）没做，桌面端有；我们目前靠加中间色标近似。
3. 曲线吸管、液化/变形/图案图章专属参数、裁剪与画布大小、AI 仍是待办。
