# 0.72.8 图层拖动排序 / 长按菜单 / 打组 / 选区运算

1. **上移下移去掉**，改成**按住行上下拖动**排序：拖动累计超过约 46px 就与相邻层交换（`moveLayer(from,to)`），放手停住；列表实时刷新。
2. **删除 / 新建**：标题行现在是「组+ / 置入图 / 新建 / 删除」四个**文字按钮**（之前只有图标，容易看不见）。
3. **长按菜单**：长按任意一层弹出「复制这一层 / 打成组 / 删除这一层」；复制走 `duplicateLayer(i)`，成组和删除会先选中该层再执行。
4. **打组没反应**：根因是 `groupLayersAt` 要求至少 2 层才动作（单选一个层直接 return -1）。已放宽到 1 层，并顺手把组头默认折起来。
5. **选区运算补齐**：抠图参数区第一行加了 `新建 / 加选 / 减选 / 交叉` 四个 chip，直接写 `SketchView.selectOp = SelectOp.NEW/ADD/SUB/INTERSECT`。

没做：组不参与拖动排序（拖组头只会在顶层之间移动）；PSD 导出仍是占位。
