# 测试用 PSD 语料（2026-11-08）

生成脚本：`E:\deepseek\_mkpsd.py`（psd_tools 1.24.0 + PIL，可直接重跑）
位置：`%USERPROFILE%\Desktop\Reveal-测试PSD\`

| 文件 | 结构 | 要验的点 |
|---|---|---|
| 01_三层_中文层名 | 3 个普通层，层名走 luni（UTF-16BE） | 中文层名不乱码（我们历史上 luni 偏移读错过） |
| 02_组套组 | 外组 > 内组 > 2 层，另有一个组外层 | 组嵌套的层级、缩进、展开折叠 |
| 03_图层蒙版 | 底 + 带椭圆蒙版的层 | 蒙版是否被识别（不是把整层裁剪成椭圆那么粗暴） |
| 04_剪贴蒙版 | 椭圆形状 + clipping=1 的渐变层 | 剪贴是否生效（只显现在底形状内） |
| 05_三组三十层 | 3 组 × 10 层 = 33 项 | 图层面板滚动/性能、组排序 |
| 06_隐藏层_组透明度 | 组 opacity=128、组内一层隐藏、顶层 200 | 组透明度是否真的乘进合成；隐藏层不绘制 |
| 07_半透明层 | 一层空、一层 40% 不透明（桌面端会存成蒙版） | 半透明合成、蒙版与 alpha 的关系 |
| 08_16位 | RGB 16bit | 16 位走 Lr16 段（只读经典段会 0 层） |
| 09_CMYK | CMYK 8bit 合成图 | CMYK 打开后颜色是否可显示（能不能转换到 RGB） |
| 10_大图4096 | 4096×3072 两层，37.8MB | >24MB 走内存映射；打开耗时、内存 |

判据：**打开后图层面板里的层数/层级/名字对不对，画面对不对**。08/09 是边角，出错是预期内的，报编号即可。
