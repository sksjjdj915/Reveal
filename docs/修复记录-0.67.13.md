# 0.67.13 修复记录（对照 Reveal-测试案例.txt 的 21 条）

## 已修（19 条）

1. **1-05 减选** — 选区运算里 SUB 从 `CLEAR` 改成 `DST_OUT`。以前不管源 alpha 直接清空整块画布。
2. **1-06 选区五项修改** — 羽化/平滑/扩张/收缩/边界拆成五个独立值；打开就存一份基准遮罩，拖动只算临时预览、抬手落一次；不再是「每点一次在结果上再叠一层」。
3. **1-08② 多边形首点** — 第一下点下去就能看到顶点，不再吞掉。
4. **1-08③ 长按变形** — 长按弹菜单只在「画布外按下」时触发，画布内长按不再弹。
5. **1-11 选择主体** — 改成四边全播种的多源漫水；算出来面积超 85%（等于把背景当主体）时回退到边界距离法。
6. **1-12 色彩范围** — 找不到相近颜色时弹提示（不再静默）；压暗从 59% 降到 35%；空选区不整屏压暗；缩放时不再画压暗层/边缘层、蚂蚁线暂停。
7. **1-13 选择并遮住** — 从基准选区一次算完（越点越大的问题没了）；蒙版直接用选区 alpha（以前先铺不透明黑，DST_IN 等于没蒙版）；转新图层放最上层。
8. **1-15 放大/缩小选区** — 轴心改成选区包围盒中心，不再被推走。
9. **1-16 污点修复** — 取样改成只在笔迹**外侧**一圈取（1.6r~2.4r），按距离 + 颜色接近度加权；三种模式（内容识别/创建纹理/近似匹配）分开实现。
10. **1-17 修复画笔** — 落笔时把目标和源各拍一张 1/8 小图，整笔都从这两张图取低频均值；不再「自己追自己被这一笔改过的画面」。
11. **1-18 仿制图章** — 不透明度从循环按钮（100→75→50→25）改成 1~100 滑块。
12. **1-19 红眼** — 拖动时有可见虚线框；判定放宽（金瞳棕瞳也能命中）；无命中给提示；逐像素处理挪到后台线程（绿点不再卡着不走）。
13. **1-20 减淡/加深** — 换成滤色/正片叠底（彩色不再发白）；参数条补「大小」「曝光」「保护色调」。
14. **1-23 艺术历史** — 随机取样按 8~14px 小格聚簇（同一格同一偏移），一笔内固定种子；看起来是笔触不是雪花。
15. **1-24 涂抹** — 只混 RGB，alpha 保持目标像素原样，不再越涂越透。
16. **1-25 颜色替换** — 落笔不再把连通区一次算死；不会把刚涂上的前景色又当成目标色（红换红）；容差边缘加软过渡，红块里不再出小孔。
17. **1-26 混合器** — 参数补齐：大小/混合/载入/前景色/流量；前景色只按「混合 × 载入」掺入，默认几乎不带色；只混 RGB 不抬 alpha。
18. **1-27 橡皮擦** — 橡皮有自己独立的大小/硬度/不透明度；铅笔模式按笔刷大小画硬边；块模式沿路径盖方块笔头（不再折线接头处坑洼）；点「铅笔」按钮会变蓝。
19. **1-28 背景橡皮** — 提示文字另起一行不再竖排；命中就一次擦到 0（不留灰底）；一笔内覆盖度取最大值（不再竹节/深点）；补大小/硬度；保护前景色默认开。

## 部分修（2 条，如实说明）

20. **1-21 海绵** — 强度系数从 0.12/0.22 提到 0.45/0.7，强度从循环按钮改成滑块，补「大小」。但**逐像素仍在 8 位 HSV 上算**，没有改成浮点累积，反复涂同一处仍会有量化损失。
21. **1-16 污点修复 / 1-17 修复画笔的高级参数** — 只做了「大小/强度/修正半径」；取样圈宽、边缘融合没有单独做成滑块（按半径比例固定）。
