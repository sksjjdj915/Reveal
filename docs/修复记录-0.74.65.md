# 0.74.65 目标⑧ 第 4 步（上半）：选区映射成范围

## 做法
新增 `SketchView.selectionBounds(): RectF?`：扫一遍选区位图的 alpha，取「alpha > 8」像素的包围盒（全透明返回 null）。
新增 `SketchView.regionFromSelection(ellipse: Boolean)`：用包围盒中心/半径造一个 `RegionSpec`（`ellipse=true` 生成椭圆，`false` 生成矩形），羽化沿用当前工具值，插入后自动设为 active。

## 面板入口
`RegionDock` 里，只要当前有选区，就多出两颗胶囊：
- 「**由选区生成**」→ 椭圆范围；
- 「**由选区生成矩形**」→ 矩形范围。

这样可以把「抠图模式里精细抠出来的选区」一键变成调色范围，不用再手动画圆。

## 局限（下一步补）
1. 只取**包围盒**，不是精确轮廓——不规则的选区会变成外接椭圆/矩形；
2. **范围还没随工程保存**：现在只在内存里，切换工程/重启会丢（下一步接 `ProjectStore`）；
3. 预览裁切仍是硬边（羽化只在应用时生效），这点和上一版一致。
