# 0.74.4 色相饱和度（六色相带 + 着色）/ 亮度对比补参数 / 预览常驻循环

## 一、色相饱和度按桌面端做完整（`image/HueSat.kt` 新建）
- **全图**通道 + **六个色相带**（红/黄/绿/青/蓝/洋红，中心 0/45/90/180/225/300°）：每个色带各自有 色相 / 饱和度 / 明度 三档。
- 色带权重用余弦窗 `w = 0.5 + 0.5·cos(π·d/60)`（d = 与带中心的角度差，≥60° 权重归零），所以改「红」不会连带把「黄」拉走，和桌面端的分带逻辑一致。
- **着色**开关：打开时先按新亮度算灰度，再用「色相 + 饱和度」上色（桌面端的 Colorize）。
- 面板：顶端一排通道胶囊（全图 + 六带）、三个一行一个的滑块、着色胶囊、说明文字、「应用 / 重置本通道 / 取消」；预览走 `previewBase` 跟手。

## 二、亮度对比度补参数与说明（`image/Tone.kt` 新建）
原来只有「亮度 / 对比度」，按桌面端/LR 的习惯补到四项：
- **亮度**（-100~100，整体加偏移）
- **对比度**（-100~100，以中灰 0.5 为轴）
- **高光**（只抬/压亮部，权重 `(luma-0.5)*2`）
- **阴影**（只抬/压暗部，权重 `(0.5-luma)*2`）
三通道同样处理，不做白平衡偏移，所以拉高光不会偏色。面板加了一句说明和「归零」。

## 三、曝光度等「抬手才有预览」
- 根因：`FxSpecDialog` 的预览是 `LaunchedEffect(参数)` —— 参数一变，**上一次还没算完就被取消**，只有停手 12~60ms 才真的算完一次。
- 改法：换成**常驻循环**：`LaunchedEffect(Unit) { while (true) { 取最新参数快照 → 变了就算 → setPreview + invalidate; delay(12) } }`，参数用 `rememberUpdatedState` 读，循环本身不重启。所有走通用面板的调色项（曝光度、黑白、色彩平衡、色调分离、渐变映射等）一并受益。

## 没做
文字参数、液化变形、裁剪与图像大小、AI；曲线吸管/自动。
