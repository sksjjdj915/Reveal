# 0.74.56 九项目标 ①⑦：撤销失效修复 + 顶部工具搜索

## ⑦ 调色应用后撤销没反应（真因）
`applyFilterToActive` 应用完会把结果写进图层并压一条撤销，但**预览图 `previewBitmap` 还盖在图层上面**。
于是按撤销时：图层像素确实还原了，但预览还在上面显示着「已经调过的样子」→ 看起来完全没反应；而预览泵在参数没变时不会再重算，再按一次撤销/或者切工具之后预览被清掉，才感觉「第二次才撤回」。
**改法**：`SketchView.undo()` / `redo()` 开头都调 `clearPreview()`——撤销/重做第一件事就是把临时预览摘掉，保证看到的是真实图层状态。

## ⑥ 状态栏上方的工具搜索
- 顶栏（撤销/重做右边）新增**放大镜按钮**「搜索工具」。
- 点开是白色搜索卡片：输入框 + 结果列表；每条结果右侧灰字标出它属于哪个模式（如「滤镜 · 马赛克」会标「调色」）。
- 点中一条 → **自动切到该工具所属模式**（`mode = 该模式`、其它模式入口全部关闭，因为 `activeTool` 只有一个），同时把参数面板打开。
- 索引范围：六个模式的全部工具 + 30 个子滤镜（`allToolsForSearch()` 汇总，`FILTER_SUB_TOOLS` 归到「调色」）。
- 实现放在新文件 `ui/ToolSearchSheet.kt`，避免 `CanvasPage` 方法体过大。

## 没做
搜索只匹配工具名/中文标签/内部 id，不匹配参数名（例如打「EV」找不到曝光度）；没有拼音首字母匹配。0.74.x 全部只编译验证，无真机验收。
