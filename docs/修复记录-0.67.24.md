# 修复记录 0.67.24

承接 0.67.23。0.67.23 交付时我列了四条「保留项」，用户要求全修，这一版把这四条都补掉。

---

## 1. 污点修复「创建纹理」不再整块搬

**以前**：创建纹理模式和内容识别一样，直接找一个「最像的块」整块平移进洞里——所以涂出来是一整块重复的图案，纹理没有颗粒感。

**现在**：洞内每个像素按自己的位置做哈希，从 12 个方向里挑一个，沿那个方向往外圈找最近的干净样本取色。相邻像素方向不同 → 取到的样本也散开 → 有颗粒、不会一块块重复。

内容识别的搜索距离也拉远了（1.7 倍环半径），适合「周围有明显结构、要找到同样结构的地方」。

**应该看到**：在草、沙子、木纹这类纹理上涂，补上去的部分有颗粒、不是一整块复制；换成「内容识别」时补得更平、结构更连贯。

## 2. 长笔迹污点修复也一次性补完

**以前**：只有笔迹包围盒 ≤25 万像素（大约 500×500）才做「整条笔迹一次补完」，更长的自动退回逐段补 → 又出现月牙、发虚、边缘留印。

**现在**：按 320×320 分块跑，块与块之间叠 4 像素，长笔迹也一次补完。每块的求解迭代上限仍是 20 轮，速度可控。

**应该看到**：一笔拖很长（横跨半个画面）再抬手，补出来的区域是均匀的，没有一节一节。

## 3. 背景橡皮的「限制」真正生效

**以前**：参数条上的「连续 / 不连续 / 查找边缘」只是个循环按钮，`eraseByColor` 根本没有限制参数——三种模式擦出来一模一样。

**现在**：
- **连续**：从落点出发，只擦和落点同色、且连通的一片；中间的边界会挡住（一笔之内自己维护连通表，跨段也接着扩）。
- **不连续**：全画面同色都擦（原来的行为）。
- **查找边缘**：3×3 Sobel 算梯度，强边处跳过——擦渐变背景不会越过主体轮廓。

另外擦除改用**累计覆盖度**：命中就一次擦到位，不会出现「擦完留一层灰、要再来几遍」。

**应该看到**：选「连续」在纯色块中间点一下，只擦这一块，不越过色差边界；选「查找边缘」擦渐变，主体边缘不会被啃掉。

## 4. 减淡 / 加深有收敛，反复涂不会纯白纯黑

**以前**：每段都按固定幅度提亮/压暗，同一处多涂几下就顶到 255 纯白 / 0 纯黑，彩色还会褪成一片粉或一片灰（滤色本身会降饱和）。

**现在**：乘性明度缩放 + 按剩余余量收敛——越接近很亮（0.94 明度）减淡越慢，越接近很暗（0.08）加深越慢。反复涂会稳定在「很亮 / 很暗」，不会死白死黑，色相饱和度始终保留。

**应该看到**：在同一个地方按住多涂几遍，颜色停在明亮/深暗，不会变成纯白或纯黑块。

## 没做的

- 污点修复的 PatchMatch 仍是最多 3 轮（桌面端里能迭代更多）；质量优先时可以自己多涂两遍叠加。
- 「创建纹理」的颗粒是伪随机哈希，不是真纹理合成（没有做 example-based texture synthesis）。
- 背景橡皮「查找边缘」的阈值跟「容差」联动（`tol*0.6+24`），没单独给一个「边缘阈值」滑块。

## 怎么验（四条，各 30 秒）

1. 找一张草地图，污点修复 → 模式「创建纹理」→ 涂一道，看是不是有颗粒、不是整块重复。
2. 同一张图，一道笔迹横跨半个画面再抬手，看补出来的区域是否均匀。
3. 背景橡皮 → 限制选「连续」→ 在纯色块里点一下，看是否只擦这一块；再选「查找边缘」→ 在天空渐变上擦，看主体边缘是否保住。
4. 减淡工具 → 同一处按住涂五六遍，看是否停在很亮而不是纯白；再换加深看是否停在深暗而不是纯黑。
