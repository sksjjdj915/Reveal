# 0.74.89 范围面板加「自检圈外」按钮

## 是什么
范围面板里多一颗胶囊「**自检圈外**」。点它会当场比对两件事：
- 范围蒙版为 0 的地方（＝圈外），在**当前图层像素**里有多少是不透明的；
- 有多少是半透明/透明。

然后直接在下方面板里给一句人话：

| 结果 | 含义 |
|---|---|
| `圈外完好：N 个像素全部不透明` | 像素是好的 → 之前看到的透明是**绘制**问题（0.74.88 已修） |
| `圈外有 M / N 个像素是半透明（x%）` | 像素真被写坏了 → 是某个操作把 alpha 改了，把这句话发我 |

## 有什么用
这是把「肉眼判断」换成「程序核对」：以后不用再靠截图猜，点一下就出结论。配合 0.74.87 的应用后自检日志（`alpha 警告`），两条线索一起能定位是「写坏了」还是「没画出来」。

## 顺带核对的裁剪点
`SketchView` 里所有 `clipRect / clipPath` 一共 4 处，逐个看过：画布自身、绘制预览（已修）、笔刷落笔、导出——除已修的预览那处，其余都不会造成缺块。

0.74.x 仅编译验证，无真机验收。
