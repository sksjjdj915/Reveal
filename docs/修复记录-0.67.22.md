## 一、选择并遮住：把桌面端那几项补上

**原因**：面板只有 半径/平滑/边缘位移/对比 四个滑块，输出只有三项，桌面端的「智能半径」「净化颜色」都没有；
另外打开面板会把工具切成选区工具，关掉之后人还停在选区工具上。

**改法**
- 新增「智能半径」（默认开）：`SketchView.gradMap()` 把当前图层缩到 1/8 算 Sobel 梯度，
  `smartEdgeMask()` 用 BFS 从选区边界往外/往里走，**碰到强边缘（梯度 > 0.22）就停**——
  平坦的地方继续吃到「半径」那么多像素，跨过头发/背景这种明显交界就不吃，边缘会咬在真实轮廓上。
- 新增「净化颜色」滑块（0~100）：输出成新图层时，把边缘半透像素往邻近不透明像素的平均色拉，
  抠图常见的白边/彩边就是这一步去掉的（`selectionToNewLayer` 内 `selCleanAmount`）。
- 「输出到」保持 选区 / 图层蒙版 / 新图层（桌面端的另外两项「新建文档」「新建带蒙版图层」没有对应功能，不做）。
- 打开面板前记住当前工具，关闭面板时还原（原来会一直停在选区工具上）。

**应该看到**：拖「半径」时边缘变软但不会糊到背景里（智能半径开着时更贴轮廓）；
「净化颜色」拉高后抠出来的新图层边缘不再有小白边/彩色描边；关掉面板回到你打开前的工具。

## 二、污点修复：抬手做一次真正的 PatchMatch

**原因**：以前是逐下笔尖在「笔尖外一圈」取平均，纹理走向接不上，交界处会把一小块结构搬走。

**改法**：新增整条笔迹的覆盖度缓冲（`spotCov`，半分辨率）＋ `solveSpotStroke()`：
抬手提交那一批像素前，在 2px 粗网格上做 PatchMatch——随机初始化 → 邻居传播（左/上）→
半径递减的随机搜索，共 3 轮，代价函数是 3×3 块 SSD（源块不能取自洞内），
最后按覆盖度把结果贴回，软边不出现硬接缝。只在「近似匹配」模式、只在这次提交的范围里动手，
所以撤销记录照样覆盖到每一个改过的像素。

**应该看到**：在条纹状/纹理明显的区域拖一笔，接缝比以前顺；不会出现「一小块被挖走又贴歪」。

**保留**：内容识别/创建纹理两种模式仍是逐下笔尖处理（它们本来不是「找相似块」的思路）。
PatchMatch 在 2px 网格上做，不是 1:1 像素级（手机上一笔几万像素做全分辨率会卡）。

## 三、修复画笔：有选区 / 锁了 alpha / 超大图 也照样解泊松

**原因**：以前只有「无选区、无蒙版、没锁 alpha、≤1200 万像素」才解泊松，其余退回逐笔触预览（有涂抹感）。

**改法**
- 有选区：把选区 alpha 整行读进 `guard` 数组，逐像素裁（`kf *= maskAlpha/255`），只改选区内的像素。
- 锁了透明度：只在落笔前 alpha != 0 的像素上写。
- 超大文档：覆盖度缓冲自动降半分辨率（`healCovScale = 2`），不再整个功能关掉。

**应该看到**：先框一个选区再用修复画笔，只有选区里被改；锁了透明度的图层上不会凭空长出像素。

## 四、「源 = 所有图层」第一笔就是全图

**原因**：拍平放后台，第一笔常常还没拍好，于是第一笔实际只用了当前层。

**改法**：落笔时若没有缓存且文档 ≤ 800 万像素，当场拍平（`flatten()`）并填缓存。
更大的文档仍然走后台（当场拍平会明显卡一下）。

## 五、选区压暗改成路径填充

**原因**：压暗是一张全幅 ARGB 位图（4096² = 64MB），每建一次就多一张全图。

**改法**：`rebuildEdge()` 后台顺手算出「整幅矩形 + 选区轮廓」的**偶奇路径**（`evenOddDimPath`），
`drawSelection` 直接 `drawPath(selDimFill)`。轮廓算不出来（极少数魔棒结果）时才退回位图。

**应该看到**：大图上按选区、拖选区，内存峰值和顿挫都会低一些；压暗效果不变。

## 六、后台重建与位图回收的竞态

**原因**：后台线程正在读选区遮罩时，主线程别处 `recycle()` 了它 → 后台读到已回收的位图，
要么异常被吞掉（这一帧跳空），要么直接崩。

**改法**：所有「换选区时回收旧遮罩」都走 `recycleLater()`——后台任务还在跑就先挂进 `pendingRecycle`，
任务回到主线程时 `flushPendingRecycle()` 统一回收。

**应该看到**：连续快速换选区/缩放不再偶发跳一帧或崩。

## 还没做的（明确说明）

1. 「输出到」只有 3 项（桌面端的「新建文档」「新建带蒙版图层」没有对应实现）。
2. 污点修复另外两种模式的逐下笔尖算法没换（只有「近似匹配」换成了 PatchMatch）。
3. PatchMatch 在 2px 粗网格上跑，最细的 1:1 纹理细节不会完全还原。
4. > 800 万像素文档的「源=所有图层」第一笔仍可能先用当前层（后台还没拍完）。
5. 智能半径的阈值（梯度 0.22）是经验值，遇到特别低对比的边缘仍要手动调「半径」补。

## 怎么验

1. 抠一张头发/栏杆的图 → 选择并遮住 → 拖半径、开智能半径 → 边缘是否咬在轮廓上；
   净化颜色拉 60 输出新图层 → 边缘有没有白边。
2. 条纹衣服上拖一道污点修复 → 看接缝纹理是否顺。
3. 框个选区用修复画笔 → 选区外是否有被改到。
4. 锁透明度的图层上用修复画笔 → 空白处是否长出像素。
5. 4096 大图按选区、快速拖选区、连点缩放 → 是否还有跳一帧/崩溃。
