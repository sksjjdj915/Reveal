# 0.74.47 目标⑤：径向模糊补方法/品质

## 文献依据
桌面端「径向模糊」三个参数：**数量 1~100、模糊方法（旋转 / 缩放）、品质（草图 / 好 / 最好）**。
- **缩放**沿半径方向采样 → 冲向中心的放射模糊（越靠外位移越大）；
- **旋转**沿圆周方向采样 → 转起来的环状模糊；
- 品质只决定采样数（草图 8 / 好 16 / 最好 32），越多越平滑也越慢。

## 旧实现
`radialBlur(src, amount)`：只有「强度」，固定缩放式、固定 9 个采样点，而且位移系数用的是 `k * (s/8) * dist`——中心附近几乎不模糊、外圈过度模糊，和桌面端的「整幅放射」观感不同。

## 新实现 `FilterFx.radialBlurAt(src, amount, spin, quality, centerXpct, centerYpct)`
| 参数 | 范围 | 说明 |
|---|---|---|
| 数量 | 1~100 | 模糊强度 |
| 方法 | 0 缩放 / 1 旋转 | 缩放＝放射，旋转＝环状 |
| 品质 | 0 草图(8) / 1 好(16) / 2 最好(32) | 采样数 |

- 缩放：`t = 1 + k*f*(0.35 + dist)`，位移随半径增长（桌面端也是外圈更明显）；
- 旋转：角度偏移 `angle = k*f*2.2` 随采样累加，绕中心转。
- 行区间并行。

## 没做
1. 没有桌面端的「中心点可直接拖」（我们画布上通用有取点手势，但径向模糊这版先按画面中心，必要时可接上）；
2. 旋转式没有按半径衰减（桌面端也是全程旋转，这点一致）；
3. 0.74.x 全部只编译验证，无真机验收。
