# 0.71.6 顶栏重排 + 窄模式栏 + 调色接上

1. **顶栏**：最左一颗「首页」按钮（点开进一个空白页，只有一句「以后放工程列表 / 新建 / 设置」和「回到画布」）；右侧依次是撤销（←）、重做（→）、保存、图层（图层图标），撤销/重做用清晰箭头。
2. **工程名缩小**成一行 11sp 小字，放到按钮那排下面，后面跟尺寸 `1080 × 1620`。
3. **模式栏收窄**到 56dp（图标 + 9sp 小字），不再是 88dp 宽；收起改用**贴左边的半圆箭头**（22×44dp），箭头可以上下拖，点一下收起 / 展开。
4. **调色模式接上**（`ColorDock`）：曝光（-5~+5 EV）、饱和度（-100~+100），点「应用曝光」「应用饱和度」才对当前层生效（进撤销栈），另有「归零」。
5. 排版 / AI 仍是占位卡片。

没做：色阶 / 曲线 / 色相饱和度 这些独立面板还没接进新界面；排版模式没有实际功能。
