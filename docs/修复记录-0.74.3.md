# 0.74.3 自然饱和度做成独立完整面板

## 一、文献结论（这就是「自然饱和度」和「饱和度」的差别）
- 公开资料里的说明一致：**饱和度**对所有像素按同一比例加色，已经鲜艳的地方先溢出，肤色最先崩；**自然饱和度（Vibrance）只往不够鲜的地方加**，越饱和的地方加得越少，并且会**保护肤色**（橙红一带）。
- 参考：[DPReview 视频说明](https://www.dpreview.com/videos/8211774420/video-the-difference-between-saturation-and-vibrance-explained)

## 二、实现（新文件 `image/Vibrance.kt`）
每个像素转 HSV 后：
- 权重 `w = 1 - s`（越不鲜越加）；
- 开着「保护肤色」时，色相落在 330°~40° 且 s<0.65 的像素再乘 **0.35**；
- 正向：`s += vib * w * 0.85`；负向：`s += vib * s * 0.85`（按自身饱和衰减，不会把纯色块抽灰）；
- 之后再走一档统一的**饱和度**：`s *= 1 + sat/100`；
- 全程保留原 alpha。

## 三、面板（独立 Dock，不再走通用面板）
- 标题 + 一句人话说明（「只往不够鲜的地方加…肤色打三折」）；
- `自然饱和度` -100~100、`饱和度` -100~100，一行一个；
- `保护肤色：开/关` 胶囊（默认开）；
- 预览：`previewBase` 缩图 + 参数一变立刻 `setPreview` + `invalidate`，跟手；
- 应用（写图层、可撤销）/ 归零 / 取消。

## 没做
文字参数、液化变形、裁剪与图像大小、AI；曲线吸管/自动。
