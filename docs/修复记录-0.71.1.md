# 0.71.1 顶栏避让 + 悬浮窗变小可拖

## 一、这次改了什么
1. **顶栏不再压到系统状态栏**：`CanvasPage` 根容器加 `statusBarsPadding()` 与 `navigationBarsPadding()`，工程名和撤销/重做/保存整体下移一条系统状态栏的高度。
2. **悬浮窗变小、不写字、可拖**：
   - 收起态从「胶囊 + 模式名」改成 **44dp 圆按钮**，只留当前模式的图标，不带文字；
   - 按住可以拖到画布任意位置（拖动会实时跟手，松手停在原地）；
   - 点一下浮出模式面板（面板仍带六项文字，否则没法选），选完自动收起。

## 二、这次没做
1. 悬浮窗拖动没做边界限制（可以拖出画布外，需要的话再加夹取）。
2. 参数面板还没做（在等你确认「参数区高度」到底按哪块算）。
3. 没跑模拟器。

## 三、怎么验
1. 打开软件：顶栏应完全在系统状态栏下面，不再和电量/时间重叠。
2. 左下角是一颗小圆按钮（只有图标没有字），按住能拖走。
3. 点它 → 浮出六项模式，选一个 → 底部工具换掉、圆按钮图标换成新模式。
