# 0.74.34 重滤镜并行化（11 个）

## 做法（事故后的正确姿势）
- `Parallel.rows(fn: (y)->Unit)` 走不通：大量函数体内有 `return`，lambda 里属于非局部返回。
- 改成 **区间并行** `Parallel.chunks(h) { y0, y1 -> ... }`：线程只拿到行区间，函数体内部一行不改（该 `return`/`continue` 都合法），每个线程写自己那几行、只读同一份源数组，无锁。
- 线程数 = CPU 核数（2~8），行数 <64 或单核时退回串行；用固定线程池避免每次新建。

## 本版已接并行
表面模糊、中间值、最小值、最大值、胶片颗粒、球面化、镜头光晕、油画、水彩、动感模糊、径向模糊。
其中动感模糊额外做了一步算法优化：
- 原来采样点是 `2*distance+1`（距离 120 时 241 个点/像素），现在**采样点封顶 33 个**，长距离按步长跳采。模糊本身是低通，跳采肉眼几乎无差别，但计算量变成常数，距离拉满也不卡。
