# 0.74.7 分页改成顶部两段（按文献）

## 一、依据（先查文献）
- UX Patterns Guide 的对比结论：「**tabs 用于同一页面上下文的并列内容面板；segmented control 用于局部模式/呈现方式选择；pagination 用于翻一个有序集合**」，引用的一手来源包括 W3C ARIA Authoring Practices 的 tabs 模式、GOV.UK / Carbon 的 tabs、USWDS / GOV.UK 的 pagination、Fluent 2 的 segmented control。
- Material 3 的表述同向：segmented button 是「一个圆角容器内的一组选项」，tabs 用于并列内容切换。
- 结论：色阶（直方图｜伽马/输出）、曲线（曲线｜预设）是**同一面板的两块并列内容**，应当用 tabs / 分段控件放在**面板顶部**；底部那两条 18×4dp 细长条只适合表达页码或进度，属于误用。

## 二、改成什么样
1. **色阶**：面板第一行左边两颗胶囊「直方图」「伽马 / 输出」，当前页高亮；右边保留「黑 12 · 白 243」的实时读数；底部两条细条删除。
2. **曲线**：第一行胶囊「曲线」「预设」；第 1 页下面再一行通道胶囊（RGB/红/绿/蓝），第 2 页显示预设按钮。
3. **左右滑动翻页保留**（>40dp），所以点胶囊、滑内容两种方式都能翻。
4. 面板自适应高度（0.74.6 已做）继续生效，切页不会跳动。

## 没做
曝光度/色彩平衡/色调分离/照片滤镜/渐变映射的说明与补参数（`ui/ColorDocks.kt` 里三个 Dock 已接上但未逐项验证）。
