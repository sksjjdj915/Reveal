# 0.74.81 范围运算：新建 / 相加 / 相减 / 相交

## 加的是什么
对齐影视调色软件的窗口运算。每个范围现在自带一个 `op`：

| 运算 | 含义 | 实现 |
|---|---|---|
| 新建 | 清空之前的遮罩，只用这一个 | `drawColor(CLEAR)` 后画白色形状 |
| 相加 | 并集 | `SRC_OVER` 叠上 |
| 相减 | 从已有遮罩里挖掉这一块 | `DST_OUT` |
| 相交 | 只保留重叠部分 | `DST_IN` |

面板里在「反转 / 显示蒙版」那一行下面多了四颗胶囊，点哪颗就把**当前选中的范围**设成那个运算。

## 实现要点
- `RegionSpec` 新增 `var op: Int = 0`（老工程读进来默认 0=新建，行为不变）；
- 抽出 `private fun regionShapeAlpha(r, w, h)`：单个范围的羽化/反转/强度都在这里算；
- `regionMask()` 改为把所有范围按各自运算依次叠起来；一个范围都没画上时返回 `null`（调用方按「没有范围」处理）；
- 蒙版只按 **alpha 语义**使用——合成的 alpha 永远取原图，这点没变。

## 典型用法
- 两个人的脸要一起调：第一个「新建」，第二个「相加」；
- 圈太大带上别的东西：第二个「相减」把它挖掉；
- 只要交集：第二个「相交」。
