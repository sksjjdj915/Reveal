# 0.72.9 组做完整

## 新增能力
1. **解组**：长按组头 → 「解组（保留成员）」，走新加 `SketchView.ungroupAt(headerIndex)`——删掉组头与组底分隔层，成员原样留着，整步进撤销栈。
2. **整组拖动排序**：拖组头时走新加 `SketchView.moveGroupBlock(headerIndex, up)`，组头 + 成员 + 组底分隔层作为一个整体上下挪一格（拖普通层仍是单层交换）。
3. **重命名**：长按任意层 → 「重命名…」，弹输入框，确定后写回 `layer.name`。
4. **组头折叠**：`▾/▸` 切换（`sectionType` 1↔2），折叠后成员行隐藏；组内成员缩进显示。
5. 组的可见性、不透明度仍然作用于整组（引擎侧 `saveLayer` + `effectiveAlpha(header)` 原有逻辑）。

## 说明
- `groupDividerFor(headerIndex)` 是新加的私有helper：用 `groupSpan()` 反推组底分隔层位置，解组和整组移动都靠它定位块边界。
- 组的重命名也走同一个 `renameTarget` 对话框，名字直接改在组头上。

## 没做
1. 不支持把已有图层「拖进 / 拖出」某个组（要做得先有跨块拖拽的落点判定）。
2. 组不能嵌套折叠的状态单独记忆（重启后按存的 lsct 走）。
3. PSD 导出仍是占位；色阶/曲线、文字、液化变形、裁剪与图像大小、AI 未接。
