# 0.74.86 参数条问题 ⑤：渐变映射补参数

## 补了什么
| 参数 | 作用 | 依据 |
|---|---|---|
| 平滑度 0~100 | 0 = 色标分段线性（桌面端默认）；100 = 缓入缓出（smoothstep），暗部亮部更「聚」、中间调过渡更平 | 渐变插值曲线可调是桌面端渐变映射/渐变叠加的既有能力 |
| 反向 | 亮部取左端色、暗部取右端色 | 桌面端渐变条上的「反向」 |
| 仿色（保留） | Bayer 4×4 有序抖动，打散 8 位查表的色带 | 桌面端渐变映射的「仿色」 |
| 强度（保留） | 结果与原图按比例混合 | 手机端常用 |

多色标本来就有（色带 + 可加中间色标）：「+ 色标」在 50% 处插一个，取该位置的当前渐变颜色。

## 实现
- `AdjustOp` 新增 `gmSmooth: Int`、`gmReverse: Boolean`；
- `gradLut()` 里对归一化明度先做 `reverse`（1−t）再做 `smooth` 混合：`x = mix(x, x²(3−2x), smooth/100)`，然后才查色标；
- `ColorFx.gradientMap(...)` 把这两个参数透传进 `AdjustOp`，**调整图层那条路也自动跟着生效**（同一个 `gradLut`）；
- 面板：强度下面加「平滑度」滑块，再加一行「反向：开/关」「仿色：开/关」胶囊。

## 没做
「按 R/G/B 通道分别映射」（桌面端没有，影视调色软件有分离通道的做法，属于扩展功能，等你要我再加）；0.74.x 仅编译验证，无真机验收。
