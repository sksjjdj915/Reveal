# 0.71.0 新第一屏（按口述重做）

## 一、这次做了什么（只做用户说的四样）
1. **打开软件直接进画布**：`MainActivity.RevealApp()` 不再走首页 → 编辑器，启动时取最近一个工程（没有就新建一张 1080×1620），直接进 `CanvasPage`。欢迎弹窗也去掉了。
2. **最上方状态栏**（`NewTopBar`）：工程名 + 撤销 / 重做 / 保存，白底 50dp。
3. **画布**：`SketchView` 撑满中间，灰工作区 + 白纸 + 描边投影（上一版已加）。右上角一行小字显示 `1080 × 1620`。
4. **底部工具栏**（`NewToolRow`）：横排、可左右滚动、选中项浅蓝底；工具随模式变。
5. **悬浮窗**（`ModeFloating`）：左下角一颗小胶囊，写着当前模式；点开浮出面板，里面是六个模式（抠图/调色/排版/修图/绘制/AI），选中打勾，选完自动收起。

## 二、新文件与结构
- `ui/NewShell.kt`：`NewMode`（六模式）、`NewTool`、`toolsForMode()`（每模式 2~7 个工具）、`NewTopBar`、`NewToolRow`、`ModeFloating`。
- `ui/CanvasPage.kt`：整屏拼装 + `applyTool()`（把工具 id 翻译成 `SketchView.Tool` 与 `SelectMode`，全工程只有这一处和引擎耦合）。

## 三、这次没做（明确清空）
1. 参数面板、图层面板、图层按钮、选区工具的参数、颜色选择器 —— **一个都没接**，按你说的「什么都不要加」。
2. 「调色 / 排版 / 修图」里那些 `fx.*`、`act.*` 工具目前点了不会弹面板（只有选区类和绘制/修图类真的切了引擎工具）。
3. `EditorScreen.kt`、`HomeScreen.kt` 等旧界面文件**还在磁盘上**，只是不再被入口调用（删掉它们会连带 128 个动作入口一起消失，所以按「一屏一屏接」的节奏留到最后一起清）。
4. 没跑模拟器。

## 四、怎么验
1. 打开软件 → 直接是画布，不再有首页列表。
2. 顶部：工程名、撤销、重做、保存。
3. 底部：一排工具，能左右滑，选中变浅蓝。
4. 左下角小胶囊点开 → 六个模式，点一个 → 底部工具换掉、胶囊文字跟着变。
