# 0.73.6 曲线两页 + 加点能拖 + 面板加高

## 一、曲线加点后拖不动
- 根因：曲线上叠了两个 `pointerInput`（一个 `detectTapGestures` 加点、一个 `detectDragGestures` 拖点）。Compose 里两个手势检测器会互相消费事件，tap 那个先把 DOWN/UP 吃掉，drag 就收不到连续事件。
- 改法：合并成**一个** `awaitEachGesture`：按下先找最近控制点（阈值 0.14），按住移动就拖它（端点只动 y，中间点 x 夹在相邻点 ±0.02）；**没移动过并且没点中任何点**才算点按，在空白处插一个新控制点。这样「加点」和「拖点」不再打架。

## 二、曲线分成两页
- 第 1 页「参数」：通道胶囊（RGB/红/绿/蓝）+ 曲线编辑框（可点可拖）。
- 第 2 页「直方图」：256 档亮度直方图（抽样最多 4 万像素），单独占满整个内容区。
- 翻页两种方式：左右滑动内容区；或直接点底部**两条细线**（当前页那条是蓝的）。
- 细线放在「取消 / 应用 / 重置全部」按钮那一行**上面**，正好在按钮上方。
- 直方图那页不挤压参数页：两页各自占满同一块高度，面板整体高度 224dp → **300dp**。

## 三、其它调色面板不再挤
- `ParamDock / CutDock / ColorDock / LevelsDock / AdjustDock / EmptyDock` 高度统一 224dp → **300dp**，参数一行一个、内容超出滚动，滑块不再被压成小段。

## 四、没做
- 曲线还没有「吸管取样」「自动」按钮（要与直方图联动，下一步加）。
- 文字参数、液化变形、裁剪与图像大小、AI 仍未接。
