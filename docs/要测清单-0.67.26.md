## 一、21 个 bug 前半部分：选区（1~10）

**1. 1-05 减选**
矩形选一块 → 模式切「减选」→ 在选区里再拖一块
应该看到：只去掉重叠那部分，画布别的区域一点没变

**2. 1-06 修改五项（羽化/平滑/扩张/收缩/边界）**
选一块 → 打开「修改」→ 只拖羽化到底；再只拖扩张
应该看到：只影响拖的那一项；拖动实时变；反复点「应用修改」不越点越大

**3. 1-08② 多边形套索首点**
多边形套索点第一下，先别点第二下
应该看到：第一下就画出顶点；够 3 个点出绿圈

**4. 1-08③ 画布内长按**
在画布里面长按不动
应该看到：不弹菜单（只有画布外长按才弹）

**5. 1-11 选择主体**
用 `桌面\Reveal-测试图\ComfyUI_00387_.png`，点「选择主体」
应该看到：选中的是人/主体，不是整片背景

**6. 1-12 色彩范围**
①容差 0~5 点一下 ②正常点一次 ③取消选区后再看
应该看到：①给「没找到相近颜色，把容差调大」提示 ②压暗能看出但不糊死画面 ③没选区不压暗

**7. 1-15 放大/缩小选区**
在画面角落选一小块 → 放大选区
应该看到：以它自己的中心往外长，不被推走

**8. 1-13 选择并遮住（输出）**
选一块 → 选择并遮住 → 拖羽化 → 连点两次「应用」→ 输出试「新建图层蒙版 / 新建图层」
应该看到：双击不叠加；蒙版真生效；新图层在最上面没被盖

**9. 1-13 打开面板不动选区**
选一块 → 打开选择并遮住 → 什么都不拖直接关
应该看到：选区跟进来时一模一样；关掉后回到你原来的工具

**10. 1-13 取消不删选区**
打开选择并遮住 → 拖羽化 → 点「取消」或 ✕
应该看到：回到打开时那份选区，不是把选区删了

## 二、21 个 bug 后半部分：修图工具 + 橡皮（11~28）

**11. 1-16 污点修复基础**
头发/皮肤/背景交界点一下；再拖「取样圈宽」「边缘融合」
应该看到：不会把一小块画面搬走；两个滑块都有明显作用

**12. 1-16 污点修复三种模式**
同一个痘痘分别用「内容识别 / 创建纹理 / 近似匹配」
应该看到：三种结果不一样；平滑处看不出补过的块

**13. 1-16 污点修复 PatchMatch**
在条纹布/木纹这种有走向的纹理上拖一道长的
应该看到：接缝顺、纹理走向接得上；没有「一小块被挖走贴歪」

**14. 1-17 修复画笔 边界**
先点一下取样 → 在渐变上拖一道 → 抬手
应该看到：抬手有一下（几十毫秒）处理；边界没有笔触印、不跳一档色

**15. 1-17 修复画笔 涂三遍**
同一处来回涂三遍
应该看到：基本不变（不发糊不发偏色）

**16. 1-17 修复画笔 有选区**
先框一个选区 → 用修复画笔跨选区边缘涂
应该看到：只有选区里面被改，外面一点不动

**17. 1-17 修复画笔 锁透明度**
图层开「锁定透明度」→ 修复画笔涂到透明区域
应该看到：空白处不会凭空长出像素

**18. 1-17 修复画笔 4096 大图**
4096 文档上拖一道
应该看到：抬手最多几十毫秒，不卡

**19. 1-18 仿制图章不透明度**
看仿制图章参数条
应该看到：细线滑块 1~100%，不是 100→75→50→25 循环按钮

**20. 1-19 红眼**
拖框框住眼睛看拖动过程；再框一片没红眼的抬手
应该看到：拖动有虚线框+四角；处理不卡手；没命中给提示

**21. 1-20 减淡/加深**
红/蓝彩色区刷，试 阴影/中间调/高光 + 保护色调
应该看到：同色调变亮，不发白；参数有 大小/曝光/范围/保护色调

**22. 1-21 海绵**
强度拉满在彩色块上刷
应该看到：明显掉色；参数有 大小/模式/强度/喷枪

**23. 1-23 艺术历史画笔**
风景图上涂一道
应该看到：一颗颗笔触感，不是细密噪点；一笔内颗粒连续

**24. 1-24 涂抹**
来回涂同一处
应该看到：颜色混但不透明（不再越涂越透）

**25. 1-25 颜色替换**
红块换蓝，同一块涂两遍；看红块里有没有小孔；「限制」试「连续 / 查找边缘」
应该看到：第二遍仍红→蓝；没小孔；查找边缘不越过边线

**26. 1-27 橡皮擦三模式**
分别切 画笔/铅笔/块 各擦一道；点「铅笔」看按钮
应该看到：三种边缘真不一样；点铅笔会变蓝；有独立 大小/硬度/不透明度

**27. 1-28 背景橡皮**
看参数条提示；同一处反复擦；试「保护前景色」
应该看到：提示是一行（不竖成十字架）；擦到就真透明；反复擦不出竹节/深点；有 大小/硬度

**28. 1-26 混合器**
看参数条是否 混合/载入/前景色/流量 四项；载入 0 刷一道
应该看到：四项都在且是细线滑块；刷出混合效果不是整片前景色；不透明

应该看到：能取到画面远处的同源纹理，不是附近一小块反复重复

## 跟桌面端仍不同的地方（不是 bug，是取舍）

1. 选择并遮住「输出到」只有 3 项（桌面端的「新建文档 / 新建带蒙版图层」没做）。
2. 污点修复只有「近似匹配」走完整 PatchMatch；「内容识别 / 创建纹理」走样本合成，不是向量式补全。
3. > 800 万像素文档，「源=所有图层」第一笔仍可能先用当前层（全图拍平在后台跑）。
4. 智能半径阈值（梯度 0.22）是经验值，低对比边缘还要手动调半径。
5. 橡皮 / 背景橡皮用自己的大小字段（有意为之），不跟画笔共享。
