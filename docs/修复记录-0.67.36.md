# 修复记录 0.67.36（code 301）

日期：2026-11-08

## 这次改了什么：全部参数条「拖了没反应」

### 现象

参数**真的生效了**（画出来的效果会变），但界面上的滑块不跟着动、数字不变、开关点了文字也不变。看起来像「这个参数坏了」。

### 根因

Jetpack Compose 只有读到 **Snapshot 状态**（`mutableStateOf` / `mutableFloatStateOf` / `mutableIntStateOf`）才会重组界面。
参数存在 `SketchView` 的普通 `var` 里时：

- 画笔/工具在绘制时读这个值 → **效果正常**；
- 参数条在 `composable` 里读同一个值 → Compose 完全不知道它变了，**界面永不刷新**。

所以「有效果、没反应」是同一条根因的两种表现。

### 改法：把工具参数全部换成 Snapshot 状态

`SketchView.kt` 里 **89 个参数**改成状态托底、对外保留同名属性（get/set 转发），其它代码一行不用改：

- 浮点：`mutableFloatStateOf(v)` + `.floatValue`
- 整数：`mutableIntStateOf(v)` + `.intValue`
- 布尔：`mutableStateOf(v)` + `.value`

覆盖范围（按工具分组）：

| 组 | 参数 |
|---|---|
| 画笔 | brushSize / brushOpacity / brushHardness / brushType / brushBlend / brushSmooth、角度与抖动（brushAngle、brushSizeJitter、brushOpacityJitter、brushFlowJitter、brushAngleJitter、brushRoundJitter、brushColorJitter、brushNoise、brushDualOn/Count/Size、brushMinDiameter、brushVelocity、brushRev、brushWetEdge）、纹理（brushTexture / brushTextureMode / brushTextureDepth） |
| 橡皮 | eraserSize / eraserHardness / eraserOpacity / eraserMode |
| 背景橡皮 | bgEraserSize / bgEraserHardness / bgEdge / bgLimit / bgProtect / bgSampleMode |
| 修复 / 仿制 | cloneOpacity / cloneAligned / cloneAllLayers / healDiffusion / spotType / spotRing / spotFeather |
| 色彩替换 | replaceMode / replaceSample / replaceLimit / fxTolerance |
| 混合器 | mixerWet / mixerMix / mixerLoad / mixerFg / spongeMode / spongeStrength / spongeAirbrush |
| 艺术历史 / 图案 | artStyle / artFidelity / artRegion / patternIndex / patternAligned / patternImpressionist |
| 红眼 | redeyePupil / redeyeDarken |
| 魔棒 / 快速选择 / 选择主体 | wandTolerance / wandContiguous / wandSampleAll / quickTolerance / quickSize / subjectTolerance / magnetWidth |
| 液化 | liquifyMode / liquifyStrength |
| 减淡 / 加深 | dodgeStrength/Range/Protect、burnStrength/Range/Protect（0.67.34 已改） |
| 视图 / 辅助 | showGrid / gridCount / gridStepPx / showRuler / showGuides / snapGuides / channelView / historySource / pencilAutoErase / magicContinuous / magicAntialias / magicAllLayers / gradientRadial / eraseToHistory |

其中 4 个原来带自定义 setter 的（channelView 要换通道滤镜、gridCount / gridStepPx 要 coerceIn、showRuler 要 invalidate）改成把原逻辑合并进新的 setter，行为不变。

## 怎么验

随便挑几个参数条拖一下，界面都应该立刻跟着变：

1. 画笔 → 参数：大小、不透明度、硬度、流量、间距，滑块与数字同步。
2. 橡皮：大小、硬度、不透明度；三种模式点了要变蓝。
3. 仿制图章 / 修复画笔：不透明度、修正半径。
4. 色彩替换：容差；背景橡皮：容差、边缘阈值。
5. 混合器：湿度、载入、混合、前景色、流量。
6. 魔棒：容差；快速选择：笔刷大小、容差。
7. 减淡 / 加深：曝光、大小、保护色调。
8. 视图：网格开关、格数、标尺开关。
9. 点「通道」切换红/绿/蓝：三张灰度应该立刻切换，回来点 RGB 恢复。

## 说明

- 这是纯界面刷新问题，绘制算法一行没动，所以之前「有效果但没反馈」的参数改完之后效果应与之前一致。
- 参数条之外，对话框（色阶、曲线、曝光度、黑白等）本来就是 Compose 本地状态，不受影响。
