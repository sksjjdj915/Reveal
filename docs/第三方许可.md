## 3. sRGB 色彩配置文件

`app/src/main/java/com/reveal/editor/image/SrgbProfile.kt` 内嵌一份 sRGB ICC 配置，字节取自
系统标准的 sRGB Color Space Profile（配置文件内自带的版权声明为 Copyright (c) 1998
Hewlett-Packard Company），该配置文件允许随软件免费分发。

## 4. 未随包分发的色彩配置

工程不内嵌第三方 CMYK / 印刷用色彩配置。打开带这类配置的分层文件时，配置从文件自身携带的
ICC 数据运行时解析，不在 APK 内保存，也不对外分发。

## 5. 关于文件格式名称

本工程按公开的分层图像文件格式规范实现读写，代码与文案中出现的 `.psd`、`.psb`、`8BPS` 等
字样仅为文件格式与字节标识，不代表与任何软件厂商存在隶属或合作关系。

文档（`docs/` 下的开发记录）里出现的其他软件名称，只用于说明「这个做法业界已有实现」的
事实引用，不表示代码或界面来自这些软件。
