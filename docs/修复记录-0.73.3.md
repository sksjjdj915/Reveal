# 0.73.3 色阶加直方图 + 实时预览 + 参数行放宽

## 一、「色阶参数没反应」
- 原来只有点「应用」才动画面，拖滑块看不到变化（其它滤镜面板是带预览的，所以对比更明显）。
- 现在：打开色阶时把当前层位图复制一份当底图，**参数一变就在副本上算一次并贴到预览层**（`setPreview`，70ms 节流），退出或点「应用 / 取消」时清预览；「应用」才真正写进图层（可撤销）。

## 二、直方图
面板顶部加了一条亮度直方图（256 档、抽样最多 4 万像素，避免大图卡顿）：
- 落在「输入黑场 ~ 输入白场」之外的柱子显示成浅灰（被切掉的部分），区间内是深灰；
- 底色浅灰、圆角，和面板其它控件同一套视觉。

## 三、「一点就调很多」
- 原因是参数并排三列，每列只有约 90dp 宽，0~255 的映射下 1px 就是 2~3 个色阶值。
- 改成**一行一个参数**：标签 56dp + 滑块占满剩余宽度 + 数值 44dp，同样拖动幅度对应的变化值小了一个数量级，便于微调。
- 曲线面板同步改成一行一个参数（阴影/中间调/高光）。

## 没做
曲线仍没有「拖控制点」的图形化曲线控件；文字参数、液化变形、裁剪与图像大小、AI 未接。
