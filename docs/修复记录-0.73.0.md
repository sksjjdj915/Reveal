# 0.73.0 PSD 导出接通

## 实现
新增 `SketchView.exportPsdBytes()`：按当前图层表重建 `Psd.PsdLayer` 列表，再交给 `Psd.encode(w, h, layers)` 输出标准 PSD 字节。
- 每层带上：名字、位图、可见性、不透明度（`alpha`）、混合模式（`blendMode`）、剪贴蒙版（`clipped`）、锁定透明（`alphaLock`）、蒙版（`mask`）、组结构（`sectionType`）。
- 组底分隔层（`sectionType == 3`）按 PSD 约定写成 `lsct=3` 的空层，组头和折叠状态靠 `sectionType` 1/2 写回，所以在电脑上的修图软件 里仍然是一个组。
- 导出走系统「保存到」对话框（`CreateDocument("image/vnd.adobe.photoshop")`），文件名 `reveal.psd`，完成后 Toast 报大小（KB）。

## 已知限制（写进面板说明）
- 调整层（色相饱和度、亮度对比、色阶）与渐变映射在这条「整层重建」路径下会**烘成像素**，不是可再编辑的调整层。要保留可编辑调整块，得走旧界面那条 `buildPsdNow()`（它带原始调整参数与 smart 源），需要时再单独搬。
- 16 位 / CMYK / 灰度回写仍只在旧链路里；新界面导出统一 8 位 RGB。

## 没做
色阶/曲线面板、文字参数、液化变形、裁剪与图像大小、AI 仍未接。
