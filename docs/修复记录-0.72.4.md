# 0.72.4 容差量纲修正（魔棒全选 / 时灵时不灵）

## 一、根因
引擎里的 `SketchView.wandTolerance` 是 **0~1**（0.12 = 12%），而新参数区把它当成 **0~100** 用：
- 初始值直接给 `32` → 引擎收到 32（相当于 3200%）⇒ 整张图都算「同一颜色」⇒ **一拉就全选**。
- 只有没动滑块时才是引擎默认 0.12，所以表现为 **有时有反应、有时没反应**（动过滑块之后就一直全选，看着像失效）。

## 二、改法
`CutDock` 里统一换算：
- 初始化：`tol = (sketch.wandTolerance * 100).coerceIn(0, 100)`（默认显示 12）
- 滑块回调：`tol = f * 100`，同时 `sketch.wandTolerance = (tol / 100).coerceIn(0f, 1f)`
