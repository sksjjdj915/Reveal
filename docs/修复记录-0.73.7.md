# 0.73.7 修曲线闪退 / 直方图丢失

1. **曲线闪退**：`CurveCanvas` 里拖动用的 `dragIndex / dragList` 原来声明在父 composable，子组件引用不到（编译期报错、上一版是把状态放错了层）。现在两个状态直接放进 `CurveCanvas`；同时把手势拆成两个独立检测器——拖动用 `detectDragGestures`（落点 0.16 阈值内才拖），加点改成**双击**空白处（单击不再抢事件）；所有预览计算包 `runCatching`，即使某个尺寸异常也不会把 App 干掉。
2. **色阶直方图没了**：原来那段统计是逐像素 `getPixels(1×1)` 在 UI 线程跑 4 万次，既慢又容易在某类位图上抛异常。现在抽成公用 `luminanceHistogram(bitmap)`：先把图缩到 192×192 再一次性取像素统计，稳定、快、不越界；色阶和曲线两处都用它。
3. 色阶面板高度 224 → **300dp**（和曲线一致），直方图跟着放大。

没做：曲线吸管/自动按钮；文字参数、液化变形、裁剪与图像大小、AI。
