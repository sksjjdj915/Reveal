# 0.68.1 修复记录 · 形状参数 / 新建层开关 / 桌面端 式变换框

用户 2026-11-09 反馈：
1. 「参数里没有有关直线粗细，矩形长宽等等有关参数调整的」
2. 「我想加一个，这种形状也能选择创建形状是否创建图层，创建图层要和 ae 一样出现变换的框」
3. 「把调整往下滚动设计开一点不要太拥挤，能滚动」

## 一、形状参数补三项（`ui\ShapePaths.kt`）

| 参数 | 范围 | 说明 |
|---|---|---|
| 线宽（0=跟笔刷） | 0~200 | 0 表示跟底部画笔大小；填了就固定用这个宽度，直线、矩形描边、椭圆描边都吃它 |
| 宽 | 1~4096 | 「按尺寸生成」用的宽度 |
| 高 | 1~4096 | 「按尺寸生成」用的高度 |

- 新增按钮 **「按尺寸生成」**：在当前画面正中按“宽×高”生成一个形状，不用手拖。做分割线就填 260×3、选“直线”或“矩形+填充”。
- 「直线」类型按尺寸生成时，宽 ≥ 高画横线，否则画竖线。
- 实现：`SketchView.makeShapeAtSize(w, h)`，`shapePaint()` 里 `p.strokeWidth = (if (shapeWidth > 0) shapeWidth.toFloat() else brushSize).coerceAtLeast(1f)`。

## 二、「新建图层」开关

新增芯片 **「新建图层：开/关」**，默认开（`SketchView.shapeNewLayer = true`）。

- **开**：每个形状单独一层（「形状 N」）。撤销 = 整层消失一步；能用变换单独改大小；能单独隐藏/加样式。
- **关**：画进当前图层（老行为）。撤销 = 一步像素补丁，形状和人物糊在一起。
- 两条路合并到 `SketchView.stampShape(path, label)`，`commitShape()` 只负责算路径。

## 三、新建层后自动出变换框（桌面端 式）

`stampShape()` 新建层之后 `post { beginTransform() }`：形状层刚生成就自动进入变换状态，四角手柄直接出现，拖角就能改大小，点「应用」落定。不想动就点「取消」，层还在。

## 四、参数区改成可滚动、不拥挤

- 整个形状参数区 `heightIn(max = 172.dp)` + `verticalScroll`，超出上下滚动，不再一格挤一格。
- 每行上下留 4dp（原来 0），标签字号 9→10sp，标签宽度 118→126dp。
- 行距、提示语一并放宽；只有三行可见，超出的滚动出来看。

## 出厂验法

1. 形状 → 参数条能上下滑，每行有名字、不挤。
2. 线宽填 12 → 画一条直线，线明显变粗；改回 0 → 又跟画笔一样粗。
3. 宽 260、高 3、选「矩形」+ 打开填充 → 点「按尺寸生成」→ 画面正中出一条 260×3 的白条。
4. 「新建图层：关」→ 画形状 → 图层列表不多新层，撤销一步就没了。
5. 「新建图层：开」→ 画形状 → 图层列表多「形状 N」，并且**立刻出现变换框**，拖角能改大小。
6. 画三个形状后连按三次撤销 → 三层倒序依次消失。

## 没做的

- 形状仍是像素层，不是矢量层：画完再改圆角/边数/星形内径不会重画（只能改大小/位置/样式）。
- 「按尺寸生成」放在画面正中，没有跟随手指落点（要别的位置用变换拖）。
