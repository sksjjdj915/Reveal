# 0.67.83 修复记录（2026-11-08）

这一版把「之前记下来的待办」一次清完。

## 1. 图层面板加了「置入图」
之前「置入图片…」只在右上 ☰ 菜单里，新建空白画布后找不到入口。
现在图层面板标题行、`组+` 左边多了一个蓝色 `置入图`：
点了打开系统相册，选图后等比缩到画布 90% 内、居中放成新图层（同一套 `addImageLayer`）。
代码：`Dialogs.kt` 的 `LayerPanel` 新增 `onPlaceImage` 参数；`LayerPanelHost.kt` 透传；`EditorScreen.kt` 里接到已有的 `insertLauncher`。

## 2. 新建画布能自己填分辨率
`NewDocumentDialog` 重写：常用尺寸四个按钮保留（点一下直接建），下面加「宽 / 高」两个输入框（默认 1080 / 1620）、「保持比例」开关（默认关）、「背景：透明 / 白底」切换、右下「创建」。
校验：宽或高小于 16 会说「宽度不能小于 16 像素（现在填的是 N）」，最大 8000，两个都没填会说清楚。

## 3. 变换时看得见缩放多少
档框上方那行小字从「自由变换 · 拖角等比 / 拖边拉伸」变成带数字：
- 等比缩放：`自由变换 · 85% · 拖角等比 / 拖边拉伸 · 双击确认`
- 拉边造成不等比：`自由变换 · 85% × 120% · …`（两个数都报）
百分比直接取当下 `tfSx / tfSy`，跟着手指实时变。

## 4. 变换支持双击确认
变换状态下在同一处双击（两次间隔 < 340ms、落点相距 < 24 屏幕像素）= 回车确认，等价于点底部「应用」，成功后弹「变换已应用」。
只做双击、不做单指长按，避免和拖拽冲突。

## 5. 组 / 无像素层 / 锁定层进变换会给明确提示
`beginTransform()` 改成就地判断，返回 `false` 并弹一句：
- 组 →「这是组，整组不能直接变换：先选中组里的某一层再变换」
- 无像素（空层、调整层）→「这一层没有像素（例如空图层或调整层），画点东西或栅格化后再变换」
- 锁定 →「这一层锁住了（图层面板里的锁），先解锁再变换」

## 怎么验
1. 新建画布 → 填 1080 / 1620 → 透明 → 创建；进编辑后点「图层」→ 面板里点「置入图」→ 选一张相册图，应该出现新图层且居中不超边。
2. 变换：拖四角，看上方数字在 80%~90% 之间变；拉左边那条边，数字变成「85% × 120%」这种两个数。
3. 变换时双击画面，应该直接应用并弹「变换已应用」。
4. 新建一个组、或加一个调整层，进变换应弹提示而不是毫无反应。
