# 0.74.40 任务③④⑤⑥：减少杂色独立算法 / 圆形邻域 / 高斯高反差 / 杂色分布

## ③ 减少杂色改成独立算法（不再复用表面模糊）
文献口径：桌面端的「减少杂色」是**分通道**处理的——亮度通道做轻度选择性平滑（强度/保留细节），色度通道（Cb/Cr）可以重得多（减少彩色杂色）。这正是它和表面模糊的本质区别：彩色噪点在亮度上几乎看不出来，只有单独重压色度才干净。
实现 `FilterFx.reduceNoise(src, amount, detail, chroma)`：
1. BT.601 转 YCbCr（`Y=0.299R+0.587G+0.114B`，`Cb=-0.1687R-0.3313G+0.5B+128`，`Cr=0.5R-0.4187G-0.0813B+128`）；
2. 亮度走双边（半径 1~2，阈值 `6 + 42·强度·(1-保留细节·0.8)`）；
3. 色度走方框模糊，半径 `1 + 减少彩色杂色×4`（上限 5）；
4. 合回 RGB，alpha 保留原值。
参数条：强度 0~100、保留细节 0~100、减少彩色杂色 0~100。

## ④ 最小值 / 最大值改圆形邻域
桌面端的这两项是**圆盘**邻域（半径 1~20），方形会把方角吃尖。现在循环里跳过 `dx²+dy² > r²` 的采样点，结果边缘是圆的。

## ⑤ 高反差保留的低频改用高斯
原来是 `boxBlur`（方框）当低频，边缘外会留一圈方块状光晕；改成 `gaussBlur`，和桌面端一致。

## ⑥ 添加杂色补「分布」
桌面端有平均分布 / 高斯分布两种：
- 高斯（默认）：`nextGaussian() * 0.35 * 数量`，钟形，痕迹自然；
- 平均：`(nextFloat()*2-1) * 数量`，等概率，颗粒更硬。
参数条：数量 1~120、分布 0高斯·1平均、单色 0关·1开（单色时 RGB 用同一偏移）。
