# 0.72.2 参数做完整（第一轮）

## 一、调色 7 个面板真正接上了
原来的 `ColorFxDialog(id, sketch, onClose)` 是自带外壳的完整面板，直接复用：
- 曝光度 / 自然饱和度 / 色彩平衡 / 黑白 / 照片滤镜 / 色调分离 / 渐变映射
参数区里直接就是这些面板（最多 420dp 高，内部滚动），改完即时预览、确认落盘。
不在表里的（色阶 / 曲线 / 色相饱和度 / 亮度对比）继续显示占位。

## 二、绘制 / 修图参数补齐
画笔条从「大小 / 不透明」扩成四个：大小（1~200）、不透明（0~100%）、流量（0~100%，`brushFlow`）、硬度（0~100%，`brushHardness`）。

## 三、形状 / 渐变用回原参数
- 形状工具：参数区直接是原来的 `ShapeToolBar`（宽高、长度、角度、圆角、边数、星形内径、填充、线宽、新建图层开关、按尺寸生成）。
- 渐变工具：参数区是原来的 `GradientSection`（线性/径向、两端取色、平滑度、缩放、反向、只画范围、选区提示、取消/应用）。

## 四、还没做
1. 色阶 / 曲线 / 色相饱和度 / 亮度对比 四个面板没接（它们的实现有预览管线依赖，需要单独搬）。
2. 文字工具没有参数区（要搬 `TextSpec` 那一大套）。
3. 液化 / 变形 / 修复画笔的专属参数（修复半径、取样源、液化笔压等）还没露出来。
4. 裁剪 / 图像大小 / 画布大小仍是占位。
