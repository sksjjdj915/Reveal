# 0.73.1 PSD 导出做完整（搬用旧链路）

## 做法
把旧界面 `EditorScreen` 里那段 `buildPsdNow()` 整段搬到新文件 `ui/PsdExport.kt`，改名为
`internal fun buildPsdBytes(view: SketchView, context: Context, projectId: String): ByteArray`，
旧界面改成调用它（两边共用一份，不再各写一套）。

## 现在导出会保留什么
- 每层：名字、位图、可见性、不透明度、混合模式、剪贴蒙版、锁定透明、蒙版（含 `rawMask`）、组结构（`sectionType`）。
- **调整层参数**：`adjust` 原样写回（色相饱和度 `hue2`、亮度对比 `brit`、色阶 `levl` 等），在桌面端里是可再编辑的调整层。
- 渐变映射 / 调整组这种桌面端没有原生块的情况，按旧逻辑**先烘成一张像素层**并清掉下方已合入的层，避免桌面端里叠两次。
- 文字层：`textContent / textSize / textColor / textFont` → PSD 文字层（桌面端里还能改字）。
- 图层样式：描边、投影、外发光、内阴影、内发光、颜色叠加、渐变叠加、斜面和浮雕、光泽、图案叠加、纹理、等高线，全部写成 PSD 效果块。
- 16 位 / 32 位：层没被画过（像素指纹一致）就把原始通道原样搬回；画过则按 8 位重建（避免脏数据）。

## 调用点
文件面板「导出 PSD」→ 系统「保存到」→ `buildPsdBytes(view, context, projectId)` → 写文件，Toast 报大小。

## 没做
色阶/曲线面板、文字参数面板、液化变形、裁剪与图像大小、AI 仍未接（这些是「功能入口」，导出侧已经完备）。
