# 0.74.55 新增两个滤镜：阈值、黑白转换

## 一、阈值
- 参数：**阈值色阶 1~255**（只有一个，和标准做法一致）。
- 算法：像素亮度 ≥ 阈值 → 纯白，否则纯黑，保留 alpha。
- 用途：二值化线稿、做蒙版、剪纸/版画效果。

## 二、黑白转换
- 六个参数：**红 / 黄 / 绿 / 青 / 蓝 / 洋红**（0~100，越大该色在灰度里越亮）。
- 算法：每像素取 HSV，按色相落点对六个带做余弦窗加权，得到放大系数 `k`，再 `v = 亮度 × (1 + (k-1)×饱和度)`。
- 和「去色」的区别：去色是固定公式（三通道加权），同亮度不同颜色出来的灰阶完全一样；黑白转换能让红色和蓝色出不同灰，正是黑白摄影调层次的做法。

## 入口
「滤镜」子工具栏里新增两颗：**阈值**、**黑白转换**（排在马赛克后面）。

## 没做
黑白转换还没有「色调」开关（那种给黑白加单色调的选项）；阈值没有「平滑」类扩展。0.74.x 全部只编译验证，无真机验收。
