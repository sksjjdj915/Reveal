# 0.74.80 显示蒙版（对齐影视调色软件的 Show Mask）

## 是什么
范围面板里多了一颗胶囊：「蒙版：显示 / 隐藏」。打开后整幅画布铺成黑白——白＝这条调色真正会生效的地方，黑＝完全不受影响。跟影视调色软件调色页的「显示蒙版（Show Mask）」是同一个用途：先确认蒙版罩住哪，再看效果，不用靠猜。

## 实现
- `SketchView.showMask: Boolean`（带 `invalidate()` 的 setter）；
- 每帧在画范围描边之前，把 `regionMask()` 的 alpha 通道铺成灰度画到画布上（`px = 0xFF<<24 | a<<16 | a<<8 | a`），所以羽化带是灰渐变、反转是反过来的黑白；
- 面板 `RegionDock` 里加 `showMask` 状态与胶囊，切换即时生效；
- 蒙版是按文档尺寸生成的，绘制时按 `docPixelWidth()` 比例铺满。

## 怎么用
1. 画一个范围；
2. 点「蒙版：显示」→ 看黑白：白的地方以后调色才会变；
3. 如果白的不是你以为的那块 → 是范围选错了（拖圈/改宽高/反转移）；
4. 如果黑的地方调色后也变了 → 是合成路径的问题，不是蒙版。

## 没做
`compositeWithMask` 收敛、范围运算（相加/相减/相交）、参数条问题。0.74.x 仅编译验证。
