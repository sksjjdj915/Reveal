# 0.74.16 子滤镜面板重做（实时预览 + 分页 + 独立图标）

## 一、子滤镜参数面板改成和其它调色面板一致
- 新增 `ui/FilterDock.kt`：拖动任何参数都**实时预览**（常驻泵 + `Dispatchers.Default` + `previewBase(900)`）；
- 只有点「应用」才真正写进当前图层并进撤销（`applyFilterToActive`）；
- 另加「复位」把参数拉回默认值。
- 之前用的是弹窗式 `ColorFxDialog`（预览弱、只在确定时落盘），现在换成和色阶/曲线/曲线映射同一种底部卡片。

## 二、分页与面板介绍（参考文献：桌面端滤镜库的参数口径）
- 面板顶部两页签：「参数」/「说明」。
- 「说明」页写三件事：这个滤镜对应桌面端的哪个效果、每个参数的物理含义与取值范围、以及「预览是降采样、点应用才落盘」的说明。
- 参数多也不拉长面板：`heightIn(max=340.dp)` + 内部滚动，和色相饱和度一致。

## 三、子工具行的交互
- 点亮「滤镜」后子工具行**一直显示**；点子工具不会把子工具行收起来。
- 「滤镜」和当前选中的子工具**同时保持蓝色**（`activeId` 传的是子工具 id，父级「滤镜」按钮本身仍是激活态）。
- 再点同一个子工具 = 收起它的参数面板（子工具行仍在），符合「同工具二次点击收起」的既有规则。
- 子工具行高度 68 → **54dp**、单元 56 → **48dp**（占用更小）。
- **每个子工具换成不同图标**，并按常用程度从左到右排：高斯模糊、USM 锐化、马赛克、动感模糊、查找边缘、添加杂色、油画、表面模糊、智能锐化、径向模糊、水彩、浮雕、中间值、蒙尘划痕、减少杂色、方框模糊、波纹、球面化、旋转扭曲、挤压、极坐标、云彩、镜头光晕、高反差保留、最小值、最大值、位移、胶片颗粒、剪纸、碎片（共 30 个）。

## 四、没做
1. 「说明」页只有文字，没有配示意图。
2. 参数是按现有 `filterSpec` 的真实参数写的，没有为每个滤镜再补桌面端里我们算法尚未实现的项（比如「镜头光晕」的镜头类型、「水彩」的笔触细节）。
3. 曲线吸管、液化/变形/图案图章、裁剪与画布大小、AI 仍未做。
4. 0.74.x 全部只做编译验证，无真机验收。
