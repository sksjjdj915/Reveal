## 自检时顺手改掉的问题（不在原清单里）

- `drawSelection` 每帧都整幅 `getPixels` 判断选区是否为空（4096² 一次 64MB）→ 改成分块扫描、碰到不透明像素就返回，且只在选区变化时算一次。这是缩放/大图掉帧的主因之一。
- 选择并遮住「应用」在参数全 0 时会把还在用的基准图回收掉（选区可能变黑/崩）→ 只回收不是当前选区的那张。
- 选择并遮住的默认值（羽化 6/平滑 4/对比 40）一打开就先改了一遍选区 → 默认改 0，不动滑块就是原样。
- 选区「修改」五项默认 8/4/4/4/3，只拖羽化也会把扩张收缩算进去 → 默认改 0。
- 背景橡皮抬手时又按整段覆盖度擦了一遍（段重叠处更透）→ 抬手改用增量覆盖度。
- 修复画笔提示「涂在瑕疵上」有误导（它其实要先取样）→ 改成「先点一下取样，再涂到瑕疵上」。

## 没做透的地方（老实交代）

1. 污点修复「近似匹配」还是单点取色，没有桌面端那种多候选块匹配算法。
2. 颜色替换的「限制：连续 / 不连续」现在实际差别很小（连续≈笔刷范围），只有「查找边缘」有明确效果——因为不再预冻连通区。
3. 「源=所有图层」的修复画笔首笔要把整幅拍平再缩图，超大文档（4000px 以上）第一笔可能有一两百毫秒的顿感。
4. 1-12 的「选区内侧 1px 亮边」没加（现在靠压暗 90% + 蚂蚁线）。
5. 每个工具记忆自己的笔刷大小：已生效（切换工具各自保留），但橡皮擦/背景橡皮走的是自己那套独立字段，切换时不会跟画笔互相影响——这是有意的。
