# 0.74.26 子工具目标 ⑨：点画面选中心（交互补齐）

## 为什么做这个
挤压 / 球面化 / 旋转扭曲 / 镜头光晕 / 极坐标 / 波纹这些径向类滤镜，桌面端本体都固定在画面正中；我们之前补了「中心 X% / 中心 Y%」两个滑块，但用滑块找位置很不直观。这一版补上手势：**在画面上点一下就取该点为变形中心**。

## 实现
1. 新增 `ui/FilterPick.kt`：`object FilterPick { active; onPick; start(cb); stop() }` —— 一个极轻的跨层通信点，不进 ViewModel 免得把参数链路搞复杂。
2. `ui/FilterDock.kt`：检测 `spec.knobs` 里是否存在标签以「中心 X」开头的参数；有就多显示一颗 chip「点画面选中心」。
   - 点开 → 进入取点模式，chip 变蓝、旁边提示「现在点画布上任意位置」；
   - 点完画布 → 自动把归一化坐标 ×100 写回 `values[cx]` / `values[cx+1]`，并自动退出取点模式；
   - 面板关闭或切滤镜时 `DisposableEffect` 兜底 `FilterPick.stop()`，不会残留「点哪都没反应」的状态。
3. `ui/CanvasPage.kt`：`FilterPick.active` 时在画布上层叠一块透明感应区（`pointerInput + detectTapGestures`），把 `off.x / size.width`、`off.y / size.height` 归一化回传；同时顶部浮一条深色小提示「点一下要作为中心的画面位置」。
   - 用 `pickTick` 作为 `pointerInput` 的 key，点一次自动失效重装，避免连续点击被吞。

## 覆盖范围
只要参数里有「中心 X/Y」的滤镜都自动生效：挤压、球面化、旋转扭曲、镜头光晕、极坐标、波纹。

## 没做
晶格化、点状化按桌面端参数表已无缺项（都只有「单元格大小」）；曲线吸管、液化/变形/图案图章、裁剪与画布大小、AI 未做。0.74.x 全部只编译验证，无真机验收。
