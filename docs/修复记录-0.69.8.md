# 0.69.8 界面改版 · 调色/滤镜面板统一外壳

## 一、这次做了什么
1. **`FxSpecDialog` 换成 `RvPanel` 外壳**：这是「调色 / 滤镜」里几十个面板共用的那一个通用面板（色相饱和度、自然饱和度、照片滤镜、色彩平衡、阈值、匹配颜色、颜色替换以外的绝大多数滤镜）。改一处，覆盖全部：
   - 白色 20dp 圆角卡片 + 10dp 阴影 + 四周留白；
   - 标题行右侧 ✕；
   - 「取消 / 确定」从标题行挪到底部右侧两颗胶囊（原来和标题挤在一行，小屏会被压缩）。
2. 面板最大高度 196 → 380dp（滑块都在内部滚动区，参数多的滤镜不用再一格一格啃）。
3. 数值文字颜色从 `#D2D6DC`（深底用的浅灰）改成 `Rv.text`，浅底上才看得清。

## 二、这次没做
1. 曲线面板其余部分（数值框 / 取样 / 参考曲线 / 网格开关）没重排。
2. 色相饱和度等面板内部还是一行行滑块，没再多分组（它们本身参数不多，暂时够用）。
3. 首页「QQ/微信发来的」卡片区、多选态没重排。
4. 左栏逐项错开动画没做。
5. 没跑模拟器。

## 三、怎么验
1. 调色 → 色相/饱和度 → 面板应是白色圆角卡片，标题右上有 ✕，底部有「取消 / 确定」两颗胶囊。
2. 同样的面板打开照片滤镜 / 色彩平衡 → 外观一致。
3. 参数多的滤镜（比如照片滤镜）→ 面板高度更大，内部可滚动。
