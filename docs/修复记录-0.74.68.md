# 0.74.68 需求①：抠图模式加「色带抠图」（混合颜色带）

## 这个东西是干嘛的
混合选项里的「混合颜色带」（Blend If）本来是做图层混合的，但在抠图上非常好用：**按某个通道的亮度决定透明**——背景是纯色或纯白时，把「比某个亮度更亮的部分」直接变透明，不需要选区，也不用魔棒调容差。

## 实现
新增 `FilterFx.bandCut(src, channel, loBlack, hiBlack, loWhite, hiWhite, feather)`：
- channel：0 灰度（`0.299R+0.587G+0.114B`）/ 1 红 / 2 绿 / 3 蓝；
- 亮度 ≤ 黑场下 → 完全透明；黑场下~黑场上之间线性升到不透明（这就是「拆分滑块」的软过渡）；
- 亮度 ≥ 白场上 → 完全透明；白场下~白场上之间线性降到透明；
- 羽化 0~100 再把边界收一段，边缘更柔和；
- 只改 alpha，RGB 不动；alpha 为 0 的像素直接跳过。

## 入口
抠图模式工具行最后加「**色带抠图**」（`cut.band`），点开是参数卡：
- 通道四选（灰度/红/绿/蓝）
- 黑场下 / 黑场上 / 白场下 / 白场上（0~255，会自动保持 b0≤b1、w0≤w1）
- 羽化 0~100
- 「应用」（走 `applyFilterToActive`，进撤销、也会受区域范围限制）+「复位」

## 典型用法
白底图 → 白场下 = 240、白场上 = 255 → 背景直接透明；如果边缘还有一圈浅灰，把黑场上抬到 30 左右。

## 没做
1. 没有实时预览（点「应用」才落层，进撤销可以反复试）；
2. 只有「本层颜色」这一组条件，没有「下一图层」那一组（那要先做图层合成语义）；
3. 灰度通道用 BT.601 权重，和引擎其它地方一致。
