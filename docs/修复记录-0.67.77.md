# 0.67.77 修复记录：画笔手感的三个根因

用户反馈（0.67.76）：「1 依然是一段一段的，2 笔迹抖，3 还是硬。综合评价还不如不改，卡顿、延迟、不流畅、生硬、抖动。」

## 参考文献 / 成熟做法

- libmypaint `mypaint-brush.c`：笔迹是「沿路径按走过的距离落笔头（dabs）」，距离是**跨整个 stroke 连续累计**的，不是每个事件重新数。
- MyPaint / Krita 的「硬度」是**笔尖 alpha 的径向衰减曲线**（半径内从实心渐变到透明），不是对一条描边做模糊。
- 桌面端默认间距 25%，但前提是笔尖本身是抗锯齿渐变、且每滴累积叠加；换到我们这种「笔头位图 + 累积」的路径上，25% 在大笔刷上笔头之间是能看出来的。

## 三个根因（都在 `ui/SketchView.kt`）

1. **「一段一段」= 间距每段重新起算**
   `stampQuad` 里 `val steps = max(1, (approx / spacing).toInt())`，循环 `for (i in 0..steps)` 每次都从本段起点 t=0 开始。手指每次移动事件结束，下一段又从 0 数，段接缝处要么双印（叠一块深色）、要么差半格（空一小截）。快画时事件少、段长，这个接缝就特别明显。

2. **「抖」= 落印坐标被取整到文档像素**
   `stampAt` 的 `noScale` 快路径：`val sx = (x - stamp.width / 2f).toInt().toFloat()`。文档 4096 缩到屏幕（约 20%）时，1 个文档像素 = 5 个屏幕像素，每一滴都在 5 像素的格子上跳，看起来就是抖。

3. **「硬」= 整段描线捷径 + BlurMaskFilter 假软边**
   `canStrokeAsPath()` 门槛是 `brushHardness >= 0.55f`，所以硬度 0.5~0.6 的笔也走「整条路径描一根 stroke 宽度的线」，再用 `BlurMaskFilter` 糊一下冒充软边。真正的软边必须是笔尖图自己带 alpha 衰减（`stampFor` 里本来就有 7 段 S 形衰减 `e0 → 1`），但门槛太低，这条正确的路根本走不到。

## 改法（`_fix_t104.py`，6 处）

| # | 位置 | 改动 |
|---|---|---|
| 1 | `brushSpacing` 默认值 | `0.22f` → `0.08f`（直径的 8%：笔头之间不露缝、笔头数又不到老版本那么夸张） |
| 2 | `canStrokeAsPath()` | 门槛 `brushHardness >= 0.55f` → `>= 0.95f`：只有近乎实心的笔头才走描线，其余全部走笔尖盖章，软边由笔尖 alpha 衰减产生 |
| 3 | `stampAt` noScale 分支 | 去掉 `.toInt()`，用 float 坐标 + `FILTER_BITMAP` 交给 Skia 插值（亚像素落印） |
| 4 | `stampQuad` 落印循环 | 改成沿弧长均匀落印，并把「上一段走剩的距离」`spacingCarry` 带到下一段；不再强制每段至少盖一下 |
| 5 | 新增字段 | `private var spacingCarry = 0f` |
| 6 | `beginStroke` | 起笔时 `spacingCarry = 0f` |

## 怎么验

1. 圆头硬笔一笔画长弧线：应该是一条线，笔头之间看不出接缝（重点看快画的时候）。
2. 缩小到 20% 左右再画：笔迹不该一格一格地跳。
3. 硬度 0.5~0.6 画一笔：边缘是柔的过渡，不是一条硬边线。
4. 用 200px 大笔刷快速扫一片：覆盖均匀，不再一串圆头。

## 还没做的
