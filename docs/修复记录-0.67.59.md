# 修复记录 0.67.59

## 1. 图层眼睛关着时，现在会告诉你（下次不会再白画半天）

开画前检查当前图层是否可见；被隐藏时直接不落笔，并弹一句：
**「当前图层是隐藏的（眼睛关着），画上去看不见：先在图层面板点开眼睛」**

这样就不会出现「画了半天什么都没有，以为是软件把笔迹吞了」。

## 2. 弧线一段一段拼成的

**根因**：为了 4096 上跟手，上一版把大图的笔头间距抬到了笔刷的 22%，
其余情况靠「一个挨一个的圆点」去近似一条线。软边笔头看不出来，
但**硬边笔头（默认 85% 硬度往上）就会变成一串圆点，弧线上看着就像一段一段的折线**。

**改法**：硬边、不透明、无抖动/纹理/双笔尖的笔头，不再靠密集盖章，
改成**沿二次贝塞尔描一条圆头线**（`Paint.STROKE` + `Cap.ROUND` + `Join.ROUND`）：

- 弧线天生是连续的一条，不存在圆点拼接的接口；
- 一段只画一次，比盖几十下还快，4096 大笔刷也顺；
- 大图落笔时的屏幕预览同样用这条路径画一遍，所以预览和最终结果完全一致。

判定条件（任一不满足就走回原来的盖章路径，绝不硬套）：
硬度 ≥ 0.8、散点/抖动/角度抖动/颜色抖动/流量抖动都为 0、无旋转、无湿边、无双笔尖、
圆度 ≥ 0.999、流量 ≥ 98%、正常混合、无纹理、无起收笔变尖。

软边画笔、喷枪、纹理画笔、双笔尖、带渐隐的笔：仍然逐一盖章 —— 它们本来就靠叠加出效果。

## 怎么验
1. 把图层眼睛关掉，随便画一笔 → 应该立刻弹出提示，而不是白画。
2. 打开眼睛，默认画笔（硬度 85）画一条大弧线 → 边缘应该是连续平滑的，不再是圆点串。
3. 缩放看这条弧线的边缘 → 放大后也应平滑（不再有台阶感）。
4. 4096 上画同样的大弧线 → 要更顺、更快（描线替代了密集盖章）。
5. 把硬度拉到 30% 画一笔 → 仍是软的（走原路径），确认没有被我改硬。
