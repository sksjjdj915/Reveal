# 0.74.8 曲线自动 / 文字参数 / 图像大小

## 一、曲线加「自动」
第 1 页通道行右侧加了一颗「自动」胶囊：按当前合成图的亮度直方图，两端各切掉 0.5% 后生成三点曲线（`lo → 0`、中点 → `0.52`、`hi → 1`），只作用于当前选中的通道（RGB/红/绿/蓝）。

## 二、文字工具有面板了（复用原 `TextPanel`）
- 点「文字」工具，参数区就是完整的文字面板：内容、字号、颜色（点色块弹 `ColorPickerPanel`）、字体、字符样式/间距/比例/对齐/变形等折叠区全在。
- 点「确定」按当前文档中心生成一个新文字图层（`sketch.addTextLayer(text, size, color, cx, cy, font)`）。
- 面板常驻在底部（自适应高度、可滚），不会挡住画布中心。

## 三、图像大小
排版模式里的「图像大小」现在是真实操作：
- 宽度/高度两个滑块（16~8192），显示当前文档尺寸；
- 「应用」调 `sketch.resizeDocument(w, h)`（整份文档缩放，所有图层一起）；
- 「还原」填回当前值。

## 没做
液化 / 变形 / 图案图章的专属参数（仍是通用大小/不透明）；裁剪与画布大小仍未接；AI 仍是占位；曲线「吸管取样」未加。
