# 0.74.91 范围变成「可移动的活蒙版」（应用后拖圈，效果跟着走）

## 你要的
点「应用」之后颜色已经改好；这时把圈拖到别处 —— 圈现在罩住的地方实时变成那个颜色，圈离开的地方恢复原样。

## 参考文献（语义）
这正是影视调色软件 / 桌面端 / 局部调整工具 的蒙版语义：修正（correction）和蒙版（mask）是分开的两层数据，**蒙版一移动，修正跟着走**，原图始终保留在下面。所以「应用」不该是烤死的，而应该记住「原图 + 这次用的滤镜」，每次蒙版变化就重算一次合成。

## 实现
- `applyFilterToActive` 在按范围应用时，保留 `lastFilterBase`（应用前的原图）与 `lastFilterFn`（这次用的滤镜+参数）；
- 拖圈过程中：`regionMove` 用 100ms 节流调 `previewRegionComposite()` —— 按新位置算一遍合成，**圈内立刻变、圈外立刻恢复**（预览层，不动像素）；
- 松手：新增 `bakeRegionComposite()` —— 用同一套公式（`base + (corrected−base)×mask`、alpha 取原图 alpha）在**全分辨率**上重算并写回图层像素，然后清掉预览。这样拖到哪，效果就真正落在哪，旧位置恢复原图。

## 语义边界（重要）
- 只有「最近一次按范围应用的那个滤镜」是活的；换工具、换图层、撤销之后，活的绑定就失效（回到普通像素）。
- 每次松手都会重算全分辨率一次（1080×1620 大约几百毫秒，随滤镜复杂度变），松手瞬间可能有一顿。
- 不是调整图层：参数不能回头改，只能重新调一次。

0.74.x 仅编译验证，无真机验收。
