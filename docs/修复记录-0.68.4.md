# 0.68.4 修复记录 · 变换角度双向实时同步

用户 2026-11-09：「实时的做成」——0.68.3 留下的问题：拖旋转手柄时，画布顶部标签会变，但底部「角度」滑块不动，两边对不上。

## 改法

`ui\SketchView.kt`

- 新增回调 `var onTransformRotation: ((Float) -> Unit)? = null`。
- 新增 `private fun normDeg(d: Float): Float`：把角度规范到 -180~180（`tfRot` 会累加超出整圈）。
- 新增 `private fun notifyRotation()`：规范化后回调给界面。
- `tfDrag()` 的 `3 ->`（旋转）分支：先把手势角度差规整（`>180 减 360`、`<-180 加 360`），再 `tfRot = tfStartRot + d`，然后 `notifyRotation()`。
- `tfTwoFinger()`：双指旋转后同样 `notifyRotation()`。
- `currentTransformRotation()` 改为返回 `normDeg(tfRot)`。

`ui\EditorScreen.kt`

- `view.onTransformRotation = { deg -> tfAngle = deg }`（挂在 `view.onActiveLayerChanged` 之前）。
- 进变换时 `tfAngle = view.currentTransformRotation()`，不再写死 0。

## 验法

1. 选一层 → 变换 → 拖顶上的 ↻ 圆点：**底部「角度」滑块跟着走，数字实时变**。
2. 拖底部角度滑块：画布上的内容实时转，顶部标签同步。
3. 双指旋转：底部角度也实时跟。
4. 角度转过 +180 后继续转，滑块走的是 -179 那一侧（不会跳）。
5. 「归零」：内容回正，滑块回 0。

## 没做的

- 旋转 90° 后形状层的「宽/高」仍按水平包围盒算，会显示成互换。
- 角度滑块拖得很快时，底部数字和画布会有约一帧的差（不是错，是同步顺序）。
