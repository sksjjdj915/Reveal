Reveal 全功能实测 · 6 个案例（0.67.12 用）
写在前面
- 一共 6 个案例，做完就覆盖了 230 项功能。不用桌面端，工文件都用本 App 自己存。
- 需要你准备的素材：动漫插画 2 张（长边 1500~2500px，JPG/PNG）、照片 3 张（人像 / 风景 / 静物各一，网上随便下）。
- 做法：照着编号一条一条点。做完一条在后面打 √。不对的记「编号 + 你看到什么」，不要自己想办法绕过去。
- 参数值我都写死了，照着拖就行；某个条目你找不到，记下编号告诉我，那说明是 bug。
- 每步「预期」没达到就算不合格。

案例 1  插画精修（最常用，约 40 分钟）
素材：动漫插画 1 张
================================================================
1-01 文件 → 打开 PSD，选那张插画。预期：画面出图，图层面板里有 1 层。
1-02 图层 → 图层面板 → 新建图层（+）。预期：多一层「图层 2」，能点选、能关眼睛。
1-03 选区 → 矩形选框。底部参数条第一行选「椭圆」，在人物头部拖一个圈。预期：蚂蚁线，虚线圈。
1-04 同一条改成「矩形」拖一个；再改「单行」点一下（横线选区）；再改「单列」点一下。
1-05 运算依次试「加选」（再拖一个圈，两个圈合并）、「减选」（拖掉一块）、「交叉」（只留重叠）。
1-06 修改：选「羽化」，修改量 20px → 应用修改。预期：边缘变虚。再分别试「平滑 5」「扩张 5」「收缩 5」「边界 5」，每次点应用修改。
1-07 存储选区 → 取消选区 → 载入选区。预期：蚂蚁线回来。
1-08 形状切「套索」随便画一圈；切「多边形」点五下再双击闭合；切「磁性」沿头发边缘慢慢拖。三个都要出蚂蚁线。
1-09 选区 → 魔棒：容差 20%，点背景一次；把「连续」关掉再点一次（预期：全图同色都选上）；开回来。
1-10 选区 → 快速选择：笔刷大小 40、容差 15%，在人物衣服上涂。预期：选区顺着颜色长出来。
1-11 选区 → 选择主体：抠图范围 50%，点人物身上。预期：整个人被选中（不需要背景）。
1-12 选区 → 色彩范围：容差 20%，点背景某一块颜色。预期：相近颜色整片选中。
1-13 选区 → 蒙版 / 抠图（选择并遮住）：半径 2、平滑 3、边缘位移 0、对比 20%。
     先「输出到选区」看一次；再「输出到蒙版」；再「输出到新图层」。三种都要有反应。
1-14 选区 → 全选 → 反选 → 取消选区。
1-15 图层 → 选区复制成层：先拉一个矩形选区，再点它。预期：多一层只有选区内那块图。
1-16 绘制 → 污点修复：在画面杂色处横着划一下。预期：痕迹消失、颜色融进周围。
1-17 绘制 → 修复画笔：源=仿制，先按一下干净处取样，再涂瑕疵。
1-18 绘制 → 仿制图章：不透明度 80%，先按一下取样，再涂。
1-19 绘制 → 红眼：瞳孔大小 50%、变暗量 50%，点眼睛中心。
1-20 绘制 → 减淡：范围中间调、曝光 20%，刷一处；再换「加深」同参数刷另一处。
1-21 绘制 → 海绵：模式去色、流量 30%，刷一处；再换加色刷一处。
1-22 绘制 → 历史画笔：先去「调色」把整图调亮，再用历史画笔把一部分刷回原样。
1-23 绘制 → 艺术历史：样式随便选一个（共 10 种），刷两下。
1-24 绘制 → 涂抹：强度 50%，在边缘拖。
1-25 绘制 → 颜色替换：容差 20%，用当前前景色（红色）涂一块蓝。预期：蓝变红。
1-26 绘制 → 混合器：湿度 50%、载入 50%、混合 50%，在两种颜色交界处涂。预期：颜色被拖出混色。
1-27 绘制 → 橡皮擦：模式分别试「画笔 / 铅笔 / 块」，各擦一下。
1-28 绘制 → 背景橡皮：容差 20% 擦背景；绘制 → 魔术橡皮：容差 20% 点背景。
1-29 调色 → 调色…：亮度 +20、对比 +15、饱和 +10、色温 +10 → 确定。预期：画面变亮变暖。
1-30 调色 → 色阶…：输入左 20、右 235 → 确定。曲线…：RGB 拉一个 S，再切红/绿/蓝各拉一点 → 应用。
     亮度/对比度（+20）；色相/饱和度（色相 +20）；可选颜色（红色里青色 -20）；照片滤镜（选中性、浓度 25%）；自动色调。
1-31 长按图层 → 图层样式…：依次开「投影」（不透明度 75、距离 8、大小 10）、「描边」（2px 红）、「外发光」、「内阴影」、「斜面和浮雕」、「光泽」→ 应用。
1-32 再开第二次图层样式：开「颜色叠加」「渐变叠加」「图案叠加」「等高线」「纹理」，逐个拖一下参数看预览，再应用。
1-33 图层面板：不透明度 70%；填充 80%；混合模式换成「正片叠底」看一次再换回正常；
     剪贴蒙版（把上层剪到下层）；加蒙版后用黑色笔刷在蒙版上擦一块；锁定透明像素、锁定图像、锁定位置、锁定全部 各点一次（看图标锁上）。
1-34 图层面板：给一层加颜色标签；「选择同色标签」；建组、把两层拖进组、折叠组；顶部搜索框输入文字筛一次、类型筛选点一次。
1-35 文字：分类文字 → 文字工具 → 点画面 → 输入「测试文字」；字体选一个花字、字号 120、颜色红、粗体、字距 20、行距 40、居中、居中对齐 → 确定。
1-36 文件 → 导出…：格式 JPG、质量 90 → 导出；再 PNG；再 WEBP（有损 80）；再 BMP；再 TIFF；再 PDF。六个都要能存出来。
1-37 文件 → 分享 PSD：选微信或 QQ 发给自己，电脑上确认能收到。
1-38 文件 → 保存；再「另存为 PSD」存一份。
1-39 双击图层名 → 改名「人物」；再复制图层（复制一份）；再删除刚才复制的那层。
1-40 图层 → 上移一层、下移一层各一次（或拖动图层排序）。
1-41 图层 → 全部显示、全部隐藏各一次。
1-42 图层 → 向下合并；再「合并可见」；再「盖印可见」（预期：多一层合成结果，原来的层都还在）。
1-43 图层 → 栅格化图层（对形状层或文字层用一次）、栅格化文字（对文字层用一次）。
1-44 图层 → 拼合图像（放最后做，做完只剩一层，别在这之前存工程）。
1-45 绘制 → 图案图章：选一个图案，在空白处涂。
1-46 文字：把已输入的文字改成「斜体」看一次（预期：字真的歪，不是变糊）。
1-47 调色 → 亮度/对比度：点完看图层里是不是多了一层「调整层」（可再点开改参数、能删）。

案例 2  海报排版（用动漫插画，约 35 分钟）
素材：动漫插画 1 张（和案例 1 不是同一张更好）
================================================================
2-01 打开插画。变换 → 图像大小：宽度改成 1200（另一项自动跟）→ 确定。
2-02 变换 → 画布大小：加 200px 留白 → 确定。预期：四周出白边。
2-03 变换工具：拖四角缩小一次；双指旋转 15°；拖中间移动。
2-04 变换面板依次切「斜切」「扭曲」「透视」，各拖一个角。
2-05 变换 → 水平翻转、垂直翻转、右转 90°、左转 90° 各一次；再「再次变换」一次。
2-06 变换 → 拉直…：在图上画一条应该是水平的斜线。预期：图被自动转正并裁掉黑边。
2-07 变换 → 内容识别缩放…：把宽度拉窄 20%。预期：人物不明显变形，背景被压缩。
2-08 变换 → 裁剪：框一块区域 → 确定。预期：画布变小。
2-09 形状：依次画「矩形」「圆角矩形」（圆角半径 20）「椭圆」「多边形」（边数 6）「星形」（内径 40%）「直线」。
2-10 形状面板：把刚画的形状「存为路径」；点路径名「载入成选区」；再「选区→路径」；再对路径点「填」「描」。
2-11 绘制 → 钢笔：点四下画一条折线，切「平滑曲线」再点两下，试一次「闭合」，最后「变选区」。
2-12 辅助：显示标尺；网格间距 50；网格细分开；辅助 → 水平参考线、垂直参考线各加一条；显示参考线；
     用移动工具拖一条参考线走；吸附参考线开着时把图层往线上拖（预期：被吸住）；清除参考线。
2-13 图层 → 对齐（左对齐 / 水平居中等各点一次）；辅助 → 分布（水平、垂直各一次）。
2-14 文字进阶：文字工具输入「POSTER」，字号 160、字体换一款英文字体；
     试「全大写」「全小写」「小型大写」；试「上标」「下标」；试「竖排」；试「下划线」「删除线」；
     变形：13 种形状逐个点一遍（每种都看画面），弯曲 40；试「路径文字」（选一条已有路径）。
2-15 文字工具 → 选项里「把上一段文字转选区」。预期：文字轮廓变成选区。
2-16 图层 → 图层复合…：存一个「版本 A」；关掉两层再存「版本 B」；在两者之间切换；删掉一个。
2-17 图层 → 转为智能对象；再「换智能对象内容…」换一张图。预期：换完仍保持清晰、能反复缩放。
2-18 文件 → 导出 PNG（整幅）；再导出 PDF。
2-19 形状 → 变形：切到变形工具，拖 4×4 网格里几个点 → 应用。预期：图像跟着弯。
2-20 面板 → 颜色面板（取色盘）：点前景色开调色盘，点一个色；换背景色；点交换箭头；点黑白复位；从 24 色板里点一个；看「最近用过」里有没有刚点的色。

案例 3  手绘 + 滤镜全测（约 45 分钟）
素材：不用素材，新建空白画布
================================================================
3-01 新建画布 1600×1200 白色。
3-02 画笔：笔刷 40、硬度 80%、流量 100%、不透明 100%，画一条。再把「变尖」拖到 60% 画一条（预期：两头细）、
     「抖动」40% 画一条（预期：边缘毛）、「散开」50% 画一条、「圆度」30% 画一条（预期：扁）、「间距」80% 画一条（预期：点点串起来）。
3-03 画笔预设：面板里点开「笔刷」预设，换三种不同的再各画一条。
3-04 面板 → 吸管 取一个颜色；面板 → 油漆桶 点一块区域填充；渐变：拖一条渐变（线性→径向各一次）。
3-05 面板 → 通道：点 RGB / 红 / 绿 / 蓝 各看一次（预期：画面变单色或只显示一个通道）。
3-06 面板 → 直方图（看均值/中间值/像素数）→ 刷新一次；面板 → 信息；面板 → 导航器（拖红框、缩放）。
3-07 滤镜：反相、去色、阈值…（阈值 128）、高斯模糊（半径 8）、锐化、马赛克（格 12）、偏暖、偏冷、偏绿。
3-08 滤镜：查找边缘、浮雕效果、动感模糊（角度 45、距离 30）、径向模糊、方框模糊、表面模糊、USM 锐化（数量 80、半径 2）、添加杂色（20%）。
3-09 滤镜：中间值、蒙尘与划痕、波纹、球面化、旋转扭曲、挤压、极坐标、晶格化、点状化、云彩。
3-10 滤镜：镜头光晕、高反差保留、油画、光照效果、最小值、最大值、位移、碎片、彩色半调、减少杂色、木刻、水彩画纸、胶片颗粒。
3-11 滤镜 → 智能锐化…（数量 100、半径 1.5、减少杂色 20%）。
3-12 绘制 → 液化：推进（力度 50）拖一下；膨胀；收缩。三个都要动。
3-13 滤镜 → 消失点…：画 4 个角定平面 → 「拉正为新图层」；再进一次 → 「透视裁剪成新文档」。
3-14 滤镜 → 镜头校正…：桶形 -20、垂直透视 10、暗角 20。
3-15 滤镜 → 自适应广角…：强度 50、旋转 5、缩放 100%。
3-16 面板 → 历史记录：点回第 5 步、再点回最后一步。
（案例 3 结束后这张图留着，案例 4 的导出帧/视频要用历史记录）

案例 4  照片批处理与合成（约 40 分钟）
素材：3 张照片
================================================================
4-01 打开照片 1。特效 → 动作录制…：开始录制 → 做三步（调色亮度 +10 / 曲线拉一点 / 高斯模糊 3）→ 停止 → 保存动作。
4-02 特效 → 批处理…：选那 3 张照片 → 「选图片并开始」。预期：提示处理完成 3 张，文件在 App 目录 batch/。
4-03 特效 → 动作录制… →「套成智能滤镜」；在图层上把它关掉、再打开、再删掉（预期：非破坏、随时能关）。
4-04 特效 → 特效…：一键黑白大片、一键赛博、一键胶片、一键柔光、一键锐利、3D 立体化（挤压）各点一次。
4-05 特效 → 历史回放：播放 → 暂停 → 换速度。
4-06 特效 → 全景拼接：选两张左右有重叠的照片。预期：拼成一张，接缝有羽化。
4-07 特效 → 焦点堆栈：选两张一虚一实的同一场景。预期：取出都在焦的那张。
4-08 换回案例 3 那张图，特效 → 批处理 →「每 5 步」→「导出历史帧」。预期：frames/ 里出一串 PNG。
4-09 同一个面板：24 帧/秒 →「导出视频 MP4」。预期：videos/ 里出 mp4，能播。
4-10 文件 → 导出…：选 JPG，输出尺寸 50% → 导出（预期：尺寸减半）；再选 PNG 100%。

案例 5  调色进阶（约 25 分钟）
素材：1 张风景照片
================================================================
5-01 打开照片。调色 → 曝光度…（+0.5）；自然饱和度…（+30）；色彩平衡…（中间调 +15）。
5-02 调色 → 黑白…（红 40、黄 60）；照片滤镜…（暖色 85、浓度 30%）。
5-03 调色 → 色调分离…（色阶数 6）；渐变映射…（黑→橙，勾反向看一次）。
5-04 调色 → 阴影/高光…（阴影 30、高光 20）；通道混合器…（红通道里绿 +20）。
5-05 调色 → 色调均化；替换颜色…（点草地、换成黄绿色、容差 25%）；可选颜色…（黄色里洋红 -20）。
5-06 调色 → 匹配颜色…（参考图选另一张照片）；变化…（点两格偏暖、一格偏亮）。
5-07 调色 → HDR 色调…（强度 40、半径 30）；自动对比度；自动颜色。
5-08 调色 → 亮度/对比度、色相/饱和度：这两个在「新建调整图层」里，点完确认能生成可再编辑的调整层（不是直接改像素）。

案例 6  兼容与性能（约 30 分钟，只跑一遍）
================================================================
6-01 用案例 1 的图：另存为 PSD 存到手机；再「打开 PSD」打开它。预期：图层、图层样式、文字都还在。
6-02 打开一张 16 位 PSD（如果没有，就在 App 里把工程存成 16 位再打开）。
6-03 打开一个 PSB / 大于 300MB 的 PSD。预期：能读出结构；内存不够时给明确提示，不闪退。
6-04 新建 5000×5000 画布：画 30 笔、缩放、切工具、撤销 10 次。记录：卡不卡（能忍 / 明显卡 / 卡死）。
6-05 面板 → 历史记录：跳到中间一步、再跳回；点「快照」存一张 → 改几笔 → 恢复快照。
6-06 连续撤销 20 次、再重做 20 次。
6-07 长按图层 → 拷贝图层样式 → 另一层粘贴图层样式。
6-08 关掉 App 重开：工程还在、字体还在、动作还在。

================================================================

2. 不对的写：编号 + 你看到的现象（例：1-13 选择并遮住点了没反应）。
