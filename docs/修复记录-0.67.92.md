# 0.67.92 修复记录（2026-11-09）

## 选区有时显示、有时不显示

查到三条独立原因，全部修掉（`ui\SketchView.kt`）：

### 1. 活动层没有像素时不画（最常见）
`drawSelection()` 第一行原来是：

```kotlin
val bmp = activeLayer?.bitmap ?: return
```

**只要当前选中的是调整层、组、或空层（bitmap 为 null），整个选区覆盖层就直接不画了。**
你调色时新建了「渐变映射」调整图层，它会自动变成活动层 —— 这时候选区就"消失"，
点回像素层又出现，看起来就是"有时候显示有时候不显示"。

改法：活动层没有位图时，取任意一个有像素的层做画布范围，照常画。

### 2. 拖动选区时整块不画
原来是 `if (mask != null && hasSel && !selDragging)` —— 手指一按下去拖新选区，
**已经存在的选区边界和压暗会整个消失**，松手才回来，视觉上就是"闪一下"。

改法：拖动时照画压暗 + 矢量轮廓（都是缓存好的位图/路径，几乎不耗时），
只把"位图蚂蚁线"那一次整幅 `saveLayer` 跳过（那才是拖起来卡的原因）。

### 3. 双指缩放后没补重建
快速选择模式下第二根手指落下会把选区还原（`selStaleDuringZoom = true`），
但抬手时只判断了 `edgeDeferred` 才重建 —— 这个标志是 false 的情况下就不重建，
于是缩放过一次之后选区一直不显示，直到下一次改选区。

改法：抬手时 `if (edgeDeferred || selStaleDuringZoom) rebuildEdge()`。

## 验收方法

1. 拉一个矩形选区 → 不要松手，继续拖：**边界应该一直看得见**（以前会消失）。
2. 保持选区，去「调色 → 新建调整图层 → 亮度/对比度」：**选区还在**（以前会消失）。
3. 双指放大缩小一次，松手：**选区还在**（以前快速选择模式下会不见）。
4. 点回像素层：一切照旧。

## 没动的东西

- 蚂蚁线的流动速度、线宽、内侧那圈浅蓝边，都没改。
- 选中调整层时**不能直接画**这个限制仍然存在（那是正确的，调整层没有像素）。
