# 0.74.48 目标⑥：镜头校正补色差/晕影中点/角度

## 文献依据
桌面端「镜头校正」参数表：**移去扭曲**、**色差（红/绿/蓝三条）**、**晕影（数量 + 中点）**、**变换（垂直/水平/角度）**。
色差的物理来源是镜头对不同波长的折射率不同（轴向/横向色差），表现为画面边缘的紫边、绿边——修法就是让三个通道分别按略不同的径向比例重采样。晕影的「中点」决定暗角从半径多远开始压。

## 旧实现
`lensCorrection(src, distort, vertical, horizontal, vignette)`：4 个参数，没有色差、没有角度、晕影只有强度（固定从中点=画面半径的 0.9 倍开始压）。

## 新实现 `FilterFx.lensCorrectAt(...)`
| 参数 | 范围 | 说明 |
|---|---|---|
| 扭曲 | −100~100 | 桶形/枕形径向畸变（`f = 1 + k·r²`） |
| 垂直透视 / 水平透视 | −100~100 | 梯形校正 |
| 角度 | −45~45° | 旋转校正（水平线摆正） |
| 色差·红 / 绿 / 蓝 | −100~100 | 每通道自己的径向缩放 `f = 1 + ca·r²`，三条不同就在边缘错色 |
| 晕影数量 | −100~100 | 正数压暗（暗角），负数提亮 |
| 晕影中点 | 0~100 | 从多远开始压（越大压得越靠边） |

流程：旋转 → 透视 → 径向畸变 → **三通道各自色差缩放分别采样** → 按晕影曲线做亮度衰减。行区间并行。

## 没做
1. 没做桌面端的「自动校正」（按 EXIF 镜头型号读畸变参数）；
2. 没有网格变形（桌面端的网格工具）；
3. 0.74.x 全部只编译验证，无真机验收。
