# 0.74.6 面板高度自适应 + 参数行不再挤

1. **下方大块空白没了**：所有参数卡从「固定 300dp」改成「内容高度、最多 340dp」（`heightIn(max = 340.dp)`），内容少就自动收短：
   - `ParamDock`（画笔/修图）、`CutDock`（选区）、`ColorDock`、`AdjustDock`、`FxHueSatDock`、`FxVibranceDock`、`FxBrightContrastDock`、`FiPhotoFilter` 等全部生效；
   - 色阶、曲线两个两页面板同样改成自适应（内容多的页仍可滚）。
2. **参数行留白**：`LevelRow` 每行加 4dp 上下间距（标签 56dp + 滑块撑满 + 数值 48dp），不再一行贴一行挤成一块。
3. 面板内所有参数一律「一行一个」，不做并排多列。

没做：曝光度/色彩平衡/色调分离/照片滤镜/渐变映射的说明与补参数（`ui/ColorDocks.kt` 里已写好三个 Dock，接线在下一版验证后一起报）。
