# 0.67.86 修复记录（2026-11-08）

## 1. 裁剪底部条重做：按钮不再被挤掉
上一版加了「范围」按钮之后，那一行里说明文字 + 三个按钮的总宽度超出了屏幕，
`应用`（当时叫「完成」）被挤到屏幕外——所以看起来「没有应用按钮」。

现在：
- 说明文字压到最短（`拖边/角调整`，`maxLines=1` + 省略号），并用 `weight(1f, fill=false)` 只占剩余空间；
- 三个按钮都收窄了内边距（`PaddingValues(horizontal=6.dp, vertical=2.dp)`）；
- 右边那个改名 **应用**，字号 13sp + 半粗，视觉上就是主按钮；
- 整行 `fillMaxWidth()`，按钮不会再被推出去。

按钮从左到右：`拖边/角调整`… `范围：整张 / 当前层` · `取消` · **`应用`**

## 2. 图像大小也有「范围」了
对话框里多一个开关，点一下切换：
- `范围：全部图层（画布一起缩放）`（默认）—— 就是以前的图像大小，整张文档缩放到 W×H；
- `范围：当前图层（画布尺寸不变）` —— 只把当前层的像素等比缩到能装进 W×H 的大小，
  再居中贴回画布尺寸的层上；画布尺寸和其它图层都不动。

「画布大小」对话框不放这个开关（它本来就是改画布，不存在只改一层）。

## 怎么验
1. 两个图层 → 变换 → 裁剪：底部条应该从左到右看到 `范围：整张`、`取消`、`应用` 三个都在屏内。
2. 点「范围：整张」变「范围：当前层」→ 只裁当前层，画布尺寸不变。
3. 变换 → 图像大小：对话框里能看到「范围：全部图层（画布一起缩放）」这一行；
   点成「范围：当前图层（画布尺寸不变）」→ 确定 → 只有当前层变小/变大，画布没变。
