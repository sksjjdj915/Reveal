# 0.74.17 滤镜工具改成「工具包」+ 层级顺序修正

## 一、顺序（按你的口述）
自上而下：**画布 → 参数面板 → 子工具栏 → 主工具栏**。
之前子工具栏放在了参数面板上面，已改到下面。

## 二、「滤镜」是工具包，不算选中工具
- 只点「滤镜」：**不出现参数面板**，只把子工具栏展开；主工具栏里「滤镜」保持蓝色。
- 点某个子滤镜：才出现它自己的参数面板（参数面板在上、子工具栏在下）。
- 再点同一个子滤镜：收起参数面板，子工具栏仍在。
- 再点「滤镜」本身：整个滤镜组收起（子工具栏消失、参数面板消失）。

## 三、占用高度
- 硬要求「点开子工具占用的画面高度 = 普通工具」：`FilterDock` 的高度上限从 340 → **282dp**，正好让出 compact 子工具栏的 54dp；
  参数多的滤镜（动感模糊有距离+角度、镜头光晕等）在面板内部滚动，不额外压画布。
- 子工具栏仍比主工具栏小一号：行高 54 vs 68dp，单元 48 vs 56dp，图标/字号同步小一档。
