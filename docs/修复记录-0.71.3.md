# 0.71.3 图层 + 抠图（只接这两块）

## 一、图层
- 右下角一颗蓝色圆按钮（48dp），点了从右侧滑出图层卡片（占宽 74%，白底、圆角、带影，点卡片外可关闭）。
- 卡片里：层列表（最上层排最前）、眼睛开关显示/隐藏、点一行选中该层、「编辑中」标记、蒙版显示 `M`。
- 顶部四个动作：上移 / 下移 / 新建层 / 删除层。
- 底部：不透明度细线滑块，拖动实时改当前层。

## 二、抠图
- 工具栏里矩形 / 椭圆 / 套索 / 魔棒 / 主体，点下去就是切换 `SketchView.selectMode` 并进入选区工具，画布上直接能拖。
- 抠图模式的参数区换成专门的：`容差`（魔棒用，写进 `wandTolerance`）、`羽化`（0~50，点「羽化应用」才生效），下面五个按钮：羽化应用 / 全选 / 反选 / 取消 / 到新层。

## 三、这次没动
- 调色、排版、修图里的面板（`fx.*`、`act.*`）仍未接，点了不弹面板。
- 图层的混合模式、组、剪贴蒙版、图层样式这些入口都没做（面板只有上面那几件）。
- 参数区高度 112dp 固定；绘制模式仍是「大小 / 不透明」两个参数。

## 四、怎么验
1. 右下角蓝按钮 → 右侧滑出图层卡片；点眼睛隐藏层、点行切层、拖动不透明度、上移下移、新建/删除都作用于真实图层。
2. 打开软件默认就是「抠图」模式，底排是矩形/椭圆/套索/魔棒/主体。
3. 拉一个框选 → 参数区显示容差/羽化 + 五个按钮；点「反选」「取消」画布上蚂蚁线会跟着变。
