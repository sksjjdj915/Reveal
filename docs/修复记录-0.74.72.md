# 0.74.72 三个入口都找出来了：真正的原因在面板分发里

## 为什么你三个都没看到
查 `CanvasPage.kt` 的 `ParamDock` 发现一个**真 bug**：

```kotlin
if (mode == NewMode.COLOR) {
    val fxId = when (toolId) { "fx.exposure" -> ... else -> null }
    if (fxId != null && fxSpec(fxId) != null) { ...画面板... } else { EmptyDock(); }
    return          // ← 这一句把后面所有分支都吃掉了
}
```

调色模式里只要工具不是那 7 个（曝光度/自然饱和度/色彩平衡/黑白/照片滤镜/色调分离/渐变映射），就会先画一张「空面板」然后 **return**，后面「范围 / 液化 / 变形 / 图案」的专属面板**永远执行不到**。所以点「范围」什么都不出来 —— 不是没做，是被这段吞了。

## 改了什么
1. **把「范围 / 液化 / 变形 / 图案」的专属面板判断搬到调色分支之前**，并删掉调色分支里的 `return`（只在真的画出调色面板时才 return）。
2. **色带抠图挪到抠图工具行第一个** —— 原来排在最后一项，工具行是横向滚动的，不往左滑根本看不到「最后一个」。
3. **光晕工作室直接进调色工具行**（色阶后面那个），不用先进「滤镜」再找子工具了；滤镜行里那一份仍然保留。
4. **色带抠图补了实时预览**：拖黑场/白场/羽化，画面上立刻能看到哪里变透明（预览走 900px 底图后台算），「应用」才落层。

## 没做
「色带抠图」仍然只作用于当前图层，没有「下一图层」「多图层合成」的条件；光晕工作室里没有画布上的拖动手柄。0.74.x 只做编译验证，无真机验收（这轮改的正是「入口不可见」，必须真机确认）。
