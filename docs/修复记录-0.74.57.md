实现上给 `FxSpec` 加了可选 `presets: List<Pair<String, List<Float>>>`，`FilterDock` 有预设就渲染这一排；**参数顺序必须放在 `apply` 之前**，否则 `FxSpec(...) { }` 的尾随 lambda 会绑错参数（这次真踩了，编译直接报「No value passed for parameter」）。

## 二、画布拖光源
光照类参数的滑块很难「找到光源在哪」，所以加了一个胶囊：**点画面定光源**。
- 出现条件：参数里同时有「方位角」和「仰角」（目前只有光照效果）。
- 点开后进入取点模式，在画面上点一下：
  - 方位角 = 点击点相对画面中心的角度（右 = 0°、下 = 90°）；
  - 仰角 = 离中心越远越低（中心 90°、边缘 5°）。
- 复用已有的 `FilterPick` 通道（和「点画面选中心」同一套），点完自动退出。

## 没做
1. 没有做「拖光源」的连续跟随（现在是点一下定位，不是按住拖）；
2. 预设只有 10 个，没有做自定义预设的保存；
3. 光源没有半径/衰减曲线参数（聚光的衰减目前固定）。
