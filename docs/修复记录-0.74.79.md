# 0.74.79 圈外不消失：绘制层加的第三道锁

## 模型（沿用影视调色软件/桌面端/局部调整工具 一致的做法）
```
out.rgb   = base + (corrected − base) × mask
out.alpha = base.alpha
```

## 这次补的第三道锁（关键）
`SketchView.drawLayerPixels` 画预览时，只有「当前选中了范围」（`rg != null`）才先画原层再叠预览。
如果画面上有范围、但当前没选中它（`activeRegion == -1`），`rg` 是 null → **只画了预览图**；而预览图是按蒙版裁过的、圈外透明 → 圈外立刻变空。
现在改成：**只要 `regionsS` 里存在任何范围，就永远先画一遍原层**，再叠预览。这样预览图带不带透明都不影响圈外。

## 现在三道锁
1. `applyFilterToActive`：应用时 alpha 恒取原像素（`allowAlpha` 默认 false）；
2. `setPreview`：预览位图先叠到原层上（只要画面上有范围）；
3. `drawLayerPixels`：绘制时永远先画原层。
