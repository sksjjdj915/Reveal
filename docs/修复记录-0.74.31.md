# 0.74.31 模式之间真正互不干涉

## 问题的真因
`applyTool(view, id, mode)` 的 `when` 只给「画笔/选区/修图」这类真正的工具 id 赋了 `v.tool`，其余（色阶、曲线、滤镜入口、图像大小这些）全都落到 `else -> Unit`。
于是切到「调色」模式时，面板换了、**引擎里的工具没换**——上一次在抠图模式里选的 `Tool.SELECT` 还挂着，手指在画布上拖就继续拉选区。

## 改法
`else` 分支改成 `v.tool = SketchView.Tool.MOVE`：
- 非绘制类入口（色阶/曲线/各调色面板/滤镜/动作）一律把引擎切到「平移」；
- 此时单指拖动画布只是平移视图，不会再画线、也不会再拉选区；
- 双指缩放/旋转本来就和工具无关，不受影响。

于是：
- 「抠图 → 调色」：选区工具关闭，画布只剩平移/缩放；
- 「调色 → 绘制」：切到画笔；
- 「任何模式 → 只点了一个面板入口」：引擎都不会残留上一个模式的手势状态。

## 关于「一个模式里只能用一个工具、点开新的自动关掉旧的」
这个已经是现状（`activeTool` 单一状态 + `ParamDock` 单一面板），这次没有改动逻辑，只把「模式切换后引擎残留」这条漏掉的口补上了。

## 没做
选区本身不会因为切模式而被清除（选区是文档状态，不是工具状态）——你要的是「切模式后画布不再响应选区手势」，这点已达成；如果你希望**切出抠图模式时顺手把选区也取消**，说一声，一行就能加。
曲线吸管、液化/变形/图案图章、裁剪与画布大小、AI 仍未做。0.74.x 全部只编译验证，无真机验收。
