# 0.74.29 马赛克补参数 / 面板滚动 / 全部子滤镜自检

## 一、马赛克没有参数的真因
`ui/NewShell.kt` 的 `FILTER_SUB_TOOLS` 里有 `fx.cfx.mosaic`，但 `ui/FilterFxTools.kt` 的 `fxSpec("mosaic")` **根本没写**——`FilterDock` 拿到 null 直接 return，所以点「马赛克」什么面板都不出。
我用脚本把 30 个子工具 id 和 35 个 FxSpec 做了一次集合比对，缺的只有 `mosaic` 一个，其余都存在（含「查找边缘」这种真的无参数的）。

## 二、马赛克参数（新增 `FilterFx.mosaicAt`）
| 参数 | 范围 | 依据 |
|---|---|---|
| 单元格大小 | 2~120 | 桌面端「马赛克」唯一参数（每格取平均色） |
| 形状 0方·1圆 | 0~1 | 桌面端没有，多数手机 App 有的圆点马赛克 |

## 三、镜头光晕面板太高
- 面板高度预算从 `(屏高/2)−130` 收紧到 `(屏高/2)−150`，上限 460 → **380dp**；这样「面板 + 子工具栏 54 + 主工具栏 68 + 边距」稳定不超过屏幕一半。
- 结构改成**只有参数区滚动**：标题行与「应用/复位」固定在上下，参数多时中间那块独立滚动，按钮永远不会被挤出屏幕（原来整块一起滚，滚到底才看到按钮）。

## 四、没做
色阶/曲线等独立大面板仍用顶部两段分页；曲线吸管、液化/变形/图案图章、裁剪与画布大小、AI 未做。0.74.x 全部只编译验证，无真机验收。
