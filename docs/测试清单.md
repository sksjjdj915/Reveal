# Reveal 全功能测试清单（0.66.23）

13 个类别都已接通。下面按左栏类别顺序列，每条都是「点一下能看到变化」的行为，不是功能名词。

## ① 绘制
- [ ] 画笔/铅笔各画一笔：铅笔是硬边，画笔是软边。
- [ ] 画笔动态里调「大小抖动/角度抖动/散布」，笔迹明显变化。
- [ ] 橡皮擦擦掉一块；背景橡皮在纯色背景上擦，边缘不留白边；魔术橡皮点一下整块同色消失。
- [ ] 涂抹拖一下，颜色被拖出拖影；减淡/加深/海绵各刷一下，亮度或饱和度变化。
- [ ] 仿制图章按住取样点再涂，能复制另一块；修复画笔涂掉痘印；污点修复点一下瑕疵变干净；红眼点眼睛。
- [ ] 颜色替换在别处落笔，只把落点颜色换成前景色；混合器把画笔上的颜色拖进画布。
- [ ] 历史画笔回到前面某一步再涂，涂出的是那一步的样子；艺术历史选一种样式再涂。
- [ ] 图案图章选图案后能在画布上盖章。

## ② 选区
- [ ] 矩形/椭圆/套索/多边形套索各框一次，蚂蚁线正常。
- [ ] 磁性套索沿边缘走，能吸附。
- [ ] 选「加选/减选/交叉」，两个框叠起来结果符合预期。
- [ ] 修改里：羽化、扩展、收缩、平滑，边缘能看到变化。
- [ ] 色彩范围取一个颜色，只选中相近色。
- [ ] 选择主体：人像照片点一下，选区落在主体上。
- [ ] 存储选区 / 载入选区能还原。

## ③ 图层
- [ ] 加图层、复制、删除、上下移动、拖拽调序、成组和折叠组。
- [ ] 锁定（透明像素/位置/全部）后，对应操作被挡住。
- [ ] 填充不透明度调低，效果和普通不透明度不同。
- [ ] 颜色标签设完，点「选择同色标签」能选到同标签的层。
- [ ] 合并可见 / 盖印可见 / 栅格化；拷贝样式再粘到别的层。
- [ ] 加蒙版后黑笔遮住（显示红）、白笔还原；应用蒙版能真删像素。

## ④ 变换
- [ ] 自由变换：拖角缩放、拖角外旋转、拖内部平移。
- [ ] 再次变换（Ctrl+T 的重复）能接着上一次的位移/旋转。
- [ ] 拉直：画一条斜线，画布自动转正并裁掉空白。
- [ ] 内容识别缩放：主体不变形，只有四周被拉伸。

## ⑤ 调色（20 项）
- [ ] 亮度/对比度、色阶、曲线、曝光度、自然饱和度、色相/饱和度、色彩平衡、黑白、照片滤镜、通道混合器、色调分离、渐变映射、阴影/高光、色调均化，各点一次能看到变化。
- [ ] 替换颜色：选一个目标色，调容差，只有相近色被改。
- [ ] 可选颜色：选「红」范围，拉青色/洋红/黄/黑，红色区域变化。
- [ ] 匹配颜色：拿一张参考色，画面整体往参考色靠。
- [ ] 变化：拉色相/饱和/明暗，画面整体偏移。
- [ ] HDR 色调：暗部提亮但高光不爆。

## ⑥ 滤镜（45 项）
- [ ] 风格化：查找边缘、浮雕、油画、木刻、等高线、风。
- [ ] 模糊：高斯、动感、径向、方框、表面模糊、镜头模糊。
- [ ] 锐化：USM 锐化、智能锐化、高反差保留。
- [ ] 杂色：添加杂色、蒙尘与划痕、中间值、减少杂色。
- [ ] 扭曲：波纹、球面化、旋转扭曲、挤压、极坐标。
- [ ] 像素化：马赛克、晶格化、点状化、彩色半调、碎片。
- [ ] 渲染：云彩、镜头光晕、光照效果。
- [ ] 风格：滤镜库式的「水彩画纸」「胶片颗粒」。
- [ ] 每个滤镜都试一下「取消」，画面必须回到原样（可撤销）。

## ⑦ 图层样式
- [ ] 双击图层出样式面板，依次开：投影、内阴影、外发光、内发光、描边、颜色叠加、渐变叠加、斜面浮雕、光泽、图案叠加。
- [ ] 光泽：调角度/距离/大小，能看到一道窄的柔光带。
- [ ] 图案叠加：换图案索引、缩放、不透明度。
- [ ] 导出 PSD 后用电脑上的修图软件 打开：描边、投影、颜色叠加、外发光、内阴影、内发光、光泽应该还在图层面板里（双击图层能看到对应勾选项）。

## ⑧ 文字
- [ ] 点画布打字，字体、字号、颜色可改。
- [ ] 加粗/斜体/下划线/删除线、全部大写/小型大写、上标/下标。
- [ ] 字距、行距、横向缩放、纵向缩放、基线偏移。
- [ ] 对齐：左/中/右/两端（两端对齐时字间距被撑开）。
- [ ] 变形：13 种（弧形、旗帜、波浪…），弯曲度可调。
- [ ] 竖排：字从上往下排。
- [ ] 文字转选区：按文字轮廓出选区。
- [ ] 点已有文字层能重新编辑，改完内容/字号仍然生效。

## ⑨ 形状与路径
- [ ] 形状工具切换：矩形、椭圆、直线、多边形、圆角矩形、星形。
- [ ] 圆角半径、多边形边数、星形内径都能调，形状实时变化。
- [ ] 「填充：开/关」切换，实心/描边两种。
- [ ] 「存为路径」后再点路径名，能把它载入成选区；「填」「描」能直接画到当前层；「×」能删。
- [ ] 「选区→路径」把任意选区转成路径再载回来，形状应基本一致。

## ⑩ 视图与排版辅助
- [ ] 标尺开关：顶部和左侧出现刻度，缩放后刻度自动换档位。
- [ ] 网格间距循环：自动 / 25 / 50 / 100 / 200 px。
- [ ] 水平分布、垂直分布：三层以上时按等间距排开。

## ⑪ 文件与格式
- [ ] 保存 / 另存为 PSD，关掉 App 再打开工程，图层和样式都在。
- [ ] 导出：PNG / JPEG / WEBP / BMP / TIFF / PDF 各导一次，都能在电脑上打开。
- [ ] 导出对话框里「输出尺寸 50%」+「质量 60%」生效（文件名和体积都变小）。
- [ ] 分享 PSD 能发出文件。

## ⑫ 特效
- [ ] 「特效…」面板里：3D 立体化，角度 45°、厚度 18，应用后图层有厚度和暗边。
- [ ] 五个一键动作：黑白大片 / 赛博朋克 / 复古胶片 / 柔光人像 / 高对比锐化，各点一次画面风格明显不同，且可撤销。
- [ ] 历史回放：点「播放」画面自己一步步重演，能暂停、能调速度。

## ⑬ 面板与界面
- [ ] 导航器：缩略图出现，红框随手指移动，缩放滑杆拖动时画布跟着缩放。
- [ ] 信息：文档尺寸、缩放、图层数、有没有选区、历史步数都显示。
- [ ] 动作：回到开头 / 下一步 / 播放，历史在画布上逐步回放。
- [ ] 通道、历史记录、吸管、油漆桶、渐变入口都还能用。

## 0.65.3 之后新加的（按左栏类别，逐条试）

### 调色
- [ ] 替换颜色：取一个颜色、调色相/饱和度/明度，画面上只有相近颜色变了。
- [ ] 可选颜色：范围选「红」拧青/洋红/黄，红色区域变，其他颜色基本不动；换「中性」「黑」再试一次。
- [ ] 匹配颜色：调强度，画面整体色调往参考色靠。
- [ ] 变化：色相/饱和度/明暗各拖一下，效果方向对（负数是偏冷/变淡/变暗）。
- [ ] HDR 色调：半径、强度、饱和度各调，暗部被提亮而高光不糊。
- [ ] 自动色调 / 自动对比度 / 自动颜色：一键后偏灰的照片变正常，能撤销。
- [ ] 镜头校正：四个滑杆分别动一下，画面出现桶形/枕形变化、色边减少。

### 滤镜
- [ ] 液化：手指推、膨胀、收缩三种都试，只影响笔刷范围，能撤销。
- [ ] 自适应广角：拖几根线把歪的楼拉直，画面跟着校正。
- [ ] 消失点：画 4 个角定义一个平面，「拉正为新图层」得到正面视角的新层；再点「透视裁剪成新文档」得到一张只剩正面的新文档（新文档的图层面板要跟着刷新成 1 层）。
- [ ] 智能锐化：数量/半径/阈值各调，边缘变清楚而噪点不被放大。
- [ ] 高反差保留 / 最小值 / 最大值 / 位移 / 碎片 / 彩色半调 / 木刻 / 水彩画纸 / 胶片颗粒：各点一次，画面变化方向对。

### 图层样式
- [ ] 纹理：选图案、调缩放和深度，图层表面出现纹理。
- [ ] 等高线：换线性/锥形/圆角/环形，描边或浮雕的明暗过渡跟着变（环形中点最亮）。

### 文字
- [ ] 文字变形：下拉选弧形/拱形等，字形真的弯，不是只缩放。
- [ ] 竖排：一排字从上往下走。
- [ ] 斜体：字体自带真斜体时是字形倾斜；换成没有斜体的字体，仍然是 12° 斜切。
- [ ] 上标 / 下标：字变小（58.3%）并上下偏移（±33%），基线对得上。
- [ ] 文字转选区：先写一段字确定，再点选项栏「把上一段文字转选区」，蚂蚁线就是字的轮廓；原地改字后再点一次，选区跟着变。

### 形状与路径
- [ ] 矩形/椭圆/直线/多边形/圆角矩形/星形各画一个，多边形能调边数、星形能调内缩。
- [ ] 路径面板：存路径、载入为选区、选区转路径、删除路径。
- [ ] 钢笔：点几下出曲线，闭合后「钢笔转选区」「钢笔填色」都有效。

### 视图与排版辅助
- [ ] 标尺上按住往下拖出参考线，按住已有参考线能拖走，拖回标尺带里就删掉。
- [ ] 网格细分、分布对齐各试一次。

### 文件与格式
- [ ] 导出 TIFF / PDF 各一次，电脑上能打开、颜色对。
- [ ] 导出时改尺寸和画质，出来确实按新设置。
- [ ] 电脑上带图层样式的 PSD 导进来，样式能在 App 里看到并改（纹理/等高线只在 App 内）。
- [ ] 电脑上「置入的智能对象」PSD 导进来，那一层能继续「换智能对象内容」，反复缩放不糊。
- [ ] 自己转的智能对象：存工程、关掉 App、重开，还是智能对象（缩放不糊）。
- [ ] 打开一个很大的 PSB（几十 MB 以上）：能开就开，开不了要弹出「内存不够（上限 xxxMB）」而不是闪退。
- [ ] 批处理：选多张图 + 先在动作录制里录两步，跑完提示「处理了 N 张」，文件在 batch/ 里。

### 特效
- [ ] 自动合成：全景两张错开的照片拼一张、焦点堆栈两张一前一后取全清晰、HDR 两张一暗一亮合成中间调。
- [ ] 动作录制：开始录制 → 做两个滤镜 → 停止 → 回放，画面一次做完且一步就能撤销。
- [ ] 智能滤镜：把动作套成智能滤镜，能「关掉看原图」「打开」；存工程重开还在；PSD 导出是压平像素（桌面端里看不到滤镜，这是已知限制）。
- [ ] 脚本：写「高斯模糊 7」运行；写「重复 3 / 高斯模糊 1 / 结束」跑三遍；少写「结束」要报第几行。
- [ ] 导出历史帧：间隔 2 步导一次，帧数 = 步数/2 + 1，编号补零。
- [ ] 导出视频 MP4：选 24 帧每秒导出，手机相册/播放器能放，时长 = 帧数/24。
- [ ] 网格变形：选「变形」工具，拖网格上的蓝点，局部跟着弯；点「应用网格」后定死，能撤销。
- [ ] 选择并遮住：先框选人物，半径/平滑/边缘位移/对比各调，输出到「选区 / 图层蒙版 / 新图层」三种都试。

### 面板与界面
- [ ] 图层复合：存两个不同显隐的复合，来回切换，图层面板跟着变。
- [ ] 图层筛选：搜名字能过滤；类型筛选「文字/蒙版/组/锁定」各试一次；两者叠加。
- [ ] 颜色面板：前景/背景双色、交换、黑白复位、点色板改前景色、最近用过会累积；关掉 App 再开背景色还在。

### 大图模式
- [ ] 打开一张超过 1200 万像素的图：能正常画、能撤销 20 步左右，不会因为撤销记录太多而卡死。
## 通用回归
- [ ] 任意操作后按撤销，画面逐步回到原样；重做能恢复。
- [ ] 16 位/32 位文档：滤镜、裁剪、旋转后继续画，导出 PSD 用电脑打开仍是 16 位且颜色一致。
- [ ] 灰度/CMYK 文档：导出 PSD 在桌面端里打开位数和颜色对得上。
