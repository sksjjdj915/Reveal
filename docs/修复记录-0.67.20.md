## 一、描边/压暗挪到后台线程

`rebuildEdge()` 一次要做三件重活：`tracedOutline`（全图描边扫一遍）、
`Selection.edgeBitmap`（全幅位图）、`buildDimMask`（全幅位图 + 铺色 + DST_OUT 挖洞）。
8000px 以上的文档光这三步在主线程就要几百毫秒，按一下选区就顿一下。

现在整批扔到后台 `Thread`，算完 `post` 回主线程按代数（`edgeGen`）对号入座：

- 每次调用 `++edgeGen`，后台算完回来发现代数变了就整批回收扔掉，画面用最新那次的结果。
- 同一时刻只跑一个重建任务（`edgeBusy`），期间来的新请求记为 `edgePending`，
  前一个做完再补跑一次 —— 面板连续拖参数时不会堆出七八个线程同时各占两份全幅位图。
- 后台读遮罩时如果遮罩恰好被换掉/回收（用户又选了别的），`try/catch` 兜住，
  整批作废，交给后面那次重建。不会崩。
- 空选区的清理分支也补 `invalidate()`，清掉后画面立刻刷新。

## 二、缩放期间也能看见选区边界

以前 `drawSelection` 一进来就 `if (zooming) return`，双指缩放全程没有任何选区提示。
真正贵的是「位图蚂蚁线」那一支（每帧一次整幅 `saveLayer`），矢量轮廓只是三笔 `drawPath`、
压暗只是一张 `drawBitmap`，缩放中照画完全没问题。

现在：
- 缩放中照画 **压暗 + 矢量轮廓（蚂蚁线）**，只跳过位图边缘那一支（`edge != null && !zooming`）。
- 蚂蚁线计时器不再「缩放时 260ms 才动一下」，恢复 90ms 正常流速。
- 只有一种情况缩放中照样不画：快速选择在双指落下时把选区还原过（`selStaleDuringZoom`），
  这时候手里的派生图对不上，先空着，松手重建完立刻出现。

## 三、怎么验

1. 4096 或更大的图拉一个选区，双指缩放：手指一碰就应该跟手，不再有「按下去先僵住」的顿感。
2. 缩放过程中边界应该一直看得见（蚂蚁线在流动），松手后压暗和边缘一起落到新位置。
3. 快速选择模式做选区再缩放：起手会先没提示线（那一瞬间在还原选区），随后正常。
4. 打开 `选择并遮住` 连续拖羽化/平滑：面板拖动依然跟手，不会越拖越卡（重建排队只保留最新一次）。

## 四、这次仍然没做

- 后台重建用的是「当前选区位图」的只读引用，没有额外复制一份；靠 `try/catch` 兜住

  even-odd 填充直接在画布上压暗（不需要位图），那属于重写渲染路径，留到你有空验证时再做。
